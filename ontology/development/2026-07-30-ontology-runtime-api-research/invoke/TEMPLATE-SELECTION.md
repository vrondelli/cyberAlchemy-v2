# Template Selection

## Selected

| Mode | Template/profile | Eligibility | Result |
| --- | --- | --- | --- |
| Define | `domainspec-spec` | Typed operations, queries, states, events, mappings, and interfaces are all material | selected |
| Design | DomainSpec architecture bundle | Normal Design from approved Define outputs; all six views required | selected |
| Plan | standalone implementation-layering | Required for Plan | selected |
| Plan | standalone work-pack | Required for Plan | selected |
| Plan | DomainSpec execution-pack | High complexity and split waves | selected |

There is no tie. The `research` family is excluded because accepted research
already exists; `ux-plan` is excluded because v0 changes no rendered semantic
contract for a natural person; `spell` and `sigil` are excluded because the
target is an ordinary private module, not a reusable Arcanum capability.

## Discovery Gate

Discovery exists at [`../findings.md`](../findings.md), so no
`discovery_waiver_reason` is needed.

## Promotion Ceiling

Selection is local authoring evidence only. It does not promote a template,
release a registry entry, or make a mutation runtime ready.
