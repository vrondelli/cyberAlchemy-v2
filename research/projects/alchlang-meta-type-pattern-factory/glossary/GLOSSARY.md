# Glossary

- **Meta-type**: an admitted criterion for a recurring kind of domain meaning,
  with formation, relationship, behavior, and realization obligations.
- **Meta-type instance**: one authored domain node whose body and relationships
  satisfy a selected meta-type criterion.
- **Source factory**: a language-level constructor such as `entity(...)` or
  `operation(...)`; it produces semantic data and carries no admission power.
- **Frontend profile**: the closed grammar and decoder rules for one authoring
  syntax, such as Markdown or static TypeScript arrows.
- **Semantic carrier**: target-neutral, executable-string-free representation
  of AlchLang meaning, source spans, typed relations, and exact meta-type refs.
- **Construction profile**: immutable manifest composing every selected
  compatibility dimension for one compilation.
- **Realization provider**: target-specific renderer/prover registered for one
  admitted meta-type and language profile.
- **Integration binding**: provider-neutral or provider-specific formation of
  D45-D49 infrastructure responsibilities.
- **Architecture pattern**: a named composition of host meta-types,
  relationships, integration bindings, generators, conformance, and optional
  runtime observation.
- **Pattern availability**: mechanically derived technical closure; never a
  synonym for stability, adoption, release, or execution authority.
- **Factory projection manifest**: deterministic split from one AlchLang model
  into isolated DomainSpec instantiation inputs and proof DAG nodes.
- **Runtime observation**: evidence about provider behavior produced after
  generation; distinct from source or generated-artifact conformance.
