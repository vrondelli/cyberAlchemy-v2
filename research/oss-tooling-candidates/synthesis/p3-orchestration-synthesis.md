# P3 — Orchestration Tooling: Synthesis (reconciled candidate table)

**Role:** Synthesizer. Adjudicates the advocate (A) and skeptic (S) reports; no new research.
**Adjudication rule:** adopt-conservative — on a genuine tie the skeptic wins (tier down).
**Load-bearing frame both agents accept:** the native dispatch (router → type-skill → form chain,
append-only `subagents-dispatch.yaml` ledger under schema v0.6.0, typed `connections[]` DAG, the
three dials `layers`/`loop_cap`/`max_loops`, and the `check-tension`/`robot-talks` anti-bias gates)
**already is a governed orchestrator** whose execution substrate is the Claude Code turn itself.
Two properties must not break: **execution stays on the turn** (CLAUDE.md route-2 native-first;
orchestrate §5 no nested model-backed CLI) and **the append-only ledger stays the single
tamper-evident system of record**. Adopting a framework inverts control (a Python loop *calls*
Claude) and bypasses the ledger — so most candidates are REJECT-no-gap.

## Net verdict

The native governed dispatch **is** the orchestrator: every framework, durable-execution engine, and
sandbox/infra candidate is REJECT-or-DEFERRED because adopting it inverts control off the Claude Code
turn and bypasses the append-only ledger, re-solving the easy graph layer while abandoning the actual
discipline (human gate, anti-bias rubric, tamper-evident record). Both agents converge on exactly two
genuine gaps: (1) **no analysis/query layer** over the write-only YAML ledger, and (2) **no
crash-recovery** for an interrupted mid-loop `max_loops` run. The adopt-conservative, private-repo
answer is native-first: **build a read-only derived view** over the existing YAML (PILOT) and, only if
mid-loop interruption ever actually bites, **a lightweight append-only per-group progress marker**
(DEFERRED) — keeping the hooked, git-tracked ledger as the single system of record and treating hosted
platforms (Langfuse/Phoenix, Temporal/DBOS) as fallbacks gated on egress caution, with MCP the one
additive, already-native, per-need adoption.
