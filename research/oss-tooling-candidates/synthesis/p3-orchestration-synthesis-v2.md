# P3 — Orchestration Tooling: Synthesis v2 (post-adversarial, zig-zag round 2)

**Role:** Synthesizer. Revises v1 after INFLATION-HUNTER (over-recommendation) and
GAP-HUNTER (under-recommendation), both verified against the live ledger.
**Adjudication rule:** adopt-conservative — skeptic/inflation wins genuine ties; private-repo,
native-first bias applied throughout.

**Ledger ground-truth (141 rows, 1.24MB, re-verified):** `loops_used` is **uniformly 1**, even on
runs that budgeted `max_loops:2`. `exit_reason` = 135 resolved / 1 error (~0.7%). The v1 claim that
runs are "single-group" is **FALSE** — many runs are genuine multi-group DAGs; only the *loop* dimension
is degenerate. This correction matters: it removes the "trivial to query" prop under the derived-view
row while leaving the "resume completed groups" motivation for the progress marker **intact**.

## Noted future-native item (no tier flip)

**Post-hoc anti-bias realization check.** `check-tension` is **pre-flight only**; the ledger stores
angles/prompts/`exit_reason`, **not full findings**. So "did the agents actually diverge, or collapse
into agreement despite the gate?" is currently **unanswerable**. This is a genuine residual gap but
**low-value**, and the proportionate close is a **future native eval** (persist findings + score
divergence), **not** Langfuse. Flag only — no tier change.

## Net verdict

The native governed dispatch **is** the orchestrator; every framework, durable-execution engine, and
sandbox candidate stays REJECT because adopting it inverts control off the Claude Code turn and bypasses
the append-only ledger. After adversarial review the honest picture is **two genuine gaps** — (1)
**crash-recovery** for an interrupted multi-group run (real, and mis-defended in v1) and (2) **queryable
analysis** over the write-only ledger (real but its once-headline metrics are degenerate) — both closed
**native-first**: a **per-group progress marker as a SEQUENCED PILOT built now, armed on the first
`max_loops≥2` multi-group dispatch**, and a **derived read-view DEFERRED until a real variance-bearing
query arises**, emitted in **OTel-GenAI wire shape (PILOT rider)** for free backend-portability. MCP drops
to AVAILABLE (no consumer), DBOS to REJECT (nothing defers to it), self-hosted Langfuse stays DEFERRED on
second-store weight (not egress); the residual **post-hoc anti-bias realization** question is flagged as a
future native eval, not a tool adoption.
