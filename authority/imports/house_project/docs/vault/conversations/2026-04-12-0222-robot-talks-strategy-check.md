# Robot-Talks: Strategy Check & Ownership Separation

## Summary

Session enhanced the robot-talks skill and constitution with two changes: (1) a "Strategy Check" step requiring the orchestrator to present one rejected alternative decomposition alongside the chosen one for human evaluation, grounded in PM-2 (scope design determines signal quality). (2) Explicit separation of ownership in Phase 1 — the user defines the problem (central question, layers, assumptions) while the orchestrator proposes strategy, with enforcement that agents cannot spawn until the user approves. Both changes target the highest-leverage moment in a robot-talk: the decomposition decision.
