# Test Suite Stabilization and Rollback

**Date:** 2026-03-16
**Tags:** #multi-tenancy #testing #debugging #rollback

## Summary

The session focused on resolving a massive volume of test failures introduced by the `20260309-multi-tenancy` branch, particularly database deadlocks, `OperationalError`s, and widespread `TypeError`s/`ModuleNotFoundError`s. We successfully identified and patched multiple root causes—including tenant context loss in API tests and parallel background threads. Afterward, a highly detailed 500+ line post-mortem was generated. Ultimately, the user opted to roll back to the `main` branch to rebuild the domain piece-by-piece, starting with clean models and registry management tests.

Key outputs:
- `test-fixes-report.md` (subsequently deleted during rollback) — A comprehensive, 500+ line post-mortem detailing deadlocks, `FieldError`s, `TenantMiddleware` Token auth patch, and `.pyc` ghost error caching phenomena.

## Conversation Arc

**Started:** The user requested to fix database deadlocks and `OperationalError: server closed the connection unexpectedly` issues during test suite execution on the multi-tenancy branch.

**Ended:** After deeply debugging and documenting the true state of the broken test suite (179 legitimate failures), the user rolled back to `main` and manually introduced the clean definitions for Phase 1 models (`Bancarizador`, `TipoProduto`, `KitType`, etc.) and a comprehensive `test_registry_management.py` suite.

## Key Decisions

- **Topic: Test Deadlocks / OperationalError:** Found that background threads were operating without the `TenantMiddleware` context. Fixed via a unified global `conftest.py` injecting `get_default_company()` into test threads.
- **Topic: Deduplication FieldErrors:** Updated deduplication queries to traverse `remessa_id__company_id` instead of a direct `company` filter, since staging records no longer hold direct company FKs.
- **Topic: API Client 404s:** Enhanced `TenantMiddleware` with a fallback to extract user logic from DRF `Token` headers, since DRF authentication otherwise bypasses middleware execution.
- **Topic: Test File Fixture Cleanup:** Sequentially replaced rogue `__import__` paths generated by a previous refactor script and stripped invalid `company=` kwargs from staging models.
- **Topic: Ghost Errors (pycache):** Discovered that aggressive back-to-back testing and file overwriting decoupled the AST from the `.pyc` files, masking the test suite's actual state until caches were purged.
- **Topic: Rollback Strategy:** The branch was too entangled with broken legacy test assumptions. The decision was made to roll back to `main` and port the models/tests in smaller, verifiable increments.
