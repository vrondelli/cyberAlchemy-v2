### Synergetic Cybernetic Human-Machine Integration

Candidate ID: `CAV2-CAND-HMI-001`

Candidate aliases:

- governed human-machine integration
- CyberAlchemy human-machine integration
- synergetic human-machine integration
- synergistic cybernetic human-machine integration
- governed human-machine integration for complex knowledge work

Scientific/formal sketch: synergetic cybernetic human-machine integration is a
candidate system-level property or method posture in which human signals,
machine capabilities, and governed artifacts are coupled through explicit
feedback loops:

```text
sense -> decide -> route -> act -> test -> preserve -> hand off -> re-sense
```

The loop is admissible for CyberAlchemy v2 only when authority, provenance,
traceability, gates, consent or explicit user choice, residue handling, and
challenge routes remain visible. The synergetic claim should mean that the
combined loop enables a governed work capability that isolated agent systems,
knowledge stores, software tools, or interfaces do not provide alone.

Plain-language sketch: CyberAlchemy is not just a set of agents or tools. It is
people and machines working in one governed loop, where the person can still see
what is happening, choose the next move, and keep the work's evidence and
purpose intact.

Domain-context sketch: in CyberAlchemy v2, this candidate explains why IDE
Ergonomics and Connective matter. Cached knowledge references, teammate handoff
memos, the Craft control panel, and Connective task recommendations are treated
as integration surfaces: they help human attention, machine execution, Craft
state, tests, handoffs, and domain priorities regulate each other.

Boundary sketch: this candidate is not a claim that machines replace human
judgment, not generic human-computer interaction, not automatic execution, not
surveillance, not a medical or productivity diagnosis, and not public-ready
marketing language until boundary review. Human indicators must remain opt-in,
local, reviewable, and subordinate to explicit user control.
