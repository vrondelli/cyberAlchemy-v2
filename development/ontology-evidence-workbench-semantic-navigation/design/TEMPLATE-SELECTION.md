# Design Template and Profile Selection

- Baseline: DomainSpec `architecture-bundle.md`; required six views authored
- Required companion: `ux-plan`, because natural persons read, navigate,
  recover and operate changed rendered semantics
- Required companion: validation contracts, because the design carries
  hard-gate measurements, browser matrices and acceptance-readiness claims
- Triggered extensions: authority/trust, integration/versioning and quality
- Not selected: persistence/concurrency, failure/compensation,
  migration/rollout, data lifecycle and security/abuse; the package creates no
  durable product store, external/irreversible effect, deployment, personal-
  data flow or authenticated boundary
- Candidate template promotion: none
- Tie: none
