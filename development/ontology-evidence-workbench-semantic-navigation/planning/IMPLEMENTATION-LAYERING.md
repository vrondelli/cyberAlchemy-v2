# Implementation Layering: OEW Semantic Navigation

## Target and boundary rule

- Target: profile-driven semantic navigation in the existing OEW overlay
- Current state: partially implemented focus-scene prototype with a frozen
  Body War UX/UI failure baseline
- Rule: later layers preserve exact source identity, explicit projection scope,
  reversible navigation, local-only execution and authority effect none

## Layer Decision Table

| Layer | Decision question | Minimum working unit | Included | Deferred | Exit evidence | Promotion |
| --- | --- | --- | --- | --- | --- | --- |
| L0 | After this layer, we know whether one exact relation can be presented and operated accessibly in a bounded Body War scene. | pure relation-record derivation plus one selected-edge renderer/keyboard witness | schema, source/presentation directions, predicate color, presentation pattern, text, focus/action | home, portals, Path, broad controls | unit fixtures, selected-edge browser proof, contrast and forced-color assertions | continue only if lossless/redundant semantics pass |
| L1 | After this layer, we know whether profile-owned clusters, portals, Path and controls work repeatably with restoration. | one complete Home -> portal -> relation -> Path -> Back journey | approved profile, frames, cards/icons/counts/copy, modes, disclosures, modal, contrast | audit portability and human study | deterministic state, responsive and browser matrices | continue only if all hard gates pass |
| L2 | After this layer, we know whether the frozen quality loop detects fixes/regressions without inflating claims. | one comparable Body War baseline-to-current delta | full task/control/state/mode replay, receipt validation, residue | second project and human outcomes | digest-bound delta and independent verifier | continue only if atomic deltas/ceilings hold |
| L3 | After this layer, we know whether a second project can replace the profile without core changes. | second-project profile and calibration run | portability gate, four fixture families, vocabulary isolation | release/production and universal scoring | two-project conformance receipts | propose reusable capability development or stop |

## Value/cost boundary

- L0 unlocks the highest-risk semantic invariant with the smallest reversible
  product change.
- L1 adds one bounded theme—repeatable navigation and operation—after relation
  truth is stable.
- L2 adds evidence reliability without mixing it into product semantics.
- L3 is deferred because no second project is authorized and it adds no value
  to the first Body War prototype decision.

## Non-regression guardrails

- One stable color per exact predicate, one pattern per presentation relation,
  and redundant text/direction survive every later layer.
- Projection never becomes ontology membership, branch, causality or authority.
- `Show all loaded graph` remains explicit and never means ontology complete.
- Browser or agent evidence never becomes human comprehension evidence.
