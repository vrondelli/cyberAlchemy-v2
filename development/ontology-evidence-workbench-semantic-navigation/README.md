# OEW Semantic Navigation

Candidate Invoke Define, Design, and Plan package for making an Ontology
Evidence Workbench understandable before it exposes a full loaded graph.
Body War is the first frozen project profile and browser witness. It does not
become the authority for the reusable navigation contract.

This is an authoring package, not a runtime package: it adds no package
manifest, dependencies, deployment surface, ontology mutations, or promotion
authority. Future implementation remains in the existing
`cyberAlchemy-v2/implementation/ontology-evidence-workbench/` adapter/overlay
seam.

## Evidence ceiling

The package may prove only that a candidate Define, Design, and Plan were
authored and deterministically checked. Planned fixtures begin as
`plan-evidence-pending`. No artifact here proves usability, comprehension,
complete accessibility, ontology correctness, implementation, release,
deployment, or production readiness.
