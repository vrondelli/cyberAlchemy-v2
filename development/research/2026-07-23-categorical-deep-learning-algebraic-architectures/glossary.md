# Glossary

| Term | Local reading | Misuse warning |
| --- | --- | --- |
| architecture constraint | a commuting or lax-commuting categorical condition | not a CAV2 authority rule |
| parametric implementation | `(P,f)` with `f:P▷X→Y` | not a repository implementation task |
| reparameterisation | a typed comparison with parameter map reversed relative to the 2-cell | not governance transformation |
| weight tying | abstract repeated parameter use via copy structure in the source | practical correctness remains unproved here |
| recovery | construction from a selected functor/cell | not discovery from trained artifacts |
| universal | initial/final/free categorical property under hypotheses | not canonical authority |
| research value | useful external owner, distinction, or candidate | not promotion |
