# Local Glossary

Every term is `local-only / unpromoted`.

| Term | Source kind | Local meaning | Operator reading | Misuse warning |
| --- | --- | --- | --- | --- |
| category of wiring | local-inference | free category generated by a typed directed multigraph of specialist nodes and wiring edges | auditable path syntax | does not imply semantic meaning or runtime equivalence |
| specialist instance | primary-source | proposed JGS LoRA/gate/head bundle on a shared backbone (pp. 10–11) | graph node and callable component | not automatically a category object with a formal equality |
| composition edge | primary-source | stored source/target wiring with utility/validity metadata (pp. 11–12, 20) | candidate generating arrow | metadata and dimensional fit do not prove lawful composition |
| operational composition | operator-reading | sequential execution of compatible specialists | runtime pipeline | state/effects/error behavior can break a naive categorical model |
| coverage gap | local-inference | region where routing/gates lack adequate support | evidence-acquisition trigger | must not be called a missing morphism without typed arrow semantics |
| model neighborhood | primary-source + operator-reading | nearest items under a pinned embedding/index/metric (pp. 8, 12–13, 27) | candidate generator | proximity is not relation, order, facet, or hierarchy |
| growth operator | local-inference | state transition that adds validated nodes/edges/index entries | graph evolution | not a functor until its categories and preservation laws exist |
| backbone map | primary-source + operator-reading | mapping from adapter-specific representations into a shared space (pp. 1, 11) | representation interface | shared dimensionality does not establish a functor |
| variant replacement | primary-source | swapping one specialist variant while retaining wiring (p. 1) | graph rewrite/migration | not a natural transformation without two functors and naturality |
| escalation/compilation loop | primary-source + operator-reading | LLM resolves; trained JGS later handles similar inputs (pp. 2–3, 8–9) | slow-to-fast lifecycle | bidirectionality does not establish an adjunction |
| DNG encoding | primary-source | proposed dynamic-graph-to-latent transformation (pp. 14–17, 23–24) | learned graph encoder | no invariant, objective, or trained witness is supplied |
| DNG decoding | primary-source | proposed latent/specification-to-weights or model transformation (pp. 15–17, 24–25) | hypernetwork-like generator | no adjunction or inverse/reconstruction guarantee is supplied |
| category latent vector | primary-source | one proposed vector representing all nodes, edges, and flows (pp. 17, 24) | model-minting bottleneck | not a categorical invariant or proof of retained behavior |
| minted model | primary-source | standalone snapshot decoded from the category representation (pp. 23–26) | derived deployment artifact | existence, compression and behavioral fidelity are open |
| typed relation proposal | operator-reading | stable-endpoint candidate with explicit predicate, direction, evidence, owner, status | semantic-bridge boundary | neither embedding nor wiring creates semantic authority |
| preservation taxonomy | related-source | unit/counit/Lan/Ran/S2/S3 predicates explicitly typed in Lean | source of audit discipline | it does not supply learned semantics or validate this proposal |
