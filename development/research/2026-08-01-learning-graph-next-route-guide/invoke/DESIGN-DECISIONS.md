# Design Decisions

| ID | Decision | Reason | Consequence |
| --- | --- | --- | --- |
| DD-001 | Build a regenerable projection, not a canonical ontology. | Accepted research and owner boundaries. | Generated schema/runtime carries authority none. |
| DD-002 | Integrate with the existing ontology-view host only after learner-view mutation admission. | Avoid a second generic learning-map product. | No standalone `learning-graph.html` product; the permission cannot be reused as semantic evidence. |
| DD-003 | Freeze one positive and one abstention fixture first. | Smallest credible mechanical proof. | Real-source adapter and generalization deferred. |
| DD-004 | Treat question revision as a pure exact mapping. | Avoid anthropomorphic question semantics. | Premise drift suppresses revision. |
| DD-005 | Treat suggestion as a package, not a relation to executable work. | Preserve governance boundary. | No action control or workflow event. |
| DD-006 | Use generated JSON plus receipt as the cross-view source. | Preserve parity and replay. | Host must not rederive semantics from geometry. |
| DD-007 | Select UX, authority, state, persistence, integration, quality, and validation concerns. | Natural-person surface plus generated writer and governance boundaries. | Architecture and Plan carry explicit companions/gates. |
| DD-008 | Persist no real learner text in the first layers. | Session privacy owner is unresolved. | Use frozen fixture only. |
| DD-009 | Keep learner-view mutation admission, owner-resolved semantic-admission evidence, and destination-owner identity/admission as three disjoint records. | Passing the product mutation gate must not suppress mandatory abstention or make a candidate route executable. | Compiler/validator includes LGP-FIX-014 and the UI preserves a display-only destination string. |
