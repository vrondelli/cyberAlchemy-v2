# Template Selection

## Selected Family

- Define: DomainSpec specification family.
- Design: DomainSpec six-view architecture bundle plus the selected UX
  companion.
- Plan: standalone implementation-layering and work-pack companions plus the
  medium-complexity execution pack.

## Eligibility Evidence

The target has capabilities, typed records, pure derivations, a read-only UI
contract, explicit source bindings, and validation obligations. That matches
the DomainSpec baseline. A natural person reads and navigates a changed
semantic surface, so the UX predicate is true. The plan crosses owner and
artifact boundaries, changes more than two product artifacts, and requires
browser plus deterministic validation, so it exceeds the low-complexity
threshold.

No eligible tie exists. Spell and sigil families are ineligible because the
target is an ordinary feature/projection, not a reusable Arcanum capability.
