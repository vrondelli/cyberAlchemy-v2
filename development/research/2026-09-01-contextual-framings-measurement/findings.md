# Contextual Framings Measurement — Findings

**Status:** candidate measurement design; evidence closure is ready for writing only.  
**Scope:** the analogical contextual-framing treatment (`ACFT`), not framing in general.  
**Authority effect:** none.

## Claim ceiling

This artifact defines a source-grounded candidate measurement contract and a falsifiable round-trip protocol for a frozen `ACFT`. It reports no experiment result and grants no implementation, acceptance, publication, release, deployment, recruitment, external-effect, or human-benefit authority.

`ACFT` is an evidence-equivalent representation that declares source-to-target correspondences, non-correspondences, limits, and a return path to the concrete case. A future result could concern only the frozen arm bytes, cases, task family, population, and recorded conditions. It could not support a claim about framing generally.

The measurement spine is inherited from the Cognitive Tools Reflection Tower: representation design is separable from evidence about a reader response; horizontal alternatives must retain the claim, limit, governance, and approval invariants; and effectiveness remains empirical until a controlled route is executed. [`TOWER.md` §Construction, §Three axes, kept distinct, §Stop rule, §Gates](research/2026-08-07-cognitive-tools-reflection-tower/TOWER.md)

## Source-backed measurement spine

The inherited fixed task family is restatement, audience-appropriate representation choice, bidirectional translation, claim/approval-boundary identification, causal-overclaim rejection, return to the concrete case, unfamiliar-case transfer, and evidence-status classification. The inherited observables are semantic preservation, claim-ceiling and authority accuracy, return and transfer fidelity, causal-overclaim detection, stalls, paired confidence/correctness, and optional completion time. Time is secondary and cannot replace correctness. [`EVIDENCE-HANDOFF.md` §Fixed task family, §Candidate metrics](research/2026-08-07-cognitive-tools-reflection-tower/EVIDENCE-HANDOFF.md)

This is a task-local protocol: correct responses on its frozen prompts are evidence for those prompts and conditions, not a general claim about a person. The existing gate model keeps source identity and lane definition apart from protocol validity, treatment evidence, human evidence, public boundary, and owner authority. [`closure-gates.md` §Closure gates, §Gate policy](research/2026-08-07-cognitive-tools-reflection-tower/gates/closure-gates.md)

Explorer returns are synthesis lineage, not source authority: Halford supplies the semantic/return/transfer operationalization (`research.md` §Agent 0, §§3–7); Tversky supplies the proposed mapping and harm diagnostics (§Agent 1, §§Measurement contract–Interpretation boundaries); and Simon supplies the separate process-cost and stopping considerations (§Agent 2, §§Outcome model–Required next gate).

## Definitions and inference ceilings

| Term | Candidate operational unit | Ceiling |
|---|---|---|
| Framing | Selection and organization of evidence for one stated context, audience, or decision. | Artifact property only; no analogy, explanation-quality, or cognitive-effect inference. |
| Analogy | One declared source-target mapping or non-correspondence edge. | Permits inspection of the declared mapping only. |
| Explanation | An artifact intended to make one bounded claim intelligible. | Intention/form only; not evidence of a reader outcome. |
| Semantic fidelity | One preregistered source distinction in one response, scored retained/omitted/contradicted. | Fidelity to the frozen source key only. |
| Task-specific comprehension evidence | One keyed response to a frozen restatement, boundary, discrimination, return, or transfer task. | Evidence for that task and recorded conditions only; not a latent or general construct. |
| Recall | One keyed source element reproduced at one stated observation time. | Recall at that time and task only. |
| Retention | Persistence of acquired information or task performance across a justified longitudinal design. | One delayed-recall observation alone does not establish retention. |
| Delayed-recall fidelity | One keyed source element reproduced at one preregistered delay. | Human-only secondary candidate; exact items and interval only, not retention. |
| Boundary error | One claim-ceiling or authority-boundary error event per scored trial. | Recorded error incidence only. |
| Return fidelity | One required concrete-case element in one return response. | Reconstruction of the sampled case only. |
| Counterfactual discrimination | One keyed rejection of an unsupported mechanism claim per trial. | Discrimination for that item only. |
| Transfer accuracy | One keyed application plus justification in an unfamiliar matched case per trial. | Transfer to sampled cases only. |
| Confidence | One participant-reported certainty value for one response. | Reported certainty only. |
| Calibration | One confidence value paired with one keyed correctness/evidential-sufficiency observation; statistic and minimum observations remain unfrozen. | Correspondence on recorded items only; not general metacognitive ability. |
| Perceived effort | One response on one separately selected scale after one task block. | Self-report only; optional and deferred. |
| Cognitive effort/workload | Latent resource demand during task performance; no admissible unit in this protocol. | Not inferable from one effort response, task time, or agent behavior without a separately supported instrument. |
| Task performance | One trial’s correctness, critical-error events, completion state, and separately recorded process-cost fields. | Performance on the frozen task family only. |
| Completion time | Elapsed seconds per completed or stopped trial. | Task-local duration only; never a correctness substitute. |
| Action count | One recorded interaction action per trial. | A separate process-cost field only; no efficient-path or accessibility inference. |
| Help-event count | One recorded help request or help presentation event per trial. | A separate process-cost field only; no interpretation of need or difficulty without a frozen rule. |
| Stall/recovery | One preregistered no-progress event and its recovery trace. | Process event only; an agent trace is not a report of felt difficulty. |
| Usability | Effectiveness, efficiency, and satisfaction for specified users, goals, and context; no admissible unit here. | Not inferable from this protocol without a separately designed study. |
| Productivity | Meaningful output or value relative to resources over a defined workflow and horizon; no admissible unit here. | Not inferable from isolated correctness, completion, speed, preference, or self-report. |

Neither an analogy nor an explanation-form establishes a reader outcome. Confidence is not calibration; perceived effort is not cognitive effort or workload; speed or completion is not productivity; and agent success is not human evidence. These exclusions follow the candidate definitions and ceilings in `synthesis-round-2.md` §§`SYN2-04`–`SYN2-05` and the automated-structure boundary in [`cyberalchemy-naturalized-interface-design-research-result-synthesis.md` §Claim And Authority Boundary](.arcanum/inventory/entries/cyberalchemy-naturalized-interface-design-research-result-synthesis.md).

## Framing-specific candidate extensions

The following are precedent-clean candidate extensions, not inherited validated measures:

- **Mapping fidelity:** each declared correspondence or non-correspondence is scored correct, unsupported, or contradicted against a frozen mapping key.
- **Analogy-harm sentinel:** an `ACFT`-trial misconception is counted only when blinded adjudication retains a mapping-to-error trace. It requires a baseline-compatible generic-error taxonomy, severity policy, denominator, and literal trigger threshold.
- **Seven witness classes:** positive/helpful control, neutral, misleading, harmful, leakage, required-return, and unfamiliar-transfer. Each needs paired bytes, an evidence-atom inventory, answer key, permitted/prohibited inferences, and expected residue.

These extensions remain deferred pending a fixture catalog and frozen codebook; the existing worked example supplies calibration precedent for persuasive-label error and required return, but does not validate analogy attribution. [`round-trip-comprehension-example.md` §Treatment instrument, §Required return, §Scoring](research/2026-08-07-cognitive-tools-reflection-tower/examples/round-trip-comprehension-example.md); `synthesis-round-2.md` §§`SYN2-05`, `SYN2-07`.

## Safety-first non-operational primary hierarchy

1. **`P1a` boundary-error safety:** comparative claim-ceiling and authority-boundary errors.
2. **`P1b` analogy-harm sentinel:** treatment-only adjudicated analogy-attributed misconception events.
3. **`P2` correctness design family:** semantic fidelity, return fidelity, counterfactual discrimination, and unfamiliar transfer.
4. **Secondary/diagnostic observations:** confidence pairing, completion time, actions, help events, and stalls; optional perceived effort is exploratory.

`P2` is deliberately non-operational. Before any verdict it needs one preregistered decision object specifying component units, ordering or weights, denominators, missing-data rules, safety margin, harm threshold, benefit threshold, and uncertainty method. `P1a` and `P1b` are lexically prior: a favorable later value cannot conceal a boundary-safety or analogy-harm failure. [`EVIDENCE-HANDOFF.md` §Pre-registration requirements](research/2026-08-07-cognitive-tools-reflection-tower/EVIDENCE-HANDOFF.md); `synthesis-round-2.md` §`SYN2-06`.

## Evidence-equivalent arms and pretest

**Invariants.** Baseline is one prose representation; `ACFT` reorganizes the same evidence atoms through declared analogy, mappings, non-mappings, limits, and return path. Freeze source bytes, evidence-atom inventory, prompts, task-order policy, time/help policy, rubric, manifests, and digests. Matched tasks, loci, prompts, and stimuli remain byte-identical wherever the arm distinction permits. Learner-visible keys, audits, rubrics, results, and reviewer metadata are leakage failures. [`EVIDENCE-HANDOFF.md` §Arms, §Fixed task family, §Pre-registration requirements](research/2026-08-07-cognitive-tools-reflection-tower/EVIDENCE-HANDOFF.md); [`body-war-business-view-novice-comprehension-review-result-synthesis.md` §Reusable Instrument Contract](.arcanum/inventory/entries/body-war-business-view-novice-comprehension-review-result-synthesis.md).

**Agent structural pretest.** A later non-human pretest may validate paired-arm digests, evidence-atom equivalence, prompt/task identity, refusal and leakage fixtures, score-schema coverage, and telemetry completeness. It may report only that the instrument passed its recorded structural conditions. It cannot support a human result. [`EVIDENCE-HANDOFF.md` §Arms, §Result language](research/2026-08-07-cognitive-tools-reflection-tower/EVIDENCE-HANDOFF.md).

**Illustrative later human shape.** Separately authorized human-protocol work could use a counterbalanced first-exposure design: each person encounters alternate cases in baseline and `ACFT`, never both forms of the same case. The primary comparison is first exposure or a preregistered first-period estimate; later periods diagnose carryover only. Recruitment, population, sample size, power, thresholds, burden ceiling, retention interval, and any contact remain open and unauthorized. `synthesis-round-2.md` §`SYN2-08`.

## Scoring, adjudication, confounds, and invalidation

Machine-score exact categorical/key-presence fields where possible. Freeze the semantic codebook before execution; use condition-blinded independent scorers for semantic judgments; preserve original scores and adjudication trace; and freeze disagreement, escalation, third-adjudicator, and unresolved-result rules. This is a scorer-design proposal, not a reliability result.

Control or record order and learning, prior analogy exposure, source familiarity, demand cues, persuasive fluency, unequal evidence, help, interface conditions, fatigue, carryover, missing observations, scoring blindness, and arm deviations. Invalidate affected trials for digest mismatch, failed evidence equivalence, visible keys/rubrics, missing primary observations, arm deviation, or compromised blindness. Stop an instrument run for systemic leakage, invalid source identity, broken equivalence validation, or unusable telemetry; stop a participant block on request or a preregistered burden/stall limit. Never stop, extend, or reweight because interim observations look favorable. `synthesis-round-2.md` §§`SYN2-07`, `SYN2-09`, `SYN2-10`.

## Benefit-versus-harm interpretation

A prospective treatment-benefit direction survives only if the frozen decision object is met after `P1a` and `P1b` survive. It is unsupported if boundary safety violates its margin, if the analogy-harm sentinel crosses its threshold, or if the non-operational `P2` threshold is not met. A speed, preference, completion, confidence, or effort result cannot repair such a failure. Invalid, failed, mixed, and harmful observations remain typed residue rather than being redescribed as confirmation. This expresses a future decision rule; it does not assert a benefit or harm outcome.
