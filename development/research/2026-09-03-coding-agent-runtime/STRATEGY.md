# Coding Agent Runtime Research Strategy

## Thesis under test

The likely minimal architecture is not a new monolith. CyberAlchemy-v2 should retain product meaning and effect boundaries; ARE should retain request-relative context, reusable reasoning state, semantic receipts, and continuity; a mini-swe-agent-like kernel should provide the smallest coding loop and environment protocol; and BAML should be tested as an optional typed model boundary rather than assumed to belong in the hot path.

“Ferrari” is a measured product property, not a slogan: low route and orchestration latency, early visible feedback, minimal scaffolding, high exact-prefix reuse, deterministic trace reconstruction, crash/reconnect continuity, and fail-closed consequential actions.

## Evidence contract

Use exact-binding evidence. Local claims require current path and selector evidence. External claims require an exact upstream commit or version plus file/line or documentation selectors. Vendor performance and benchmark claims remain unverified until a reproducible local probe exists.

## Outputs

- `research.md`: parent-appended verbatim explorer returns.
- `synthesis.md`: reconciled evidence and candidate architecture.
- `review-round-1.md`: independent precedent, performance, and security attacks.
- `evidence-closure.md`: exact-binding coverage and unresolved gaps.
- `findings.md`: decision-ready product thesis, architecture, benchmark plan, and smallest vertical slice.
- Auditor verdict: accept the research result or request one bounded writer revision.

## Boundaries

This dispatch performs research only. It does not implement a runtime, adopt BAML or mini-swe-agent, alter an accepted binding, grant tool or effect authority, publish private material, or claim conformance, security, deployment readiness, or universal performance.
