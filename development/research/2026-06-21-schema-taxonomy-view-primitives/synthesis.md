# Synthesis - Schema / Taxonomy / Human View / Machine View Primitives

Synthesizer: Mac Lane, Saunders.

Evidence boundary stayed on `research.md`. This synthesis is a candidate
research artifact, not a canonical definition, constitution, axiom, discipline,
or ontology promotion.

## Verdict

- Schema: `build-from-owned`, with generic Schema `reference-only`. Do not
  duplicate `Schema`; add only narrow CAV2 subtypes like `authority schema` or
  `tower schema` if needed. Evidence: `research.md:28-34`.
- Taxonomy: `build-from-owned`. Promote only as a controlled classification
  catalog, not as ontology/schema/relation catalog. Evidence:
  `research.md:92-99`.
- Human view: `promote` as `human-continuation view`, not generic
  documentation. Evidence: `research.md:169-177`, `research.md:244-247`.
- Machine view: `build-from-owned`. Promote the primitive shape, but keep
  validator absence as residue. Evidence: `research.md:253-257`,
  `research.md:302-307`.

## Lifecycle Rule

Every load-bearing definition, constitution, axiom, discipline, task, system,
or workflow must declare its governed facets before promotion: schema/shape,
taxonomy/classification, human-continuation view, and machine/checkable view.
Missing or inapplicable facets must be explicit typed residue with owner route
and rationale, not silent absence.

## Primitive Group

Primary durable term: `governed facets`.

Candidate facet names:

- `schema facet`
- `taxonomy facet` or `classification taxonomy`
- `human-continuation view`
- `machine view`

## Proposals

Definition: A `governed facet` is a typed, owner-scoped surface that exposes one
governance obligation of a governed object without becoming the object itself.

Constitution: New governed objects must declare `source_of_truth`,
`owner_route`, `authority_posture`, `schema_ref`, `taxonomy_ref`, `human_view`,
`machine_view`, `evidence_links`, `validation_boundary`, and `residue`, or mark
facets `not_applicable` with rationale. Generated views must declare
`generated_from`, freshness, and non-authority. Evidence: `research.md:210-223`,
`research.md:280-283`.

Axioms:

- Shape evidence is not authority evidence. Evidence: `research.md:67-70`.
- Taxonomic assignment is not promotion. Evidence: `research.md:131-139`.
- Human-readable is not canonical. Evidence: `research.md:181-201`.
- Machine-readable is not authoritative. Evidence: `research.md:285-287`.

## Non-Collapse Laws

Schema validates shape; it does not satisfy contract or confer authority.
Taxonomy names admissible categories; it does not become ontology. Ontology
requires typed objects, typed relations, provenance, confidence, promotion
state, gates, and use obligations. Human views aid continuation; readability
does not create truth. Machine views support checking; parseability is not
proof, and proof of one invariant is not total semantic adequacy. Generated
projections remain derivative unless an explicit owner route says otherwise.
Evidence: `research.md:38-52`, `research.md:103-118`,
`research.md:261-272`.

## Blockers / Residue

Decide whether schema needs one or two CAV2 subtypes. Decide whether taxonomy is
one reusable primitive or several scoped taxonomies. Build or assign the global
machine-view validator / node envelope / typed-residue gate. Define an
objective legibility/navigability gate for human views. Resolve whether these
land in one `Governed Facets Constitution` or separate constitutions. Preserve
public/private scrub rules because human views can expose more than machine
sources. Evidence: `research.md:85-88`, `research.md:154-163`,
`research.md:238-242`, `research.md:302-307`.
