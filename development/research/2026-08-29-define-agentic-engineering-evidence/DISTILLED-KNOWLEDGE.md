# Distilled Knowledge

## One-Sentence Model

Define is worth keeping if an information-matched Definition Pack causes better
downstream plans and implementations, with less semantic rework and preserved
human understanding, at an acceptable total cost.

## Compositional Spine

```text
same task and sources
    -> ticket only
    -> same facts as prose notes
    -> same facts as a Definition Pack
    -> same pack plus an evidence gate
    -> independent planning
    -> clean-session implementation
    -> hidden acceptance cases and blinded review
    -> paired task-level comparison
```

## Borrow Carefully

- task-specific evidence conditions;
- explicit verification before commitment;
- valid non-action and escalation outcomes;
- intent, rule, scope, execution, and reporting error categories;
- hidden human repair and comprehension measures;
- executable tests linked to stated obligations.

## Keep Analogy-Only

- ECLoop is analogous to a future enforcement layer, not identical to Define;
- AGENTS.md is analogous to persistent context, not a Definition Pack;
- GitHub issues are practical ticket baselines, not the whole Jira/Linear model;
- mergeability is an integration signal, not semantic correctness.

## Block

- “more documentation improves agents”;
- “a complete Definition Pack proves shared understanding”;
- “more tests or faster completion proves better implementation”;
- combining pack structure and runtime enforcement into one treatment;
- product effectiveness claims from synthetic fixtures or one pilot.

## Smallest Coherent Experimental Unit

One frozen task evaluated across all four conditions, with the same raw sources,
an information-parity record for the two enriched representations, clean
planner/implementer sessions, hidden truth cases, two blinded reviewers, and a
single append-only outcome record per condition.

The minimum pilot is six such task blocks: two low-ambiguity controls and four
high-ambiguity tasks.
