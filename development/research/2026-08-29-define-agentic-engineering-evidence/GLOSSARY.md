# Local Research Glossary

These terms are local to this tower. They are not canonical definitions.

| Term | Source kind | Local meaning | Define reading | Misuse warning |
| --- | --- | --- | --- | --- |
| Definition Pack | local source | Define's checked bundle for one stated use | the core structured intervention | not permission to implement and not an evidence gate |
| equivalent notes | operator-reading | the same selected fact set as a pack, presented as ordinary prose | information-control condition | must not omit facts present in the pack |
| evidence condition | primary-source | an observation required before a class of action | possible runtime binding from pack obligation to observation | not automatically part of Define's product meaning |
| evidence gate | operator-reading | runtime check that postpones an action until named evidence is observed | separate enforcement condition | must not be attributed to the pack-only condition |
| premature commitment | primary-source | editing or submitting before enough evidence is examined | one failure Define may help expose | not every early edit is harmful |
| valid non-action | primary-source/operator-reading | a correct outcome where no code change should occur | implement, abstain, ask, or escalate can all be valid | abstention is not always correct |
| semantic defect | local definition | behavior that violates accepted goal, intent, context, concept, owner, or permission meaning | primary downstream failure measure | ordinary style defects do not automatically count |
| hidden human repair | primary-source/operator-reading | correction performed after agent output that success metrics may miss | owner corrections, review work, and rework minutes | do not infer unobserved repairs |
| comprehension | primary-source/operator-reading | a person's ability to explain and extend the produced work | continuity guardrail | satisfaction is not comprehension |
| low-ambiguity control | local definition | task whose important meaning is explicit and stable before the experiment | detects unnecessary Define overhead | classification must be frozen before results |
| high-ambiguity task | local definition | task with a pre-identified consequential meaning, context, owner, or permission tension | intended pressure case for Define | must not be chosen because Define already succeeded on it |
