ELK’s official reference says layered layout is direction-oriented and supports edge labels/routing; seed `0` may be time-derived, so use a fixed value such as `1`: [React Flow ELK example](https://reactflow.dev/examples/layout/elkjs), [ELK Layered](https://eclipse.dev/elk/reference/algorithms/org-eclipse-elk-layered.html), [ELK random seed](https://eclipse.dev/elk/reference/options/org-eclipse-elk-randomSeed.html), [official elkjs repository](https://github.com/kieler/elkjs). When DomainSpec evolves:

2. Add a new adapter version beside the old one; never reinterpret old bytes in place.
3. Validate schema IDs, profile and registry digests, compiler version, provenance chain, and named negative fixtures.

5. rebuild snapshots; changed identity-bearing inputs must change snapshot identity.

7. only the dedicated authoritative adapter may accept owner-issued `Sg`; candidate/demo adapters can never toggle posture upward.
