# Candidate Feature Glossary

> These terms explain this package. They do not redefine Arcanum, CAV2, DomainSpec, or Craft authority vocabulary. Source-owned terms link back to their owners; normalized fields remain candidates.

| Term | Candidate meaning here | Source/authority posture |
|---|---|---|
| Projection compiler | Deterministic reader that produces a versioned immutable learning snapshot from allowed sources. | Application role; no promotion authority. |
| Internal plane | One of six application classification partitions used to prevent type collapse. | Not a canonical CAV2 node kind. |
| Semantic view | Separately serialized source-backed records and admitted relations. | Derived, authority-neutral view. |
| Learner view | Focus questions and labeled authored propositions over shared IDs. | Editorial projection; never semantic authority. |
| Navigation view | Prerequisites, learn-next edges, breadcrumbs, and journey order. | `semantic: false`. |
| Stable identity | Deterministic record/relation identifier reused across views. | Identity does not confer authority. |
| Source-local value | Kind, relation, status, or definition preserved in its owner namespace. | Owned by its source route. |
| Normalized axis | Candidate cross-source field used for filtering or explanation. | Unowned until G-OWNER closes. |
| Attempted relation | Proposed relation rejected by a source-local endpoint/signature rule. | Residue/challenge record; never semantic export. |
| Non-collapse law | Testable rule prohibiting an invalid identity or proof/authority inference between axes. | Candidate application invariant grounded in accepted research. |
| Claim class | Candidate distinction among operational, formal, analogical, philosophical, and speculative statements. | Application field; must preserve source wording. |
| Authority effect | Explicit statement of what a record/relation may change; defaults to `none`. | Displayed, never inferred by adjacency. |
| Semantic hash | Hash over canonical semantic material only. | Must ignore learner/navigation/layout-only changes. |
| Learning journey | Authored sequence answering a focus question over stable identities. | Product content, not ontology relation. |
| Equivalent non-spatial view | DOM hierarchy and relation table that expose the information/actions of the spatial graph. | Accessibility and comprehension surface, not fallback decoration. |
| Publication candidate | Separately built Arcanum-only output with allowlist, manifest, scans, and no publication authority. | Outside private L0; verdict remains separate. |
| SWU | Expansion unresolved between current Craft sources. | Learner-facing expansion blocked; use the acronym or resolve via definitions governance. |

## Forbidden synonym merges

Do not use these pairs as synonyms: projection/promotion; source/evidence; proof/verification; candidate/promoted; owner route/owner decision; learner edge/semantic relation; artifact/concept; formal correspondence/analogy; build success/publication approval.
