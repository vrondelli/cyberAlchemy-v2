# Open Questions

1. Does “whole repository” mean only the parent Git root, or all seven Git roots
   plus their remote CI and branch-protection configuration?
2. Who owns the proposed root posture surface and its repository-role decision?
3. Should observation remain completely off by default, or may local,
   privacy-bounded telemetry remain enabled when it cannot affect work?
4. Which existing surface should become the first isolated observe-only fixture?
5. Where will the seven-refresh sequence be materialized as a typed event corpus,
   and which refresh causes are semantic rather than mechanical?
6. Which countermetric will detect semantic drift that an aggressive friction
   reduction might miss?
7. Should a distinct product capability named Governance Fitness be added after
   the first vertical, or does Governed Work Loop already express the behavior?
8. What evidence threshold would justify proposing an exact Governance
   Constitution for adoption, if any?
9. Which DomainSpec v1 formulas are useful precedents after the colliding M-IDs
   are removed?
10. What owner decisions are needed before independent Git roots or public
    Arcanum CI may adopt an observe-only adapter?

None of these questions authorizes enforcement, mutation, promotion, or a Plan
handoff.
