# cav2 definitions → Mint-baseline partition (FROZEN findings)

**Question.** Of cav2's 50 `CAV2-D*` definitions, which should Mint seed into every minted repo as a
**universal governance baseline** (the D21 class), which are cav2-object-content to localize, and which
are already inherited?

**Dispatch.** research, 4 agents / 2 tensioned groups, check-tension PASS (after one revision).
Collected returns: [research.md](./research.md). Classifiers: [classify-universality.md](./classify-universality.md)
(Lawvere) · [classify-coupling.md](./classify-coupling.md) (Bateson). Verifiers:
[verify-circularity.md](./verify-circularity.md) (Russell) · [verify-gap.md](./verify-gap.md) (Popper).

## Headline
**The owner was right — the audit's binary missed a large category.** Of 50 definitions, **~29 should be
baseline** (27 seed-as-rule + 2 seed-as-format) — yet Mint currently seeds only ~5 inherited meta-rules.
D21 (Four-Facet Action Method) was the tip; the partition finds the whole class. The circularity guardrail
still holds: every baseline is a **method FORM** (how any repo acts), never cav2's object rows.

## How each call was decided
A definition reaches **inherit-as-baseline** only if it clears BOTH gates: Russell (seeding does not
re-fuse levels / a strippable FORM survives) AND it is needed (Popper, or agreed by both classifiers).
It is **localize** if Russell demotes (re-fusion) OR no domain misses it. Where Russell demoted the
*definition* but Popper needed the *format*, the item is **SPLIT** (seed the empty format, localize the
rows) — the same rule Mint already uses for #3/#4/#5/#17.

## The discriminator the partition surfaced (for the build)
Two baseline shapes, seeded differently:
- **Rule baselines** (D21, D16, D18, D24, D26, D28, D30, D38…) — "the domain's actions must satisfy X";
  seed as constitution rules.
- **Format/primitive baselines** (D15, D32–D37, D40, D42…) — "a structure the domain fills"; seed as an
  empty contract. **Do not seed a format as if it were a satisfied rule** (that was Popper's mild-D21-echo caveat).

## Residue (claim ≤ proof)
- Partition frozen from 4 agents (2 classify + 2 verify) over all 50, each verdict cited to `DEFINITIONS.md`;
  but no per-definition *owner* has ratified it — this is candidate input to the addition, not a cav2 authority act.
- **D42** is explicitly deferred (fold-or-seed) — sigil-development decides at build.
- The 27 "seed" definitions do NOT mean 27 new files — they mean a **baseline-constitution pack** binding
  them as rules/primitives (referencing IDs). Template surface is a build decision.
- Universality-classifier read only the normative *quantifier*; the circularity gate had to read the
  Formal Interpretation + Primary Consumers (where cav2 rows enter) — that split is why the two-gate
  verify was load-bearing, and why ~12 "universal-in-form" definitions still localized.
