## Surviving presentation model

Context clusters are profile-approved projected scope groupings. Portal cards are navigation entrances into clusters. Path is a separate route comparator and must not present route-local hops as an ontology branch. Exact predicate owns stable color; coarse presentation relation owns line pattern; exact text, direction, node role/kind, status, provenance, and authority remain visible non-color cues.

## Kept positives and bounded claims

- Same computed color held within the default scene for 72 `builds_on` and 159 `related` edges. Cross-scene stability remains unproven.
- Reduced-motion transitions collapsed; top controls had visible cyan focus; selected detail exposed `authority:none`; 390x844 had no document-level horizontal overflow.
- Filter/Export Escape restored trigger focus; edge names retained endpoint direction; no captured console errors or failed requests.
- Cards retained visible `CLAIM`/`SOURCE`; selected SuggestedTrack exposed authority, candidate status, summary, and source file.

No portal-recovery, human-comprehension, clarity, workload, trust, preference, ontology-validity, promotion, release, or production claim survives.
