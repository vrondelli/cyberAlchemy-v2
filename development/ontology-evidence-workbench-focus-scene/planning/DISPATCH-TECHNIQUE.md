# Dispatch Technique Trace

The target is one shared source/binding chain with overlapping files, so
parallel implementation fan-out would create merge and ownership ambiguity.
No governed multi-agent dispatch is selected.

One read-only background helper audited ordering and target overlap. Its return
was checked against live hashes and corrected where it attributed the observed
defect to the private `OewApp` branch; browser evidence fixes the target at the
default dashboard.

Execution route:

```text
Invoke plan/distill → Task Session FOCUS-001
                    → Invoke Refresh FOCUS-002 preview
                    → legacy synchronization handoff
```

Gate:

FOCUS-001 may mutate only after the current 007T receipt passes and its own
seven-path target inventory is frozen. 013B remains unselected until the focus
receipt and lock binding are synchronized.

FOCUS-002 may mutate only the frozen compatibility-preview inventory after the
FOCUS-001 receipt passes. It stops after browser evidence and does not select
or close any legacy SWU.
