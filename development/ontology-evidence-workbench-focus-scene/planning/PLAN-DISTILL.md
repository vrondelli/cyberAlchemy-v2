# Plan Distill — OEW Focus Scene

## Decision

Patch the exact default knowledge dashboard where the defect was measured.
Keep the model pure, derive all scene membership from frozen graph/sidecar
inputs, and hand immutable build/browser proof back to the legacy OEW chain.

## Smallest coherent units

One source SWU owns two new modules, one preimage-bound patch, one focused
runner, and the three binding documents. A second preview-only SWU owns the
minimal compatibility change needed to apply the complete overlay and exercise
the actual default browser surface. Splitting either unit would create hidden
glue; treating the preview as 013B/014/014V completion would inflate the claim
past the synchronized legacy frontier.

## Critical falsifiers

- the patch cannot apply exactly once to upstream commit `2cda14e...`;
- the first scene is not exactly 4 nodes / 0 internal / 6 portals;
- evidence metadata requires a duplicated dataset rather than the sidecar;
- package or adapter-schema mutation becomes necessary;
- fresh dashboard build fails.

Any falsifier blocks the SWU before legacy 013B selection.

Preview falsifiers:

- the retained builder cannot apply every bound patch in order;
- the default browser surface does not expose exactly 4 nodes / 0 internal
  edges / 6 portals for the first tour;
- the literal portal loses `owns` or `authority:none`;
- browser acceptance requires ontology, package, or custom `OewApp` mutation.

Any preview falsifier blocks FOCUS-002 without changing the completed source
receipt.
