dashboard served at `/?token=...`. The private `?oew=1` Poker evidence branch

## Layers

1. **Frozen source evidence** — Body War presentation graph, evidence sidecar,
   adapter receipt, and the black-box 237-node/231-edge measurements.
2. **Pure projection model** — derive one scene from current tour membership or
   one focused node; classify internal relations and crossing portals without
   creating ontology meaning.
3. **Viewer integration** — apply one exact upstream patch that replaces
   whole-graph fading with bounded scene rendering and exposes accessible
   portal controls.
4. **Build binding** — register new overlay files and the patch in the private
   manifests and L1 build lock without changing the package registry.
5. **Downstream proof** — legacy 013B owns the immutable build; 014/014V own
   authenticated browser acceptance and independent verification.

## Authority

Focus scenes and portals are removable presentation behavior. They do not
modify ontology nodes or relations, and their authority effect is `none`.

- no generated graph editing;

  from the existing sidecar when available, never re-authored as a second
