# Design Template and Profile Selection

## Selected

- DomainSpec six-view architecture profile: required navigation baseline.
- architecture companion: required by adapter, state, renderer, identity,
  direction, provenance, and authority boundaries.
- UX plan: required because natural persons navigate and interpret a changed
  rendered semantic contract.
- validation contracts: required by exact fixture, selector, responsive,
  forced-colors, restoration, and claim-ceiling obligations.
- successor Define delta: required because normal Design admission is blocked.

## Not Selected

- Work Pack/SWU templates: Design mode cannot create implementation tasks.
- spell/sigil templates: this is a private product feature, not Arcanum
  capability authoring.
- generalized cluster/semantic-zoom architecture: no first-prototype need and
  no accepted semantic owner.
- normal Design selection extensions: no closed successor Define or passing
  `DesignScopeManifest` exists.
