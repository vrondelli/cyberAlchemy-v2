## Discovery Baseline

## Round 1 — Full Candidate

**Proposer claim:** bounded home + context portals + relation-bearing Path +
legend + all-loaded escape form one useful navigation design.

**Evidence/assumption:** both feature families use the same exact relation
fields, source/presentation owner split, store, legend, and inspector.

**Balancer objections:**

- oversized unit: portal navigation closes without a route algorithm;
- hidden state: Path scope/filter semantics and frame fallback were incomplete;
- non-vacuity: scene-specific legend rows, responsive forbidden pairs, and
  Path hashes were not independently calculable;
- evidence maturity: source values remain candidate until Define approval.

**Reconciliation:** revise. Preserve Path in Design but split it from the first
coherent proof; close mechanical gaps in the discovery contracts; retain the
Define gate.

## Round 2 — Split Candidate

**Proposer claim:** Unit A is an Identity portal round trip:

```text
lossless relation contract
  -> four-context home
  -> Identity 2/1/5 context
  -> three source-backed portal cards
  -> one portal entry
  -> exact Back/all-loaded restoration
  -> scene legend + provenance
```

**Evidence/assumption:** this tests the user's central cluster-as-area idea with
exact Body War records while reusing existing focus/store/renderer owners.

**Balancer objection — requisite variety:** removing exact source proofs,
legend, restoration, provenance, or all-loaded escape would make the card an
unexplained visual guess. Path can be a sibling because it adds an independent
derivation algorithm and session lifecycle.

**Reconciliation:** accept the split. Unit B is relation-bearing Path and
depends on Unit A's lossless relation model, inspector, legend, scope
fingerprint, and state rules.

## Smallest Coherent Unit

Unit A owns one deterministic orientation/navigation round trip. Inputs are an
admitted graph, lossless sidecar, four ordered home IDs, the Identity ownership
and crossing fixture, exact relation fields, and one navigation frame. Outputs
are a bounded home read model, Identity context, three portal records, exact
legend/inspector records, reversible navigation receipt, and all-loaded escape.

It cannot be split further without losing the claim under test: that a named
context area and evidence-bearing portal can replace the initial black box
without hiding or inventing ontology structure.

## Recomposition

The pure context/portal projection repeats for other contexts. Unit B attaches
as a sibling consumer of the exact relation model. Both render through the same
canvas, inspector, legend, provenance, and one store. No second graph or history
owner is needed.
