# Fresh-thread learning result

The existing ARE prototype transferred three explicitly retained conventions into new conversations. It tied a plain-language memory summary; this test does not establish an ARE-specific quality advantage.

| Treatment | Applicable conventions | Scope / override controls |
|---|---:|---:|
| A: no retained memory | 0/3 | 3/3 |
| B: same preferences and conditions in a summary | 3/3 | 3/3 |
| C: ARE scoped projection | 3/3 | 3/3 |

Completed 24 live calls on gpt-5.6-sol: six training turns followed by 18 evaluation turns, each evaluation in a fresh ephemeral thread. All six arm orders were rotated. Built-in memories, external memory import, shell tools and multi-agent features were disabled. No tool, optional provider or model-judge calls occurred. Elapsed time: 307.3 seconds.

The corpus, rubric, runner and 543-file original candidate closure were frozen before live execution. Two local tests passed, including a complete scripted 24-turn wrapper rehearsal checking attribution, isolation, treatment contents, applicability and immutable lessons. The old protocol/schema binding and DomainSpec replay passed. Post-run validation confirmed 555 frozen inputs, 18 distinct evaluation threads, no training/evaluation thread overlap, exact lesson selection and the 24-call ceiling. The original candidate remains unchanged.

The local rehearsal first exposed ambiguous lexical routing and a harness attribution error caused by treating a keyed turn collection as chronological. Before freezing, requests were given consistent unambiguous wording and attribution was bound to the exact training thread. Neither finding required changing the runtime or retrying a live run.

Source-grounded feedback is explicit and host-typed. Scope is lexical, and the override control is also supplied by the host. This tests retained-memory transfer within one process, not autonomous rule discovery, weight learning, semantic generalization, restart durability or broad answer quality. In particular, the baseline correctly acknowledged missing measurements; its failed check concerns the custom suffix only. Three conventions and one observation per case are insufficient for a general reliability claim.

Usage, deduplicated by final cumulative totals for 21 threads: 392,072 input tokens (155,520 cached), 4,487 output tokens. Cached input is a subset, not an additional charge count. No monetary estimate is asserted.

Product construction frontier: explicit convention transfer is demonstrated for this bounded corpus. The next runnable experiment should freeze conflicts, revisions and stale-memory cases and compare equal-information summaries against scoped projection over repeated runs. A tie would justify narrowing the claim to inspectable retention and control, rather than superior answer quality.
