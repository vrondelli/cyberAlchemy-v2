## Product and completion contract

explicit correction of a selected completed response, scoped retention, current
overrides and inspection. Join that adapter to the existing wrapper, objective
resolver, learning lifecycle and file-backed reasoning ledger. Expose a runnable
`are interaction` review demonstration and JSON-lines host interface with an
injected response provider. Provider output is observed, never executed as tools.

Done means the review demonstration runs from this checkout, the supported host
contract is documented, source roles remain distinct, objective transitions and
learning survive a real restart, negative behavior tests pass, and a frozen
current source manifest has a reproducible test report. A fixture demonstration
must identify itself as fixture evidence. Neither literal checks nor injected
interpretation proposals establish general semantic understanding or model gain.
