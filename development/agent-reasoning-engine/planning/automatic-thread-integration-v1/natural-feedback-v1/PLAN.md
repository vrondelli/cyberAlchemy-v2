# Natural feedback prototype plan

Product construction, runnable now:
1. Define bounded phrase recognition, pending confirmation and current-request precedence.
2. Reuse the ARE lifecycle and ledger; keep original request bytes and source provenance.
3. Test real file persistence, pending expiry, modes, exceptions, quotation and scope.

Definitions and ontology scaffolds remain non-authoritative. One candidate is the
new interpreter plus isolated adapter and source-bound tests. No older native
canary PASS transfers to these changed bytes.

Current frontier: steps 1-3. Done means supported persistent feedback learns only
from a completed episode; ambiguous feedback is not retained as a lesson;
one-time instructions do not persist; confirmation is adjacent and source-bound;
invalid or quoted input creates no lesson; old controls remain compatible.

Deferred product construction: broader language interpretation, steering,
compaction, subagent attribution, richer inspection and actual erasure semantics.
Operational support owner: host integrator; affected stage: future native canary
and current-chat installation. Real model budget is exhausted, but does not block
local construction or tests. Product approval, rollback and activation are separate
later stages. No new model calls or live hooks are authorized by this plan.
