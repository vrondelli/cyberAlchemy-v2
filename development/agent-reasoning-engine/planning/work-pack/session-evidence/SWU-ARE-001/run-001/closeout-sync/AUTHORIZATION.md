# SWU-ARE-001 closeout authorization

Authorization is derived from the terminal Task Session receipt and is limited
to lifecycle bookkeeping owned by Invoke and Craft.

Allowed:

- mark SWU-ARE-001 and its parent task completed;
- link the exact terminal witness evidence;
- close `GAP-ARE-SEMANTIC-WITNESS`;
- refresh the Craft index and human view; and
- name `G-ARE-L0` owner evaluation as the next route.

Not allowed:

- promote `G-ARE-L0`;
- select or authorize a successor SWU;
- close downstream gaps;
- authorize real effects, public publication, or broader engine claims; or
- alter implementation artifacts.
