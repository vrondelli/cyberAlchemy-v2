# Agent reasoning engine implementation layering

Status: **ACI-subordinate plan authored; implementation not authorized**

## Global boundary

The whole architecture is planned, but evidence promotes one layer at a time.
No layer may claim a general reasoning engine, real-world truth, anti-bias
efficacy, canonical promotion, or effect permission.

## Cross-layer invariants

- Entry decision precedes any actor/evaluator event.
- Entry `block/defer/flag` causes zero calls; `flag` needs a new explicit pass.
- Evaluator-owned admission, applicability, reduction, and receipt assembly stay
  deterministic and non-authorizing.
- Integrated command/event lifecycle has one ACI-owned writer and canonical
  acceptance identity.
- Semantic receipt content crosses ACI only by finalized artifact ref/digest.
- Work Bus acceptance and evaluator observation admission remain separate.
- Exact-effect gate follows the persisted semantic receipt, binds one identical
  envelope, and emits at most candidate ACI command input.
- Historical replay folds verified ACI facts plus semantic artifacts with no
  mutable calls; current revalidation is a new ACI command/run.
- Local-only evidence stays explicitly non-integrated and cannot invent or reuse
  ACI identity.
- APT remains a rebuildable projection and never owns lifecycle mutation.
- Layer promotion cites previous-layer evidence; preference is insufficient.
