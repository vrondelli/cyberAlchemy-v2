LongMemEval cohort. It scored 11/16 with 16 valid judgments against control's
2/16 with 14 valid judgments, using 29,787 versus 2,229,566 all-in tokens.
Even assigning both invalid control judgments as correct leaves control at
4/16. Summed arm-plus-judge time fell 97.585%; campaign wall time is reported

priority is G01/G02 comparative work, not another replay of these questions.

## Fixed Candidate-Only Envelope

- Model: GLM-5.3-Flash, low reasoning.
- Context admission: strict 8K projected request window.
- Budget: 96K model tokens and 96 calls per task; 384K campaign ceiling.
- Cohort: four fixed exposed ContextBench tasks until a candidate qualifies for
  separately frozen untouched confirmation.
- Concurrency: at most two shared model workers.
- No fresh controls during screening; no automatic retries, task replacement or
  hidden failed costs. Fresh matched controls are required for confirmation.
- Native quality, completion, exact accounting and evidence acquisition are
  reported for every assignment.

The original goals—perfect native quality, at least 15% fewer cumulative model
tokens, improved elapsed time and untouched confirmation—remain open. These are
tested on a promoted candidate's fresh matched comparison, not inferred from a
candidate-only screen.
