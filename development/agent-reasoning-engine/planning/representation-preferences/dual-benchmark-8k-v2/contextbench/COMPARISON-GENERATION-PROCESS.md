# Comparison generation process

Status: ten offline tests pass; independent review pending. No live provider dispatch.

`comparison-generation-process.mjs` reuses the existing Linux process-group supervisor with the new dedicated `comparison-generation-worker.mjs`. The worker receives a bounded JSON request, constructs guarded storage and invokes the R2 twelve-slot campaign runner. SIGTERM/SIGINT abort its shared controller. Successful and failed terminal evidence is serialized before explicit child exit; the parent retains process-close and group-absence evidence. Settlement claims concern local processes only, never remote provider completion.

`comparison-generation-storage.mjs` binds source preparation to all twelve schedule slots and their exact task/cache/base identities. Three fresh, disjoint evidence roots receive guarded writers: 32 MiB outcomes, 128 MiB runs and 32 MiB metadata. Source admission checks reject usage above 2 GiB/150,000 entries, symlinks or unassigned top-level names. These are periodic checks, not a write-enforced filesystem quota: a Git clone or native tool write can overshoot between checks. Evidence writers, by contrast, reserve allocation before each write. The source root starts absent; its parent must be canonical. Admission reserves combined remaining growth against D:/WSL for every root. Every model dispatch and source preparation phase rechecks storage; a capacity or integrity failure permanently stops this storage instance. C: is excluded by the reused host guard.

Six actual subprocess tests verify child closure before return, failure terminal retention, cancellation, stdout bounds, native-descendant settlement and the real comparison worker's pre-dispatch rejection of a malformed request. Four storage tests use a synthetic host-admission callback to verify all twelve assignments, quota reservations, guarded persistence, permanent stopping, root overlap, wrong assignment, unexpected source entries and symlinks. These tests do not run a successful production worker campaign or certify live storage capacity.
