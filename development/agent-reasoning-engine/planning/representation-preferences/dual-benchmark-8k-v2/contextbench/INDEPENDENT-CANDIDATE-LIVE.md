# Independent-investigation candidate live protocol

This is the candidate-only successor to the completed current-ARE run. Use the
same four exposed tasks, GLM 5.3 Flash, low reasoning, measured 8K requests,
96K cumulative model tokens and 96 calls per task, with two workers and a 384K
campaign ceiling. No fresh controls are scheduled. The existing retained
independent-investigation runtime and source tools are unchanged.

The model plans three task-derived questions. Each investigation sees its own
question and latest complete exchange; durable evidence remains receipt-bound.
Planning is limited to 4K tokens / 2 calls, each investigation to 24K / 24 calls,
and the join to 20K / 22 calls with at least 8K for finalization. No transfers,
retries or replacement tasks. All failures and unknown usage remain accounted.
This candidate does not implement the distinct query-driven external archive.

The tested candidate-only execution, outcome seals, ledger reconciliation and
native scoring are reused. Only the exact production binding changes from
current-ARE to independent investigations, including its declared schedule and
native research records. The current-ARE freeze and outcomes are untouched.

The source closure includes ESM imports, runtime schemas, CommonJS package trees
and declared dependencies, tasks, credential reference configuration, evaluator
sources, native hypotheses and reviewed integration. Qualification runs with
model dispatch disabled, binds initial tokenizer receipts and settles its child.
An independent launch review must bind the exact freeze and qualification hashes
before model generation. Subsequent requests retain measured admission.

Storage remains 256 MiB for run artifacts, 64 MiB outcomes, 32 MiB metadata,
2 GiB source ceiling and the existing 2 GiB + 416 MiB total growth reservation.
D:/WSL checks remain mandatory; C: is excluded. Source and evidence roots are
fresh and separate. Generation and native scoring use supervised children.
The completed current-ARE run is historical reference, not a fresh control.

With NODE_OPTIONS=--experimental-vm-modules inherited by children:

1. `node prepare-independent-candidate-production.mjs` builds the exact freeze.
2. `node run-independent-candidate-production.mjs qualify MANIFEST SHA256`
   runs tokenizer-only first-request qualification.
3. Independently review sources, native experiment, qualification and capacity.
4. `node run-independent-candidate-production.mjs run MANIFEST SHA256 REVIEW`
   runs four tasks and isolated native scoring, without resume or overwrite.

Report every task's span/file quality, confirmed acquisition versus selection,
model tokens and validity. Perfect valid quality may pass the candidate-quality
criterion only. Matched savings remain null; untouched confirmation and full
benchmark/generalization evidence remain required. No predeclared success.
