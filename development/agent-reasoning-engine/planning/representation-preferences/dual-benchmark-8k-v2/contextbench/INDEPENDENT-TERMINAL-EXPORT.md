# Independent terminal selection and export

Additive offline adapter; no generation admission. Parent objective and limits: [INDEPENDENT-INVESTIGATION-CONTRACT.md](INDEPENDENT-INVESTIGATION-CONTRACT.md). Open questions below own integration residue.

`buildIndependentTerminalEvidence` reconstructs the verified branch-local delivery join, then uses the unchanged expanded terminal packet builder and source projector. It preserves native observation IDs even when tool-call IDs collide across conversations. Only the packet's model view belongs in a provider request.

`exportIndependentTerminalSelection` reconstructs that join again and checks its entire receipt prefix against the arm's current receipt list. The separate join-phase captures must bind every subsequent successful, known-cost model request. The exact terminal response must be hash-bound to its receipt, be the last dispatched model response, and contain one expanded terminal submission. The exact packet text and tool schema must occur in its captured request. The unchanged packet decoder validates structure and selected handles.

Every offered binding is checked against actual branch-delivered observation metadata and current native base-source projection. The unchanged source-selection validator then accepts only explicitly selected delivered IDs. The adapter calls the unchanged native trajectory exporter with projected events and those selected event IDs. It never substitutes the archive union. Empty final selection remains an explicit unscorable outcome, consistent with the existing exporter.

This version permits selection-only join conversations. Additional source observations inside join captures are rejected as unregistered. If a later design needs join-time source discovery, it must add a separately receipt-bound source phase rather than silently including it. Unassigned earlier planner/index receipts remain owned by the phase/transport accounting layer; this adapter is not the full-arm validity or cost gate.

Three offline integration groups exercise real-format two-branch capture/receipt envelopes with reused tool-call IDs, source projection and native trajectory export. They prove selection of one file does not silently include the other, and test all-file selection, forged joins, response drift, unknown handles, nonterminal responses, empty selection, packet substitution, receipt-prefix drift and source-file mutation. Fixture tokenizer counts only size synthetic prompts; they are not provider measurements or an8K qualification result.

## Open questions

Bind actual phase-ledger assignments to branch receipt indices and construct protocol-valid isolated histories. Deliver and account for investigator findings and the final packet through the native transport. Implement the common minimal-history baseline and shared supervision; qualify exact request shapes and output reservations with the real tokenizer. Independent runtime review, complete accounting, exact freeze and native benchmark scoring remain required before success can be claimed.
