# Receipt-based token diagnosis

The prior ContextBench treatment used 567,202 tokens against 626,119 control tokens:
9.41% savings. Reaching the unchanged 15% target at that observed control total
requires treatment at or below 532,201 tokens, another 35,001 tokens saved (6.17%
of the current treatment cost).

| Observed cost | Control | Treatment |
| --- | ---: | ---: |
| Model calls | 233 | 201 |
| Input tokens | 599,538 | 544,208 |
| Output tokens, including reasoning | 26,581 | 22,994 |
| Reasoning output subset | 8,739 | 8,073 |
| Total | 626,119 | 567,202 |
| Last call in every assigned outcome | 22,089 | 28,811 |

Input accounts for 95.95% of treatment cost. The receipts do not split those input
tokens into source bodies, repeated history, schemas and framing, so no exact
attribution to one component is warranted.

Even the impossible intervention of removing every last treatment call entirely
would save only 28,811 tokens, less than the additional 35,001 needed. Terminal
recovery should therefore be evaluated as a completion mechanism. It cannot alone
establish the whole-task token target for these fixed trajectories. Removing last
calls would also remove predictions; this arithmetic is a ceiling illustration,
not a proposed successful treatment.

The next efficiency hypothesis must address earlier repeated input or unnecessary
exploration. Test that mechanism separately from terminal recovery. Retain all
failed calls and compare complete trajectories; reducing per-call cost can merely
buy more calls until the same budget stop.

Evidence: [TOKEN-ANALYSIS.json](TOKEN-ANALYSIS.json), generated by
[token-analysis.mjs](token-analysis.mjs). Every assigned receipt sum matches the
sealed amended results. This analysis made no provider calls and read no gold.

## Open questions

Which repeated input can be omitted while preserving correct decisions? When can
an earlier stop preserve coverage? Does explicit retained evidence reduce recovery
calls enough to offset its own presentation cost? Provider-token measurements and
matched live ablations are needed to answer these questions.
