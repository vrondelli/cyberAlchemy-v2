# Current ARE with shared lossless tool encoding

This additive dependency set carries the shared renderer and receipt-first decoder through the current ARE recovery episode, archive/recovery controllers, evidence index, terminal selection and native export. It does not alter the frozen production runner.

DERIVATION.json binds fifteen original sources and their derived files. Static relative imports are rebased; mapped consumers select this exact local set. delivery.mjs re-exports unchanged delivery helpers and explicitly substitutes only bindDelivery with the reviewed compact decoder. Original files and prior experimental evidence remain unchanged.

Two episode rendering sites apply renderCompactPrompt before capture and native measurement. The remaining correction-only render contains no tool results. Assistant message bytes, including retained reasoning, are not transformed. The original concise system instructions and tool descriptions are retained through representation.mjs.

There is an explicit difference from the earlier current-ARE presentation: it previously removed byte_count, base_commit and redundant retrieval_handle fields. The new presentation retains raw tool fields until the shared lossless codec runs, then factors their repeated metadata. This is necessary for exact reversible decoding and is part of the prospective common-codec treatment. Its complete input overhead must be measured; prior control scores do not transfer to this implementation. There are no phase-budget, model-retry, recovery-policy or acceptance-criterion changes.
