## Code findings

No demonstrated ranking or provenance defect in the tested validated-input contract. The candidate produces a deterministic full permutation, isolates coverage by path and pinned-base hash, preserves native read identities, and keeps private ranking audit out of the public model packet. Inherited tests cover edited-source exclusion, exact receipt-bound export, source mutation, malformed selection, expanded fourth-handle availability, legacy public-byte compatibility, and diversity native export. These are useful unit invariants, not proof of all eight real donor reconstructions.

The intervention is ranking **before bounded prefix selection**: it can change packet membership, not merely reorder a fixed public set. Label the comparison accordingly. Legacy already has a distinct-path first pass. Diversity's lexicographic score gives preferred evidence and uncovered lexical terms priority over path novelty; it does not promise distinct-file coverage. Novel-line fraction precedes absolute width and can prefer a narrow entirely novel read to a wider partially overlapping read. These are declared hypotheses and plausible distractor risks, not implementation bugs. Line novelty is not native byte-span quality.

`schemaFor` derives enum and maxItems from fitted handle count. Equal configured maxima do **not** guarantee equal actual schemas: different path/span text lengths can make fitting retain different counts. The synthetic equal-schema test does not establish equality for archived donors. This is a live prerequisite: either both independently fitted packets have exactly equal schemas, or use a predeclared common count and rebuild both. Recommended deterministic backoff starts at min(32, eligible count), reduces the common count until both state and full request fits pass, and never changes nonpacket messages. Record the common reduction. Because this affects the legacy packet too, bind the rule into the prospective protocol before freeze. Reject both slots if no nonempty common fit exists; preserve their denominator.

## Accounting, protocol and decision

The PLAN appropriately treats eight donor archives as four tasks under two prior policies, not eight independent tasks; fresh legacy calls avoid treating stale answers as fresh controls. Alternate AB/BA by fixed donor index, two workers total, one repetition, 16 slots and at most128000 newly reserved model tokens. Failed/unknown calls retain conservative reservations. Tokenizer measurements remain separately reported and are not silently called model generation usage.

For donor i, let P_i be all known input+output model costs before its excluded old terminal call, C_i/T_i the new terminal costs. Logical paired totals are sum(P_i+C_i) and sum(P_i+T_i). Historical reused expenditure is sum(P_i) once; new physical expenditure is sum(C_i+T_i), including every failed attempt. The original old terminal expenditure remains in the original experiment ledger but is outside this component's shared prefix. Report all three categories explicitly. Even improved component costs cannot establish fresh whole-trajectory savings or be combined with the old12.64% result to claim the campaign goal.

The component support gate is fair and deliberately bounded: all16 valid/accounted, per-donor offered-coverage nonregression plus one strict improvement, macro native span/file F1 nonregression. Define offered coverage explicitly as the existing native gold-byte recall aggregate before freeze; if file offered recall is also a gate, name it separately. Unknown usage/infrastructure failures make execution inconclusive; they are not scientific proof of H0, despite the broad H1 falsifier wording in the hypothesis record. Perfect terminal quality is not a reasonable component gate on an archive that cannot supply missing sources. Later full-run treatment perfection, complete control/treatment outcomes, per-benchmark15% cumulative savings, and untouched confirmation remain unchanged.
