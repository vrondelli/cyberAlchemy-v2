## Fixed decision rule

All eight exposed donor archives receive both fresh variants:16 fixed slots, one repetition, alternating variant order, two workers and at most128,000 new generation tokens. Each model request uses actual native admission at most8,000 tokens with2,048 reserved output. Preserve native stricter recycle threshold. No retries, replacement donors, dropped failures, gold in generation or extra exploratory calls.

Keep32handles maximum,8,192 packet bytes,2,048 packet-text tokens, matched actual handle counts and identical tool schemas. Change only validated candidate ordering; retain the same archived evidence, other messages, source projection, provider profile and prefix receipts within each pair. The run wrapper verifies all source bindings and preparation hashes before dispatch; shared storage/provider/unknown/lifecycle/persistence failures stop future work and retain all slot outcomes.

Support requires16valid/accounted outcomes, no per-donor offered gold-byte coverage regression, strict improvement for at least one donor and nondecreasing macro native Span-F1 and file-F1. Infrastructure/unknown/reconstruction gaps yield inconclusive evidence. Otherwise report counterevidence. Score only after global generation seal; evaluator-only gold-byte coverage never returns paths or hints to candidate generation.

Report actual new model spend separately from the already consumed prefix. Include each donor's historical prefix in both logical candidate costs but only once in physical historical expenditure. No combining this component with the predecessor12.64% saving as a new full-run result. The campaign's perfect quality and15% per-benchmark gates remain unresolved.
