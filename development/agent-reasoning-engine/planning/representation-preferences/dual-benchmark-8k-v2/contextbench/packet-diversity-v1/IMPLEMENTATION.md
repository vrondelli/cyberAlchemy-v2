Status: bounded implementation and29 offline tests passed; no model, network, scoring, or gold access. Actual source restoration and tokenizer preflight are not claimed. `OFFLINE-PREPARATION.json` binds all eight verified archived boundaries and current implementation hashes. Parent controls continuity, independent review, freeze and live authorization.

## Preparation API

`fixedDonors(config)` fixes four tasks × original control/treatment in config order, indices0..7. `loadDonor({config, discovery_root, task_id, donor_arm})` verifies task/result/terminal receipt/ledger bindings, reads source snapshots and preterminal captures, and excludes the old terminal receipt/output. It checks completed-result hashing, native receipt binding, unique terminal wire, prefix known usage, and retained reasoning evidence. It binds the old config and freeze files but does not independently reverify every original freeze entry; that remains the coordinator's existing freeze gate.

`restoreVerifiedBase({donor, directory, storage_guard, maximum_bytes=33554432})` reads only required pinned Git blobs, with lazy fetching disabled, no checkout or clone. It rejects missing objects, symlinks/nonregular blobs, unsafe paths, and excess bytes before creating the destination. It verifies commit, blob SHA1, content SHA256 and UTF8. The fresh minimal tree is sufficient for native source-map projection, whose filesystem requirements do not include `.git`. Never point this API at a preexisting directory; cleanup is coordinator-owned after validation/scoring. Synthetic restoration proved that edited cache working files do not affect recovered pinned content. Actual retained repositories still need this step.

`preparePackets({donor, repoRoot, measure_tokens, measure_wire})` first requires exact legacy public reconstruction, then calls the shared-cardinality `buildPairedPackets`. The state tokenizer callback accepts text and returns real measured tokens. The wire callback accepts `{variant,prompt}` and returns full projected input-plus-output reservation. If either arm fails the preserved native recycle threshold, both rebuild with one fewer shared handle; no nonpacket history can change. A zero-handle failure remains explicit. Returned `{admitted,pair,prompts,attempts,bounds,donor_id,prefix_receipts_sha256}` is private evidence; only prompt strings go to the model.

## Native request API

`runNativeRequest({donor,prompt,directory,repoRoot,create_client,storage_guard,before_model_dispatch,model_dispatch_enabled=false,signal,variant='legacy'})` uses the actual native GLM transport and registered recycler. Caller supplies `create_client({cell,task})` from the existing live factory; it reads no credentials on import. The donor's exact started-cell profile is used, including96 native maximum calls,2048 output,512 margin, low effort and no retries. Native transport identity must match the archive.

A new recycler obtains its real writer lock. `derivePrefixLedger` imports byte-identical historical prefix receipts with matching native identity and recomputed historical counters/digest under the new scope binding. Native `bindRunLedger` loads that explicit derived continuation. `prefix-derivation.json` states its provenance and counterfactual status. Only receipts beyond the imported prefix index count as new costs. This avoids mutating the public receipt array without private native counters. Private retained-reasoning evidence remains available, while historical calls are not new expenditure.

The runner makes one generate invocation over empty recycler history and a fixed render function. Consequently oversized prompts fail fresh admission instead of recycling archived nonpacket messages. It retains the donor's `<7000` native recycle threshold within its8000 context limit; the explicit dispatch check also requires input plus2048 reserve ≤8000. This is stricter than the headline maximum and identical in both variants. Actual dispatch passes storage/shared-health checks at the native admission seam. There are no retries or correction calls. Timing covers local request lifetime only.

`measureNativeWire(options)` forces model dispatch disabled, uses a fresh owned state directory and the same native transport measurement path, and returns `{projected_upper_bound,result}`. Even an oversized request can supply its successful tokenizer receipt for shared backoff. It asserts zero model attempts. Each call needs a unique directory. The coordinator can implement the `measure_wire` callback with this method; it necessarily requires separately authorized tokenizer network access, which was not exercised here.

`runSlot({donor,prepared,variant,directory,repoRoot,...nativeOptions})` validates packet integrity and exact nonpacket identity, invokes one native request, then independently calls the current expanded packet's native receipt-bound exporter. Its `result.json` preserves source selection, current packet, captures, suffix and prefix usage separately; malformed/empty selection remains visible. The request receipt ledger is durable in native state. Known costs survive persistence exceptions through attached result/receipt fields; unknown costs retain conservative8000 reservation. No scorer is imported.

`runPairs({jobs,execute_slot,health,model_dispatch_enabled=false})` takes exactly eight ordered donor jobs, uses two workers, alternates legacy/diversity order by donor index, and retains16 slots including health-stopped slots. The callback must route each variant to its own new directory when calling `runSlot`; it receives the shared `before_model_dispatch` guard. Pair reports contain physical new usage, historical prefix once, and both logical prefix-plus-suffix totals. The coordinator must persist the global generation seal before isolated native scoring. A frozen wrapper must bind jobs, directories and create_client/storage callbacks; there is deliberately no automatically executable live CLI here.
