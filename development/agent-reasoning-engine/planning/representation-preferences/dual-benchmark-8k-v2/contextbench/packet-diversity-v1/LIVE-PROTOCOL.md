Each model request uses actual native admission at most8,000 tokens with2,048 reserved output. Preserve native stricter recycle threshold. No retries, replacement donors, dropped failures, gold in generation or extra exploratory calls.

Change only validated candidate ordering; retain the same archived evidence, other messages, source projection, provider profile and prefix receipts within each pair. The run wrapper verifies all source bindings and preparation hashes before dispatch; shared storage/provider/unknown/lifecycle/persistence failures stop future work and retain all slot outcomes.
