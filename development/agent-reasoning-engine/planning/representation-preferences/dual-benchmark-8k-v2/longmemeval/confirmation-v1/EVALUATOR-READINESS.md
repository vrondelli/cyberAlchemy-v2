## Sealed scoring contract

The evaluator requires `seal.schema === 'are.full-s-generation-seal/v1'`, `terminal`, `source_integrity_verified`, and `transport_settled` all true, plus the complete four-pair/eight-answer generation result. Unknown usage, held reservations, missing identities, nonterminal answer states, changed answer hashes or pair persistence failures prevent new judge calls.

A separate evaluator freeze must bind schema `are.full-s-evaluator-freeze/v1`, `approved:true`, exact `reference_binding_sha256`, `generation_seal_sha256`, `evaluator_sha256`, `rubric_sha256`, `maximum_judge_calls:8`, `maximum_judge_tokens:64000`, `context_limit:8000` and a finite positive `tokenizer_timeout_ms`. Broader source/dependency/transport review and native governance gates remain the caller’s responsibility; a plain JSON approval is not independent authority.

All eight slots stay in the denominator. Every completed answer gets one blinded native-rubric request; failed/blocked generation slots are retained unjudged, never replaced with fabricated answers. The judge sees question/reference/response under the same unchanged `get_anscheck_prompt` used by the parent scorer, including the native abstention-ID behavior. It receives no arm label or token/cost/performance data. An opaque deterministic hash order prevents control-first presentation. The same model rubric is the declared score, not independent truth proof.

Each actual judge wire is freshly tokenized and must fit input at most 6,976 plus 1,024 reserved output within 8,000. Calls are sequential, at most eight, with no retries. The separate judge ceiling is 64,000; it is not charged as generation-token savings. Known failed model costs and completion/reasoning tokens remain counted; reasoning is not added twice. Unknown model cost holds 8,000 tokens and stops subsequent judges. Capacity and journal/provider persistence failures also stop calls. Invalid judgments retain cost but never count correct. Positive observed cost wins over a contradictory no-dispatch flag. Final journal failure attaches the complete in-memory result and known aggregate usage only if no model cost is unknown.

Injected `meter`, `generate`, and `record` callbacks use the same exact-wire receipt convention as the generation core. The production provider must keep any raw judge prompt/receipt files in a separate private evaluator output, honor cancellation and bounded drain, preserve all usage, and never copy those files into generator inputs or model-visible root logs. The public scoring result exposes hashes, yes/no-derived correctness, counts and numeric usage only.
