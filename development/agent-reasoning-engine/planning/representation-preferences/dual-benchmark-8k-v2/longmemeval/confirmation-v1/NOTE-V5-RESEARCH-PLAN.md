## Fixed decision rule

Keep all four IDs and eight answer slots, including failures. Require all eight answers and valid judgments, all four treatment answers correct, no quality regression, every actual request within8K, all generation/judge usage known and allocated, and at least15% token reduction including ingestion, note carry, final answers and judging. Reasoning and cached input remain in parent totals. No retries, replacement tasks, source omissions, outcome-tuned retrieval or automatic compaction. Unknown usage, incomplete comparison or infrastructure failure is inconclusive. A valid complete comparison that fails quality or savings is counterevidence. Both outcomes retain all costs.

A successful development result leads to broader untouched confirmation and separate ContextBench clearance, not campaign completion. Two-worker execution precedes measured four-worker stages. Shared cross-benchmark supervision remains a separate prerequisite for simultaneous dispatch.
