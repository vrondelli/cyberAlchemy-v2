# Bounded pilot completion audit

Objective: execute the parallel pilot until there are clear results. This audit
checks the original [PLAN.md](../PLAN.md), its frozen experiment successors and the final
evidence. It does not redefine success as a positive ARE result, an official
benchmark score, or completion of the separate GLM/ContextBench qualification.

The plan explicitly permits each branch to join as completed, valid-failed,
inconclusive or blocked with evidence. Consequently the PersonaMem blocked outcome
can close this pilot's branch disposition; it cannot be counted as a quality result.
No new PersonaMem experiment is required merely to erase an inconvenient blocker.

## Verification performed

`node .../execution/audit-results.mjs --check` recomputes category and paired counts,
application denominators and provider usage. It verifies 62 distinct model attempts
across the amended LongMemEval protocol, no repeated completed generations, and
152,973 known whole-branch tokens including its stopped predecessor. It preserves
unknown usage rather than substituting zero.

`node .../execution/work-tracking/project-dag-v2.mjs --check` verifies actual native
records, exact evidence files, frozen implementation/amendment sources, graph edges
and native work-state replay. It does not transform the stopped raw run into a clean
completed experiment. The independent audit is in
[INDEPENDENT-COMPLETION-AUDIT.md](INDEPENDENT-COMPLETION-AUDIT.md); its finite reporting
and integration findings are addressed by the artifacts linked above.

## Closure and open questions

The bounded pilot has clear, reviewed outcomes for every planned branch disposition.
It demonstrates no useful improvement from the tested configurations. It does not
prove that ARE cannot help memory in general, qualify GLM, clear ContextBench,
score PersonaMem, establish exact whole-episode spend, or approve a release.

Future work is owned by the recorded successor questions: exact evidence recovery,
note omission versus reasoning errors, preference override precedence, and a feasible
PersonaMem protocol. These require new reviewed experiment choices; they are not
unreported unfinished parts of an allegedly successful benchmark run.
