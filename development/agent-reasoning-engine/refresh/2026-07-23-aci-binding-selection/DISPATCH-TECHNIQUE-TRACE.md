# Dispatch technique trace — ACI binding selection sync

| Technique | Effect |
|---|---|
| `sequence` | Decision receipt precedes staged Invoke outputs, then Craft projection and validation. |
| `concrete_path_evidence` | Every status delta cites the exact decision receipt and target path. |
| `approval_semantics_map` | The user's A selection applies to `G-ARE-ACI-BINDING`, not implementation. |
| `owner_boundary_check` | Invoke and Craft receive separate material packages. |
| `state_namespace_boundary` | Private local state, external evidence, public Arcanum, and implementation remain separate. |
| `artifact_contract_bridge` | Decision evidence is translated into exact staged artifact changes. |
| `residue_ledger` | External maturity, glossary, durability, incident, rollout, intent, and anti-bias gaps remain visible. |
| `validation_loop` | Package, receipt, JSON/YAML, projection, links, claim, and whitespace checks gate apply. |
| `execution_receipt_handoff` | The refresh emits an owner receipt without selecting executable work. |

Subagents: `none`; this is one deterministic local synchronization over a
human-selected option.
