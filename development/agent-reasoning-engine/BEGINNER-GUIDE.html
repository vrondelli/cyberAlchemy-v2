01 · Research-dispatch bridge

Where does reasoning begin?

Orchestration governs launch and lifecycle. Reasoning asks what follows from the information supplied for a domain decision.

A well-authorized dispatch can still reach a weak, contradicted, or incomplete conclusion. The shared pattern is deliberate boundaries and fail-closed behavior; the responsibilities are not shared.

Launch authorization

May this agent work start?

Cannot prove its domain conclusion.

Route advice

Which fixed route appears to fit?

Cannot select or launch an agent.

Semantic recommendation

What follows from these facts and rules?

Cannot permit a real action.

Effect permission

May this one exact action happen?

Cannot grant wider authority.

Use a concrete research question: Can the Agent Reasoning Engine use ACI-owned journal facts without becoming a second lifecycle writer?

That question crosses source ownership, lifecycle recording, reasoning input, and evidence. If it needs several source sets, independent viewpoints, or parallel work, domainspec-subagents-strategy treats it as a research-dispatch candidate. The strategy governs how the research is admitted and run. It does not decide whether the eventual finding is true.

03 · Semantic gap

What remains after a correct dispatch?

Correctly authorizing and recording a refund-review run does not decide whether the customer is eligible for a refund.

The evaluator still needs the policy rules and relevant observations fixed for that one review. The project calls these inputs a reasoning snapshot.

That snapshot is similar to the exact inputs and digests your ACI bridge binds before launch: it makes one decision traceable. It differs in owner and job. It is not an ACI event, ledger row, projection, or launch authorization.

04 · Evaluator

How does semantic evaluation work?

The order is save entry decision → evaluate fixed inputs → save reasoning → stop unless recommended → check one exact test effect.

05 · Resolver

How does route advice differ?

The resolver compares a prepared request with an owner-supplied route list. It preserves missing information instead of guessing.

no-matchThe request is complete, but no route fits

This may feel like a deterministic pre-filter in the orchestrator. The shared pattern is comparison against a fixed contract. The difference is ownership: this package owns neither the orchestrator catalog nor dispatch authority.

It does not understand free-form language, discover capabilities, approve work, launch an agent, or execute an effect. Every result carries authority_effect: none.

Trace cases.json, then read src/request.mjs, src/catalog.mjs, src/eligibility.mjs, and resolveIntentRoute.

06 · ACI boundary

How could the projects relate?

The accepted direction is ACI-subordinate: consume ACI-owned lifecycle facts instead of creating another writer for them.

Your orchestrator already owns its Session, journal, capability, and dispatch lifecycle contracts. Semantic derivation and reasoning-receipt content remain reasoning-engine responsibilities.

That is a design boundary, not compatibility evidence.

09 · Contribution boundary

When is it safe to edit?

Reading, tests, and fixture traces are open. Editing needs one selected task, an agreed file boundary, and named review checks.

Available now

  • Read current source
  • Run both suites
  • Trace fixtures
  • Surface stale or conflicting documentation

Not currently selected

  • Product mutation
  • A new integration seam
  • A next SWU
  • Hand-edited generated receipts

The lifecycle ledger and its human view still say to author the ACI-subordinate plan revision. The newer work pack says that revision is already authored, while also saying selected_swu: none and implementation_authorized: false. It adds a closeout-sync blocker absent from the ledger.

Do not pick the newest sentence and proceed. Green tests do not select an SWU. Ask the lifecycle owner to synchronize the sources and name the exact task before mutation.

Do not hand-edit generated run receipts. A changed implementation needs newly owned evidence, not altered history.
