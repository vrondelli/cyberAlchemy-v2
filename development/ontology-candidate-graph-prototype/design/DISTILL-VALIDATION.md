# Distill Validation

Mode: Standard
Rounds: 2
Status: pass-for-design

## Target Unit

One ontology-oriented candidate-graph evaluation:

```text
immutable finite fixture + pinned policy
  -> closed-world validation
  -> disposition + research-lineage projection
  -> isolated, digest-bound run receipt
```

## Round 1: Role Tension

| Role | Pressure | Result |
| --- | --- | --- |
| Ontology boundary keeper | Prevent candidate execution from becoming canonical meaning | Retain candidate-only carrier and explicit non-authority edges |
| Implementer | Minimize machinery | Use local JSON, pure functions, CLI, and create-only run directory |
| Falsifier | Require a case that catches wrong composition | Preserve cycle, inverse, session-claim, and contradiction non-composition cases |
| Evidence auditor | Separate declarations from observed proof | Bind fixtures, evaluator, outputs, projection, and isolation in a later receipt |
| Human reviewer | Make the result inspectable | Derive one static report from canonical JSON; do not add UI state |

## Round 2: Coherence

The unit cannot be reduced to a generic schema validator because endpoint law,
grounding acyclicity, contradiction non-composition, and policy-indeterminate
semantics would disappear. It cannot be reduced to the IOLM viewer because the
ontology source binding and policy evidence would disappear. It does not need
Ponder, learned scoring, hierarchy induction, promotion, a database, or a live
browser application.

## Recomposition Proof

The run contract can later feed:

- a repaired IOLM product adapter;
- broader relation policies with their own owners and fixtures;
- a separately governed promotion request.

Recomposition fails closed if a consumer treats the projection as canonical,
changes a disposition, omits source digests, or writes back to governed input.

## Residue

| Residue | Owner / next route |
| --- | --- |
| Exact implementation language and package location | future Invoke Plan |
| Enacted prototype schemas and diagnostic registry | ontology edge-law owner plus definitions review where load-bearing |
| Human browser acceptance | future IOLM/product acceptance owner |
| `specializes` meaning | future named semantic policy owner |
| Promotion or bounded-prototype label | ontology/parent owner after current runtime evidence |

## Verdict

The design unit is the smallest coherent slice that still tests structure,
policy, projection, evidence, and authority separation. Distill validates the
design shape only; it supplies no runtime proof.
