# Glossary

| Term | Local meaning | Must not collapse into |
| --- | --- | --- |
| ontology-oriented candidate-graph prototype | Finite executable slice aligned to ontology contracts | canonical ontology or full bounded ontology prototype |
| candidate-only carrier | Prototype-local record shape for fixtures | enacted authority or vault schema |
| named policy | Versioned finite rule set with owner and digest | semantic truth |
| policy-pass | Declared policy found no violation | accepted, admitted, promoted, or true |
| policy-fail | Declared policy found a violation | owner rejection or false in every ontology |
| policy-indeterminate | Declared policy lacks a rule or owner | permission, pass, or semantic ambiguity hidden as success |
| candidate projection/read model | Pure inspectable derivation from run evidence | canonical ontology |
| fixture | Immutable declared test input and expectation | observed run receipt |
| receipt | Immutable binding of one observed run | fixture, verdict authority, or promotion record |
| isolation attestation | Evidence that governed inputs were unchanged and writes were denied | a declarative `authority_effect: none` field |
| human acceptance | Separately named inspection/usability evidence | machine validation or authority approval |
