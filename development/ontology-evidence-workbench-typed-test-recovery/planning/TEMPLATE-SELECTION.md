# Plan Template Selection

- `arcanum/spells/invoke/templates/implementation-layering.md`: required for
  L0-L3 decision boundaries.
- `arcanum/spells/invoke/templates/work-pack.md`: canonical executable plan.
- `arcanum/spells/invoke/templates/domainspec-spec/execution-pack.md`: required
  because the package is medium complexity and split into waves/tasks/SWUs.
- Output mode: split.
- Eligibility: more than five implementation SWUs, multiple owned artifacts,
  dependency-ordered writes, and acceptance-critical failure paths.
- No tie: the low-complexity single-file profile is ineligible.
