# Implementation Layering — Ontology Evidence Workbench

## Boundary Heuristic

`Layer value = decision unlocked + user-visible outcome + risk reduced`

`Layer cost = implementation time + verification time + coordination burden`

Each layer stops when the next concern has an independently falsifiable
decision and belongs in the next evidence boundary.

## L0 — Verified Native-Viewer Proof

**After this layer, we know whether one independently verified candidate run can
be projected deterministically and explored through an unmodified pinned
Understand-Anything viewer without losing exact evidence recoverability.**

- Minimum working unit: source admission → loss-aware adapter → immutable
  adapter receipt → pinned native viewer → Poker smoke walkthrough.
- Included: SWU-OEW-001 through 006.
- User-visible outcome: interactive Poker graph in the native viewer.
- Risk reduced: wrong source, semantic collapse, floating upstream, nondeterminism,
  unsafe local serving.
- Deferred: custom trust-aware UI, code analysis, large graphs, manual UX.
- Exit evidence: verified/tampered fixtures, total mapping, double-build
  equality, upstream lock/build receipt, HTTP negatives, Poker smoke.
- Promotion decision: proceed only if the exact sidecar can recover every
  generalized relation and protected sources remain unchanged.

## L1 — Trust-Aware Evidence Workbench

**After this layer, we know whether a reviewer can inspect exact evidence,
conflict, uncertainty, and receipts through a coherent accessible interface.**

- Minimum working unit: completed private toolchain/materializer and exact
  store evidence, followed by one coherent Poker evidence-review UI source
  unit, a final independently verified build, browser production, and
  independent browser acceptance.
- Completed foundation: SWU-OEW-006P and SWU-OEW-007.
- Remaining candidate frontier: SWU-OEW-008F, SWU-OEW-013B, SWU-OEW-014,
  and SWU-OEW-014V. Historical blocked 006B/008 and superseded unexecuted
  009–013 remain evidence but are not candidates.
- User-visible outcome: the proposed Evidence Constellation interface.
- Risk reduced: generalized semantics mistaken for source truth, graph-only
  navigation, hidden receipt state, responsive/keyboard failures.
- Deferred: code context, scale, packaging, manual accessibility/usability.
- Exit evidence: exact Node/pnpm and effective lock, self-owned provisioning
  patch proof, preselection command/runner ownership closure, final overlay
  pre/postimages, typed tests/build, immutable build handle, cleanup/residue
  verification, exact-relation UI assertions, three-view parity, Poker tour,
  keyboard/axe/browser producer receipt, distinct verifier receipt, and
  protected-scope equality.
- Promotion decision: proceed only if critical evidence is equivalent across
  graph/outline/table and automated status does not overclaim manual UX.

## L2 — Scoped Code Context

**After this layer, we know whether Understand-Anything code analysis can add
implementation navigation without changing evidence, grounding, or authority
state.**

- Included: SWU-OEW-015 through 017.
- User-visible outcome: an explicitly labeled code-context lane linked by
  reviewed mappings.
- Risk reduced: private-scope overreach, implicit AI linkage, evidence/code
  namespace collapse.
- Deferred: whole-repository analysis, automatic link inference, IOLM runtime
  adoption.
- Exit evidence: approved scope receipt, code graph digest, mapping validator,
  evidence non-interference oracle.
- Promotion decision: code lane is optional and removable; evidence-only mode
  must remain byte/state equivalent.

## L3 — Maintenance, Scale, and Packaging

**After this layer, we know whether the prototype can be reproduced, upgraded,
measured, and handed to named local reviewers without weakening earlier
guarantees.**

- Included: SWU-OEW-018 through 020 plus closure-only verification.
- User-visible outcome: packaged local viewer and bounded pilot instructions.
- Risk reduced: upstream drift, large-graph regressions, unrepeatable setup,
  inflated accessibility/usability claims.
- Deferred: multi-user service, public release, production, automatic
  promotion, shared IOLM host.
- Exit evidence: update replay, performance thresholds, packaged artifact
  digest, automated browser matrix, named manual results or honest `NOT_RUN`.
- Promotion decision: any release/publication/production route requires a new
  owner decision and plan.

## Non-Regression Guarantees

Every later layer preserves:

- terminal receipt admission before serving;
- exact relation recovery from the sidecar;
- `authority_effect: none`;
- deterministic adapter bytes;
- read-only Poker/IOLM/authority/Craft/Arcanum sources;
- evidence-only mode;
- no outbound runtime calls;
- no implicit SWU selection or lifecycle promotion.
