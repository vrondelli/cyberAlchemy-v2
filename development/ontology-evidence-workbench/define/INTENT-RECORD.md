# Intent Record

Date: 2026-07-27
Lifecycle approval: the user explicitly invoked Define, Design, and Plan
Implementation approval: **not granted**

## Approved Intent

Define, design, and plan a visually compelling, local-first interface that lets
a person explore the implemented CyberAlchemy ontology candidate-graph
prototype using the reusable graph/dashboard capabilities of
Egonex-AI/Understand-Anything.

## Interpreted Terms

- **Use Understand-Anything** means reuse a pinned upstream viewer/dashboard
  substrate and its graph interaction patterns. It does not mean install it,
  analyze the whole private repository, or adopt its graph schema as ontology
  authority in this invocation.
- **Cool interface** means fast visual orientation, guided lineage exploration,
  precise evidence inspection, visible uncertainty/conflict, keyboard
  navigation, and restrained visual polish. It does not mean hiding evidence
  state behind decorative graph effects.
- **Working interface** belongs to future bounded implementation. This Invoke
  run authors and validates planning artifacts only.

## Decisions Captured

1. Name the candidate product unit **Ontology Evidence Workbench (OEW)**.
2. Make verified candidate run bundles the only L0 data source.
3. Keep exact ontology relation metadata in an evidence sidecar and use an
   explicitly lossy presentation projection only for Understand-Anything
   compatibility.
4. Use Poker Team O13 as the first walkthrough without modifying Poker Team.
5. Treat Understand-Anything codebase analysis as an optional later context
   lane, never an ontology/promotion lane.
6. Keep existing IOLM state and its selected A2 SWU untouched.

## Interview Disposition

No blocker interview was required. The user selected all three Invoke stages,
named the upstream dependency, and prior approved artifacts close the product,
authority, and example boundaries. Non-blocking implementation choices are
deferred to the work pack.

## Approval Ceiling

Approval covers authoring and validating this package. It does not select an
SWU, install dependencies, clone/vendor upstream into the repository, run model
analysis, modify source, or grant release/promotion authority.
