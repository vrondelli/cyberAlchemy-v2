# Feature Glossary

These are feature-local explanatory terms, not promoted canonical definitions.

| Term | Meaning | Link status |
| --- | --- | --- |
| Ontology Evidence Workbench | private UI unit for verified candidate evidence | no-match; feature-local working name |
| source evidence graph | exact nodes/edges from the verified candidate result | partial; candidate graph contract |
| presentation graph | generalized UA-compatible layout/search projection | no-match; feature-local |
| evidence sidecar | lossless mapping from presentation objects to source evidence | partial; evidence/receipt concepts |
| trust rail | always-visible verifier, candidate, and authority-effect summary | no-match; UX label |
| code-context lane | optional separate UA-generated implementation graph | no-match; feature-local |
| generalized relation | upstream-compatible visual edge type that must not replace exact relation semantics | no-match; feature-local |

Canonical authority terms retain their definitions in
`cyberAlchemy-v2/authority/definitions/DEFINITIONS.md`; this glossary neither
redefines nor promotes them.
