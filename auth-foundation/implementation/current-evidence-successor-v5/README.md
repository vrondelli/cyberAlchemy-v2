# Current Auth technical-evidence successor v5 (candidate)

The selected public HTTP API and three bridges now compose a concrete
`SqliteAdmissionService` with a READY-bound decision function. The validator
checks their normal offline Cargo dependency closures, selected source shapes,
and exact current source bytes. It runs compile probes showing that five native
raw decision APIs require explicit `legacy-raw-decision` opt-in. This isolates
those APIs from the selected roots; it does not remove them for all consumers.

The nine v3 historical preimages stay frozen, and v3/v4 bindings are not
reissued. The current D65 owner-scope links are fresh, but the older
`runtime-evidence.json` adapter-source hash is stale after quarantine. This
binding reports that limitation rather than silently updating history.

Run from the repository root:

```sh
python3 auth-foundation/implementation/scripts/test-current-evidence-successor-v5.py
python3 auth-foundation/implementation/scripts/validate-current-evidence-successor-v5.py
```

This is local source, dependency, compile, and lineage evidence only. It is
not an all-path or runtime guarantee, semantic admission, TDE/F5/EVF
satisfaction, deployment, or publication.
