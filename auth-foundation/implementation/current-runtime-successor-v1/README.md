# Current Auth runtime targets — v1 candidate

These three targets are separately generated by the current local DomainSpec
CLI. They retain byte-identical Rust/Cargo/integration artifacts from the
historical Auth targets, but carry newly issued receipts bound to the current
relationship authority. The historical targets and D65 evidence are not
rewritten or superseded by this candidate.

Run `python3 auth-foundation/implementation/scripts/validate-current-runtime-successor.py`
from the checkout root to check both target observations, exact old/new receipt
differences, generated artifact bytes, and two-run reproducibility. Passing
this check is local candidate evidence only, not semantic admission, deployment,
production security, or `runtime_guarantees_observed`.
