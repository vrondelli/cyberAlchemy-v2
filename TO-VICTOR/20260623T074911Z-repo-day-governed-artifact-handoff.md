There is a possible reading trap in the working tree:

- `CAV2-D42 Governed Artifact Tree` exists as an active definition candidate in
  the current working tree.
- `CAV2-C14 Governed Artifact Tree Interface` exists as a constitution rule in
  the current working tree.
- The governed artifact research says `governed artifact` must not become a new
  primitive.

These are compatible only if D42/C14 are read as interface obligations:

```text

promotion path, validation surface, challenge contract, drift route,
allowed use, blocked use
```

