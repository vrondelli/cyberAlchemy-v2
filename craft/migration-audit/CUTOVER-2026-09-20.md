`craft/projects/domainspec-v2` and `craft/toolchains/node-typescript` without
searching for a sibling `domainspec-core` checkout. An explicit
`ALCHLANG_DOMAINSPEC_PACKAGE_ROOT` remains available for deliberate compatibility

toolchain runner, documentation, and default compiler adapter now resolve the

Craft package and 73 built distribution files. Historical evidence and generated
trial artifacts retain their original recorded paths.

bound to its current package constraints. Installed dependencies and CLI `dist`
remain rebuildable local outputs and are not source authority.

The concurrent provider-pack change requires explicit messaging destinations.
Alch runtime profiles now author `messaging-destination <channel-ref>
<environment-name>`, retain the five base environment references in canonical
order, and require exact one-to-one destination coverage through DomainSpec.
