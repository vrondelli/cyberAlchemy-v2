# Explorer Feedback 001

This is the single declared `synthesizer -> explorers` feedback loop. It repairs
immutable bindings only; it does not widen the corpus, revise the paper, or
authorize the findings writer.

## Turing repair

Bind the exact private checkout and SHA-256 identities for the executable source,
receipt, catalogue, validator, evaluator, and fixture artifacts used in the
first return. Re-run or bind the 29-file/240-test suite, typecheck, attestation
positive/negative, architecture self-test, and candidate evaluator with exact
environment, timestamp, command, exit, and transcript digest. Do not expose
private rule implementation.

## Ashby repair

Bind an immutable public commit and selector for Arcanum license wording; exact
identities and selectors for each E3/E6/E9/E11 number proposed for retention;
and exact primary-source page/section selectors for the theory references.
Attempt to bind the deployed Pages URL/bytes to a commit, but preserve it as
deferred if unavailable. Preserve authorship consent as deferred unless an
author-approved record already exists; do not invent one.

## Return gate

Each explorer returns a bounded immutable-binding supplement. Unclosed positive
rows become deferred or removed. The synthesizer receives both supplements and
must return `exact_binding_candidate=ready` before skeptical review.
