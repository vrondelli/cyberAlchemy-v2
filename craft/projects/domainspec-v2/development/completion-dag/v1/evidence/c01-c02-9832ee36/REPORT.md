## Diagnosed environment failure and recovery

The first parallel run passed 154/155 tests and failed its release-candidate test; clean-package validation also failed. Both encountered `EACCES` in `/var/cache/node/npm`. The image's uppercase `NPM_CONFIG_CACHE` overrode the runner's lowercase task-local cache variable. A read-only npm configuration comparison confirmed the cause.

The correction was to invoke the two affected phases through `env -u NPM_CONFIG_CACHE`. Both phases were rerun fully and passed. Compiler source, dependency versions and image identity did not change. Initial failed logs and [phase-results.json](phase-results.json) remain intact; [cache-recovery-results.json](cache-recovery-results.json) records the passing retries. [RESULTS.json](RESULTS.json) explicitly joins that evidence instead of rewriting the failed attempt as a pass.

