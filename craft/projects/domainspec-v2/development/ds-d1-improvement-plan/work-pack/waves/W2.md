# W2: Semantic Hardening

## Purpose

Add finite, validator-backed distinctions for the remaining highest-risk DS-D1
backend categories. The former Saga branch is closed and routed to SGRM.

## Sequence

1. Treat SWU-DSD1-007 as complete, SWU-DSD1-008 as cancelled/not-selected,
   and SWU-DSD1-009 as completed migration through SGRM-001..008.
2. Run backend hardening SWUs that remain selected: SWU-DSD1-010,
   SWU-DSD1-011, SWU-DSD1-012.
3. Run SWU-DSD1-013 only for validator support required by selected schemas.
4. Run SWU-DSD1-014 after criterion support is stable.

## Entry Gate

W0 must be complete. Remaining work must not reopen the cancelled Saga-hardening branch.

## Parallelization

Backend hardening SWUs can run in parallel only when their schema, fixture, and
test scopes are disjoint. Validator helper conflicts must be coordinated by a
parent owner.

## Exit Gate

Selected type distinctions have positive and negative fixtures, validation
evidence, and human-readable correction routes.

## Validation

- `npm --prefix projects/domainspec-v2/impl run tools:test`
- `npm --prefix projects/domainspec-v2/impl run validate`
- Focused generated-instance validation when schema criteria change.
