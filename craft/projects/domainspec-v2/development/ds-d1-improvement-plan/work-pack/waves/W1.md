# W1: UI-11 Formation Path

## Purpose

Choose and execute the UI meta-type path without letting DS-D8 endpoint
references become accidental DS-D1 category authority.

## Sequence

1. Run SWU-DSD1-003 to record the UI path decision.
2. If `add-ui`, run SWU-DSD1-004 and then SWU-DSD1-005.
3. If `narrow-claim` or `explicit-defer`, run SWU-DSD1-006.

## Entry Gate

W0 must be complete.

## Exit Gate

Either UI types have human cards, machine schemas, fixtures, tests, and
correction contracts, or DS-D1 explicitly narrows/defer its UI authority claim.

## Validation

- `npm --prefix projects/domainspec-v2/impl run validate:docs`
- If UI schemas are added: `npm --prefix projects/domainspec-v2/impl run tools:test`
- If generated instances are touched: run the existing generate/validate
  commands named by the executing SWU.
