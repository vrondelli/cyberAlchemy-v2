# Glossary

| Term | Definition | Source status |
| --- | --- | --- |
| Candidate run | One immutable evaluation of one candidate law against pinned alternatives and evidence. | local-defined |
| Existing coverage | An existing representation preserves all observed obligations and downstream consequences attributed to the candidate. | local-defined |
| Collapse evidence | Positive equivalence, substitutability, consequence parity, and no-loss evidence supporting `covered-existing`. | local-defined |
| Distinct-supported | Every hard candidate-formation conjunct and the fixed portability threshold pass. | linked to UI repair dossier policy |
| Covered-existing | Positive existing-coverage evidence supports reuse without a new type. | local-defined |
| Defer-missing | Neither distinct support nor existing coverage is sufficiently evidenced. | linked to UI repair `missing` semantics |
| Independent positive | A candidate witness not derived from the candidate label, authored criteria, or the same review source. | linked to GAP-UIR-006 |
| Stable contrast | A repeatable difference from the nearest existing representation under equivalent conditions. | linked to formation dossier |
| Label erasure | Candidate and framework labels are removed while the claimed distinction is retested. | linked to formation dossier |
| Criterion erasure | Authored candidate criteria are removed while an independent witness is retested. | linked to formation dossier |
| Changed consequence | Candidate or coverage choice changes a tracked validation, composition, derivation, projection, test, or generated-code outcome. | linked to UI repair evidence contracts |
| Independent corpus | A real source corpus with an authorship identity not reused to inflate the same candidate's count. | linked to DEC-UIR-008 |
| Independent reviewer | A reviewer with an explicit independence attestation whose identity counts once across roles. | linked to DEC-UIR-008 |
| Owner handoff | A bounded evidence package routed to DS-D1/DS-D8 owners without mutating authority. | linked to owner firewall |

Glossary status: `linked`. No canonical glossary promotion is requested.
