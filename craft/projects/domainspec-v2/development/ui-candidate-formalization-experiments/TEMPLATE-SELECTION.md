# Template Selection

| Template/profile | Eligibility | Selected use |
| --- | --- | --- |
| DomainSpec `SPEC.md` baseline | Ordinary governed feature/process with typed records and owner boundaries | define specification |
| DomainSpec architecture bundle | Approved define outputs require six design views | design architecture |
| Standalone implementation layering | Mandatory for plan | L0-L3 decision boundaries |
| Standalone split work-pack | More than five tasks, external gates, and multiple owners | executable plan authority |
| DomainSpec execution pack | High-complexity wave and branch choreography | plan handoff |

No template tie exists. Spell/sigil templates are ineligible because the target
is an ordinary candidate experiment program, not a reusable Arcanum capability.
The profile extracted by SWU-009 is a target-domain experiment profile and has
no automatic template-registry promotion.
