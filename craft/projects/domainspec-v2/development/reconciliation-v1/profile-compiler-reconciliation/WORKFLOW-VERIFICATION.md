## Meaning and source ownership

The definition is [semantic-workflow-controls-contract.json](semantic-workflow-controls-contract.json). Existing Workflow occurrence, binding, generation, materialization, outcome and selected-recovery contracts retain semantic ownership.

| Concept | Required distinction | Reference responsibility |
| --- | --- | --- |
| Occurrence | A step is not its Operation identifier | Follow exact checked source order, including repeated calls |
| Observation | Commit evidence is not result validity | Inspect settlement metadata without touching committed values |
| Completed prefix | Committed steps are not all attempted steps | Stop at first terminal observation and preserve committed local failures |
| Selected compensation | Needed graph is not the complete authored graph | Keep active and inactive dependencies distinct |
| Recovery intent | A plan is not compensation execution | Emit deterministic metadata only; uncertain commit needs reconciliation |
