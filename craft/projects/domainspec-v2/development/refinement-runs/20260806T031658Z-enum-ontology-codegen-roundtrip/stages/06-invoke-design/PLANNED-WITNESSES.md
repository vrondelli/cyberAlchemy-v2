   fixture owned outside the emitter, with no canonical promotion claim.

   reject a missing Enum type, required property, operator, or owner boundary.

   catalogue owner.
4. Reject the same obligation key when its expected member payload changes.
5. Normalize exact member identity/value pairs plus the realization spec into a minimal, non-authoritative

   and string-literal injection; reparse emitted output.

    owned witness derived from the frozen definition/catalogue.

    values and `Object.isFrozen` state; plain `as const` is insufficient.
13. Observe the actual generated bytes through a no-expectations adapter entry
    point that does not import the emitter.
14. Prove exact fact cardinality before set comparison and preserve source
    provenance.

17. Bind definition, ontology, realization spec, catalogue, IR, binding, profile, provider, emitter,

    concurrent, escaping, or already-completed targets and redact source snippets.

20. Reconstruct positive and negative evidence in a separate process and clean
