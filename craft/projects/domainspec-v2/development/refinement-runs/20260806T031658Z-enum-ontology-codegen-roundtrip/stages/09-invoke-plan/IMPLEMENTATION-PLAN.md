## Algorithms

### Ontology realization-spec derivation

```text
load exact ontology and profile bytes
verify pinned digests and schema versions
find exactly one architecture.EnumImplementation type
verify reciprocal active Enum meta-type reference
select required binding/enum properties by stable IDs
for each property:
  verify type applicability, value type, observation stage, owner route,
  and forbidden-inference rule
select admitted profile constraints/operators for the Enum type
require direct composition and preserve composed_from as deferred relation
canonicalize by stable IDs and hash the complete spec
```

Any missing/duplicate type, property, operator, owner field, or stale digest
fails with one exact code. The projector does not modify ontology content.

### Snapshot-bound obligation catalogue derivation

```text
require the ARE-004 terminal and closeout receipts
read and validate the exact EnumDefinitionSnapshot/v1 bytes
recompute its semantic digest while excluding only definition_sha256
require definition_ref path, byte digest, and semantic digest to match
read raw ontology/profile handles and validate the Enum denominator independently
read v1 catalogue and ARE-003 receipt only as immutable predecessor lineage
reject Stage 08 expectations and compiler/adapter/evaluator imports
derive expected members only from snapshot.members
canonicalize language-neutral IDs and values using UTF-8 ordering
validate positive, same-key payload drift, and isolated definition-reference mutants
rerun the unchanged v1 catalogue validator as a regression
```

The v2 catalogue becomes the active expectation input. The v1 catalogue remains
historical evidence and is not silently rewritten or treated as the active oracle.

### Portable normalization

```text
validate definition snapshot, realization spec, and active v2 catalogue independently
exact-join their pinned type/meta-type and definition references
reject empty members, duplicate IDs, duplicate values, and non-direct scope
sort members by member_id because order_semantics is none
emit only portable fields plus input handles
canonicalize and hash
```

### TypeScript emission

```text
validate target binding path, identifiers, provider, and total member mapping
encode every semantic value through a safe literal serializer
construct provider import, const export, and EnumValue type export
parse generated bytes with the TypeScript compiler API
re-extract export/import/member records and compare to binding plus IR
format canonically, emit manifest, repeat, and compare bytes
```

No emitter helper may read catalogue expected payloads or test expected results.

### Compile and runtime evidence

```text
create non-existing run workspace under an admitted parent
reject symlinks/path escape
mirror exact provider/profile/activation/source bytes at deterministic paths
independent proof harness derives a type witness from definition/catalogue
run pinned tsc with exact config
import compiled/runtime source through the admitted provider path
record literal-union, runtime member/value, and Object.isFrozen witnesses
normalize diagnostics without arbitrary source fragments
```

### Observation and evaluation

```text
adapter parses actual generated source and emits member records/provenance only
evaluator exact-joins case/catalogue/compiler/manifest/observation handles
validate raw cardinality and uniqueness before set conversion
map target identifiers through the owner-frozen binding
compare expected member_id/value relation against observed relation
emit total findings with exact codes
```

The evaluator has a forbidden-import test covering spec projector, normalizer,
emitter, compiler implementation, adapter implementation, fixture expected
values, and mutation oracle.

### Mutation and replay

```text
parse exact positive parent source
resolve Paid through target binding
remove exactly one matching property AST node
print, reparse, and prove the normalized delta is one deletion
compile child; require green
observe and evaluate child; require one missing-member code
atomically publish raw and normalized evidence through the state machine
spawn a separate replay process in a new workspace
reconstruct every output from raw handles and compare normalized digests
```

## Stop conditions

Stop before mutation or completion when:

- the current ontology cannot express a required property/operator without an
  owner-approved ontology change;
- the concrete definition needs canonical rather than candidate-fixture status;
- implementation requires editing public Arcanum or another repository;
- a target path or import escapes the admitted workspace;
- evaluator independence cannot be demonstrated structurally;
- a positive, mutation, legacy regression, or isolated replay check fails;
- credentials, network, publication, deployment, destructive cleanup, or a new
  semantic choice is required.
