# Run-Local Glossary

These are candidate working definitions for the refinement run. They do not amend DomainSpec or CyberAlchemy definitions.

| Term | Working definition | Forbidden collapse |
| --- | --- | --- |
| DomainSpec factory | The language, schema, compiler, validator, and mint-default owner that creates a project shape. | Not owner of the minted project's concrete domain meaning. |
| Mint contract | The deterministic rules and files DomainSpec emits so a new project can author and compile its own graph. | Not a preloaded DomainSpec feature corpus. |
| Consumer project | A project created from the mint contract that owns its domain declarations and local authority decisions. | Not a fixture directory inside DomainSpec. |
| Canonical node source | The one project-local machine-readable source record that owns a node's declared semantics. | Not generated graph JSON or Markdown. |
| Source-owned connection | One authored typed edge declaration stored at exactly one canonical source location. | Not a prose link; not a duplicate reverse edge. |
| Normalized graph | A deterministic compiled projection containing first-class nodes, first-class edges, and source pointers. | Not writable semantic authority. |
| Source manifest | A generated list of canonical source files and content digests used by a build. | Not a substitute for project manifest intent. |
| Generated human view | Markdown or a visualization derived entirely from canonical sources/graph. | Not a machine parsing dependency or independent source. |
| Workflow witness | A bounded example that exercises a candidate contract. | Not general proof or production authority. |
| Authority handoff | The point at which factory-owned form produces a project-owned semantic workspace. | Not abandonment of language validation or retention of consumer meaning by DomainSpec. |

Glossary link status: `partial`. Existing authority, kind, relationship, and projection terms are linked to selected sources; the mint-package terms remain run-local candidates.
