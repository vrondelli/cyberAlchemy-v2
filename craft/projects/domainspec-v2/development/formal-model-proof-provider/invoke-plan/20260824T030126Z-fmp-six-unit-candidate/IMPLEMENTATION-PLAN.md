# Implementation Plan — Six-Unit FMP Candidate

## Ordered construction

1. Define and test the provider-local TLA case language and total TLC classifier without launching any process.
2. After exact factory-owner acceptance, add the smallest generic non-executable material and per-node execution-policy lock seam, preserving legacy providers.
3. Register one TLA/TLC provider that consumes verified Java/JAR handles, runs in private scratch, classifies every case, derives existing proof evidence, and cleans up; prove it first with a fake tool.
4. Freeze the exact 17-case Bolina corpus with source attribution and M10 discrimination.
5. Freeze the exact five-case Order Saga corpus while preserving `FreshnessSafety` as an expected red, not a repaired pass.
6. Exercise both through the existing factory lifecycle and close the exact inventory and claim ceiling in the same terminal unit.

## Data flow

```text
case manifest + virtual model bundle + independently owned denominator
  -> factory request and run lock
  -> verified Java executable + verified tla2tools artifact handles
  -> provider-private materialization and bounded TLC process
  -> total outcome classification and existing ProofEvidence/v1
  -> existing factory accounting, repeat, replay, verify, reproduce and receipt
```

No FMP-owned replay engine, receipt publisher, accounting verifier, or EVF obligation translator is introduced.

## Failure posture

Each unit fails closed on missing input, digest drift, unknown result class, incomplete accounting, unexpected red/green, foreign output, cleanup failure, or owner receipt mismatch. Repair is allowed only inside the same exact unit scope when no semantic or authority decision is required. A later passing cleanup command never masks an earlier failure.

## Handoff posture

Each task contains one SWU, implementation detail, exact source anchors, write scope, acceptance evidence, rollback, expected receipt, and successor. A later Task Session builds a fresh strict runtime context pack; this Plan does not pre-generate execution context.
