# Template Selection

Selected mode: Invoke full, deferred composition of Define, Design, and Plan.

Selected templates:

- Define: custom specification plus glossary because the package introduces a lifecycle and local evidence types without changing canonical vocabulary.
- Design: six-view architecture with current Design selection manifest/denominator/fixed-point validation.
- Plan: medium/high split Work Pack because the route crosses ontology authority, design approval, three language owners, and parity reconciliation.
- Dispatch: full capability-bound dispatch because future execution contains owner-gated waves and three independent language lanes.

Rejected: a single implementation checklist. It would collapse authority admission, architecture design, and language evidence into one mutable sequence.
