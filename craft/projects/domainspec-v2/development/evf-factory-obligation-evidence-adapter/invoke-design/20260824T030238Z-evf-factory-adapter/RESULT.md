# Invoke Design Result

## Outcome Brief

The adapter is now designed as one thin, versioned bridge: EVF supplies the exact obligation, the existing factory supplies verified lifecycle evidence, and the TLA/TLC provider supplies only solver meaning. A simple example is: “prove this ordering obligation”; the adapter binds that exact request to an exact factory run and returns a bounded EVF handle only if every identity, replay/currentness check, accounting total, result class, and claim ceiling matches.

The Design selection itself passed deterministically, but the Design is not ready for implementation planning. Exact schema bytes, negative fixtures, the factory currentness handle, provider taxonomy, and protected assignees still need their owners' acceptance.

- Objective: design the separate EVF-to-factory obligation/evidence adapter selected by `FMP-EVF-B`.
- Result: six-view candidate authored; exact denominator and two-pass selection passed; owner-gated Plan readiness remains flagged.
- Why it matters: FMP can remain a non-redundant TLA/TLC provider without duplicating factory lifecycle or inflating EVF claims.
