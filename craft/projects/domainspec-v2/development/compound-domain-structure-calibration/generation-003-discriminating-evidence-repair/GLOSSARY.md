# Generation 3 Glossary

| Term | Definition | Boundary |
| --- | --- | --- |
| atomic target | One independently observable proposition derived from one frozen parent substitution field. | Not a new observable ontology or DS-D1 type. |
| decomposition contract | Deterministic rules and digests that split parent substitution text before observations exist. | Cannot consume outcomes or explanation labels. |
| discriminating evidence | Evidence capable of deciding one explanation/atomic-target coordinate without bundled partial coverage. | Does not imply identity or irreducibility. |
| browser baseline | Source-derived React/browser behavior that must match pinned expected vectors before mutations. | Not the Savvy checkout and not production certification. |
| `M3-P` | Generated-adapter replacement of the step-9 child under the same interaction contract. | Permitted mutation only. |
| `M3-B` | Generated-adapter commit of requested step instead of guard result. | Breaking mutation only. |
| structured observation | Machine-readable DOM, route, guard, notice, requested-step, committed-step, and child state. | Screenshots are supporting evidence only. |
| downstream decision differential | Symmetric difference between two preregistered finite test selections. | Nonzero does not establish promotion-worthy usefulness. |
| generation-3 overlay | Reviewed `A x T` adjudication bound to exact observation handles. | Post-observation evidence, not a rewritten baseline. |
| compatibility projection | Deterministic v1 receipt consumed by the frozen evaluator. | Evaluation adapter, not interpretive authority. |
| imported portability limit | Stable UI-repair evidence that current portability remains below threshold. | Context only; this package does not rerun corpus policy. |
| evidence repair | New evidence and representation work after a deferred calibration outcome. | Never permission to rewrite history or force a pass. |

## Linked Terms

`Page`, DS-D1, DS-D8, identity, irreducibility, pattern, candidate, activation,
promotion, evidence receipt, fixture outcome, and suite verdict retain their
existing owners and meanings. This glossary does not redefine them.
