# Invoke Context: Generation 3 Discriminating Evidence Repair

## Intent

Author a new governed package after generation 2 closed
`CALIBRATION-DEFER`. The package must repair the evidence and adjudication
resolution problem without rewriting generations 1 or 2, rerunning the closed
UI-repair machinery, or treating calibration as type/pattern authority.

## Controlling Evidence

- Generation-2 temporal and authority audit, independent replay, suite result,
  provenance manifest, and Inventory closeout read model.
- Parent calibration specification, six-view architecture, four fixture
  outcomes, three suite verdicts, immutable generation rules, and authority
  boundary.
- Generation-2 decisions, gaps, overlay/materializer protocol, and accepted
  receipts.
- Closed UI meta-type repair successor work-pack and integrated audit:
  portability is below the fixed 2/2/2 threshold, Form/Action positives remain
  missing, and the package owns its corpus/dossier policy.
- Invoke define, design, and plan contracts; DomainSpec templates;
  implementation-layering transmutation; Dispatch Spec technique catalog.

## Problem Diagnosis

Generation 2 supplied both planned mutation observations, but five permitted
coordinates and one breaking coordinate remained `indeterminate`. Their target
propositions bundled multiple consequences, so an unchanged explanation could
cover one consequence without accounting for the whole coordinate. More runs
against the same compound targets would reproduce the ambiguity.

The evidence also remains bounded: visual output, React behavior, live browser
navigation, source-repository mutation, direct route/content attestation, and
portable Page identity were not established.

## Selected Scope

1. Define a deterministic atomic-target decomposition contract over the frozen
   parent substitution descriptions and predictions.
2. Reject decomposition derived from observed outcomes, desired verdicts, or
   explanation labels.
3. Build a source-derived browser harness outside the Savvy checkout and prove
   baseline equivalence before mutation.
4. Observe permitted child replacement and breaking guard-commit behavior at
   render, interaction, route, notice, and committed-step boundaries.
5. Measure one preregistered downstream decision differential using a fixed
   finite test-impact catalog; accept zero or nonzero output.
6. Freeze a generation-3 adjudication overlay and deterministic v1 evaluator
   projection while retaining unchanged parent explanations and decision tables.
7. Append generation 3 once, independently replay it, and expose only a
   non-authority read model.

## Ownership Boundaries

- This package owns F3 local discriminability, browser observations,
  downstream-decision evidence, generation-3 adjudication/evaluation, and audit.
- The closed UI-repair package owns corpus construction, portability policy,
  formation dossiers, and relationship owner decisions. Generation 3 may import
  its stable `DEFER` handles only as bounded context.
- Savvy and all fixture repositories remain read-only. Mutations occur only in
  generated harness modules.
- DS-D1, DS-D8, pattern governance, candidates, activation, and promotion stay
  with external owners.
