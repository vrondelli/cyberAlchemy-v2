# Compound Domain Structure Calibration Glossary

These definitions are local to the experiment package. They do not add or
change canonical DomainSpec definitions.

| Term | Local definition | Status |
| --- | --- | --- |
| Atomic DS-D1 type | A node with a label-erased formation rule admitted by the DS-D1 owner. | linked |
| Contextual role | A function an existing artifact gains or loses without changing its underlying formation. | linked |
| Projection | Behavior derived from separately owned authority while that authority remains stable. | linked |
| DS-D8 relationship | A finite active endpoint signature constraining an edge, not the formation of either endpoint. | linked |
| Architecture pattern | Recurrent problem/context guidance and arrangement that does not create validator authority. | linked |
| Named instance | A concrete artifact with local identity regardless of whether its label generalizes. | linked |
| Residual-analysis hypothesis | The candidate-only proposition that registered explanations may leave observable obligations unexplained. | local-candidate |
| Experiment envelope | The finite `H(X) = (G,A,Q,R,S,D,U)` record for one fixture generation. | local-candidate |
| Explanation set (`A`) | Finite preregistered explanations and the exact observables each may explain. | local-candidate |
| Observable set (`Q`) | Finite preregistered claims whose evidence state is evaluated. | local-candidate |
| Subtraction predicate | Frozen reviewed value `sigma(a,q)` stating whether one explanation accounts for one observable. | local-candidate |
| Residue (`R`) | Observables marked not-explained by every explanation in `A`. | local-candidate |
| Permitted substitution | Replacement predicted to preserve specified observations. | local-candidate |
| Breaking substitution | Removal, replacement, or reordering predicted to change specified observations. | local-candidate |
| Usefulness delta (`D`) | Reproducible change in a preregistered validation, decomposition, testing, ownership, or execution decision. | local-candidate |
| Uncertainty (`U`) | Explicit missing, disputed, untested, or non-portable evidence. | local-candidate |
| Fixture outcome | One of `INSUFFICIENT-EVIDENCE`, `EXPLAINED`, `RUBRIC-FAIL`, or `RESIDUAL-SUPPORTED`. | local-candidate |
| Suite verdict | One of `CALIBRATION-DEFER`, `CALIBRATION-FAIL`, or `CALIBRATION-PASS`. | local-candidate |
| Semantic digest | Digest of frozen meaning-bearing fields, excluding volatile run metadata. | reused-development-pattern |
| Generation | Immutable experiment input/result set linked to its predecessor. | reused-development-pattern |

## Forbidden Synonyms

- Do not use `compound type` for `residual-analysis hypothesis`.
- Do not use `proof of identity` for `RESIDUAL-SUPPORTED`.
- Do not use `replicated` or `promoted` for `CALIBRATION-PASS`.
- Do not use `absent` for evidence recorded as missing or indeterminate.
- Do not use `Rule projection` unless a separately authoritative Rule is cited.
