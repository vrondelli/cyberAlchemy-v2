# N32 Design Context

The exact sequencing input `produces` chooses only the first D08 verb-local subject.
D08 B preserves `Operation --[produces]--> Event` as successful-completion cause
provenance, preserves `Entity --[emits]--> Event` as subject/source provenance, and
adds no cross-row rule. The candidate packet leaves `produces.duplicates` unresolved.

The smallest coherent unit is therefore repeated authorship of the exact same
canonical `produces` proposition: identical verb, Operation concept ID, Event concept
ID, and admitted authority/feature context, with distinct authored source handles.
Event payload equality and runtime Event occurrences are not part of that identity.
N01 and N03 are structural precedents for reject versus conditional provenance-
preserving coalescence; neither selects N32.

## Dispatch Technique Trace

- `sequence`: persist exact `produces` sequencing before forming N32.
- `owner_boundary_check`: keep A/B authority-gated and N32 unselected.
- `residue_ledger`: retain `emits`, payload, occurrence, numeric, ordering, closure,
  inverse, representation, runtime, packet, canonical, and implementation questions.
- `artifact_contract_bridge`: bind sequencing, N31, D08, canonical cards, packet row,
  and N01/N03 precedents.
- `concrete_path_evidence`: distinguish canonical fact identity from Event data or
  runtime occurrence identity.
- `validation_loop`: replay extractor, selector, and prefilter byte-identically.
- `frame_handoff`: stop at the N32 owner gate.

Exactly eight source contracts are selected. Inventory is not used as authority.
`authority_effect: none`.
