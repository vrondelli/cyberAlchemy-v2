# N31 Design Context

N23 A permits a topology-admitted mixed-kind closed path only as its independent
exact kind-bearing direct facts. N30 A settles distinct endpoints only. N20 A rejects
direct canonical self-edges but does not answer whether a longer admitted path may
produce a non-authoritative self-reachability result. D30 withholds transitivity and
closure; D23 keeps a finite path consequence independently designable.

The smallest coherent frontier is therefore one canonical `belongs-to` closed path
of length at least two, using at least two exact active D30 kinds, with equal first
and last Entity IDs. N31 compares no derived self-reachability with a non-authoritative
ordered-kind-trace-preserving result. It cannot create `belongs-to_k(e,e)`, collapse
kinds, reopen topology, or select representation, completeness, runtime, or numeric policy.
