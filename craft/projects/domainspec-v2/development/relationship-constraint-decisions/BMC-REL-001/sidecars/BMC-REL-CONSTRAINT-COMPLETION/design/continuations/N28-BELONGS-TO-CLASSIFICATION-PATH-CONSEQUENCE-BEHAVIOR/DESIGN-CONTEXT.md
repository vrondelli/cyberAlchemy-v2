# N28 Design Context

## Objective

Bind the exact `classification` sequencing input without treating it as a behavior
selection, then isolate whether classification consequences stop at each direct
canonical `belongs-to` fact or include non-authoritative reachability over an
acyclic same-kind path.

## Evidence Boundary

N27 B requires an independent behavior decision for each exact active D30 membership
kind. The exact clarification selects `classification` as the first target. D30
defines a classification fact as a direct conceptual-classifier relation and
explicitly withholds transitivity and closure. D23 recognizes a relationship chain
as one possible finite composition-path consequence, which makes derived
classification reachability a genuine owner choice rather than an invalid
candidate.

The closed denominator contains six direct exact sources: the N28 sequencing
receipt, the N27 owner receipt, D23 and D30 in the definitions source, the exact
membership-kind registry, the canonical `belongs-to` card, and the packet row. One
source file supplies both D23 and D30 selectors, so the direct file count is six.

Excluded are `home-assignment`, mixed-kind paths, new canonical edges or verbs,
derived-result naming and provenance, materialization, representation, storage,
closure proof, partial-view verdicts, mandatory membership, runtime, numeric,
packet, canonical, and implementation work.

A full dispatch document is not required: this is one local authoring sequence with
no delegation, protected-context transfer, or multi-capability execution graph.

## Ordered Design Rules

1. Bind N27 B and exact `classification` sequencing.
2. Classify only acyclic paths of length at least two whose canonical `belongs-to`
   facts all carry exact active D30 kind `classification`.
3. A keeps consequences on direct facts only.
4. B permits a non-authoritative derived classification reachability consequence
   without authoring a new canonical `belongs-to` fact.
5. Do not choose behavior for `home-assignment`, mixed-kind paths, representation,
   provenance, closure proof, completeness, or runtime.
6. Present A, B, defer, and stop with aligned examples and decision effect none.
7. Stop before N28 selection, Plan, implementation, or canonical mutation.

Authority effect: `none`.
