The strict Standard pack contains 14 exact files and closes five obligations: selected N37 semantics, current blocker, ownership precedent, existing producer capability, and admission/enforcement status.

The key contrast is deliberate. The proof-obligation and EVF research define a layered ownership pattern; the minted-project implementation provides exact source resolution, a normalized graph, source manifest, and build receipt. But `emits` appears only in the candidate `complete-backend-criteria` profile whose release admission is `not-granted`, and the compiler's multiplicity check applies only to `one_to_one`. It therefore neither admits nor evaluates N37's target-side `emits` maximum.
