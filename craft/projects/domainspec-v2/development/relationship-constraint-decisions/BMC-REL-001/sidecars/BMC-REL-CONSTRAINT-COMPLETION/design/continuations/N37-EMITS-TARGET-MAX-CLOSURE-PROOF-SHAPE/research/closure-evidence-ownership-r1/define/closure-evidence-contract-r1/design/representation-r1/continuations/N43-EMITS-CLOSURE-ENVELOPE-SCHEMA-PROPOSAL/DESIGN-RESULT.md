# N43 Design result

N42-A is selected and immutably recorded. Inventory and four exact live schema precedents converge on JSON Schema Draft 2020-12 with closed objects, digest-bound references, and unique-item exact sets. N43 therefore routes directly to one candidate envelope schema instead of manufacturing a Decision Gate.

The candidate carries inline exact Entity/Event populations, independent placement sets, incoming canonical `emits` fact pairs, exact snapshot references, consumer attestation, and external-or-unknown currentness. It permits empty exact sets and gives array order no meaning. Structural and semantic validation are explicitly separate.

N43 is proposal-complete, not admitted. The next dependency is a candidate evaluator-receipt schema that binds the exact envelope and evaluator inputs. Only after both candidate contracts and the consumer-attestation owner are concrete can a coordinated admission gate be honest.

No canonical, packet, profile, implementation, publication, release, deployment, production, or D06 effect is authorized.
