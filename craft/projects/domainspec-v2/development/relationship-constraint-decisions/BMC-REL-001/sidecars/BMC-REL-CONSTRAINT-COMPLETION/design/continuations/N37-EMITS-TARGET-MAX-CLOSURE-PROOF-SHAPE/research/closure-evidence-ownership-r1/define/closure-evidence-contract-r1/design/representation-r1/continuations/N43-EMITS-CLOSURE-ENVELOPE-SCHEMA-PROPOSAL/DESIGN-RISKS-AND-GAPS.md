# N43 risks and gaps

| Risk or gap | Boundary |
| --- | --- |
| Schema validity is mistaken for truth | The schema proves shape only; the consumer owns completeness claims. |
| Empty populations are rejected as invalid | Exact-set arrays allow zero members so N43 does not infer positive minima. |
| Array position acquires meaning | `uniqueItems` arrays represent mathematical sets; order is non-semantic. |
| Placement drifts from population | A semantic validator must require set equality for each endpoint type. |
| Facts reference concepts outside populations | A semantic validator must reject unbound source or target IDs. |
| Compiler provenance becomes completeness authority | Snapshot references remain provenance only; attestation names the consumer owner. |
| Candidate bytes are treated as admitted | Schema ownership/admission remains a later coordinated owner gate. |
| Receipt design is bundled prematurely | The evaluator receipt is the next direct proposal because it binds this envelope digest. |
