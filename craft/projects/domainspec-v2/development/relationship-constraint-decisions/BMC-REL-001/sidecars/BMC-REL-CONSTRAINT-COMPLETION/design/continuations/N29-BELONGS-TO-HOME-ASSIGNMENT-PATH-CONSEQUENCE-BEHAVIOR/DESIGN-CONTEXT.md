# N29 Design Context

## Objective

Bind N27's per-kind governance and the exact N28 A classification selection, derive
`home-assignment` as the sole current unresolved D30 kind without copying behavior,
then isolate whether home-assignment consequences stop at each direct
canonical `belongs-to` fact or include non-authoritative reachability over an
acyclic same-kind path.

## Evidence Boundary

N27 B requires an independent behavior decision for each exact active D30 membership
kind. N28 A closes classification while explicitly withholding home-assignment
behavior, so the exact two-member active set leaves home-assignment as the sole
current unresolved kind by set difference, not registry order. D30
defines a home-assignment fact as a direct home or placement-context relation and
explicitly withholds transitivity and closure. D23 recognizes a relationship chain
as one possible finite composition-path consequence, which makes derived
home-assignment reachability a genuine owner choice rather than an invalid
candidate.

The closed denominator contains six direct exact sources: the N28 owner-selection
receipt, the N27 owner receipt, D23 and D30 in the definitions source, the exact
membership-kind registry, the canonical `belongs-to` card, and the packet row. One
source file supplies both D23 and D30 selectors, so the direct file count is six.

Excluded are `classification`, mixed-kind paths, new canonical edges or verbs,
derived-result naming and provenance, materialization, representation, storage,
closure proof, partial-view verdicts, mandatory membership, runtime, numeric,
packet, canonical, and implementation work.

## Ordered Design Rules

1. Bind N27 B, N28 A, and the exact two-member active D30 set.
2. Derive `home-assignment` as the sole current unresolved kind without using registry
   order as precedence or N28 A as N29 consent.
3. Classify only acyclic paths of length at least two whose canonical `belongs-to`
   facts all carry exact active D30 kind `home-assignment`.
4. A keeps consequences on direct facts only.
5. B permits a non-authoritative derived home-assignment reachability consequence
   without authoring a new canonical `belongs-to` fact.
6. Do not reopen behavior for `classification`, mixed-kind paths, representation,
   provenance, closure proof, completeness, or runtime.
7. Present A, B, defer, and stop with aligned examples and decision effect none.
8. Stop before N29 selection, Plan, implementation, or canonical mutation.

Authority effect: `none`.
