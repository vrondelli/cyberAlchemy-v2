# Unified Ontology Canvas Invoke Package

This candidate package defines, designs, and plans one persistent canvas for all
loaded ontology graph families. The canvas keeps five semantic bands in one
immutable graph:

```text
Meaning -> Realization -> Expectation -> Observation -> Explanation
```

Profile controls emphasize paths; they do not rebuild or replace the graph.
Constraints remain first-class nodes, supplied observations and expected
findings remain explicitly TypeScript-pinned, and the structured navigator must
expose the same identities and relations as the spatial view.
