# Define Transport

## Carried Into Design

- immutable five-family source bundle;
- one-graph and explicit-bridge invariants;
- deterministic five-band layout decision;
- required human UX contract;
- dependency-free/same-origin/local-only boundary;
- visible candidate, supplied-fixture, and non-authority cues;
- unresolved performance, mobile-density, copy-ownership, and optional-minimap
  gaps.

Design may refine components and interactions but may not change the one-canvas
definition or infer missing semantic bridges.
