# Glossary

| Term | Meaning in this feature | Must not be confused with |
| --- | --- | --- |
| Unified canvas | One persistent pan-and-zoom surface containing all loaded graph families. | One giant undifferentiated ontology. |
| UnifiedCanvasGraph | Immutable presentation projection assembled from the current JSON bundle. | Canonical ontology authority or a new data store. |
| Band | A deterministic layout region for one evidence/meaning layer. | A new DomainSpec layer or maturity status. |
| Meaning | DomainSpec meta-type projection, including maturity and coverage. | Architecture implementation type. |
| Realization | Candidate architecture types and their inheritance/relations. | Admitted semantic identity. |
| Expectation | Selected profiles, constraints, and property definitions. | Observed code fact or universal language law. |
| Observation | Supplied fact elements and relations. | Proof that an adapter executed or that the source is correct. |
| Explanation | Findings that compare supplied observations with selected expectations. | Authority verdict, waiver, or release decision. |
| Bridge edge | Cross-band presentation edge derived from an explicit source field or declared rule. | A newly admitted DS-D2 relationship. |
| Visibility filter | Reversible state that hides or dims nodes while preserving graph identity. | Rebuilding a different graph. |
| Focus | Temporary emphasis on selected nodes and real incident paths. | Deletion, promotion, or semantic narrowing. |
| Trace path | Available connected path across bands for one selected subject. | A guarantee that all five stages exist. |
| Stable ID | Namespaced canvas identity derived deterministically from source identity. | Canonical semantic identity minted by the view. |
| Supplied fact | Hand-authored example in the current fixture shape. | Fact extracted by a source adapter. |
| Candidate alignment | Explicit non-authoritative link between a DS-D1 meta-type and an architecture type. | Formation, admission, or canonical binding. |
| Implementation coverage | Whether a semantic meta-type has a candidate realization in this experiment. | Meta-type maturity. |
| Finding | Typed expectation/actual mismatch from the supplied expected evaluation. | Runtime failure or production defect. |
