# Template Selection

| Mode | Selected output | Why |
| --- | --- | --- |
| Define | DomainSpec spec family | The feature has typed calculations, queries, rules, an interface, and an interaction lifecycle. |
| Design | Architecture plus required UX plan | A natural person navigates a rendered surface whose semantic reading order and focus behavior change. |
| Plan | Split Work Pack, Implementation Layering, and Execution Pack | The medium-complexity feature has independently testable projection, layout, rendering, interaction, accessibility, and acceptance concerns. |

Generic, research, sigil, and spell templates are not selected. No new research
question or reusable Arcanum capability is being authored.
