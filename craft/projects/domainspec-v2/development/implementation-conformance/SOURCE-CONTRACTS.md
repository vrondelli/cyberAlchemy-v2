selected source spine. `cyberAlchemy-v2/SOURCE-MAP.md` points to private
DomainSpec implementation evidence and says generalized pattern cards require
owner review. Therefore this design:

1. consumes CAV2's authority and projection discipline;
2. consumes Architecture-Pattern Enforcement findings for structural laws;
3. uses the parser experiment and v1 pattern library only as bounded precedent;
4. does not claim an ontology import, pattern promotion, or CAV2 method
   authority.
