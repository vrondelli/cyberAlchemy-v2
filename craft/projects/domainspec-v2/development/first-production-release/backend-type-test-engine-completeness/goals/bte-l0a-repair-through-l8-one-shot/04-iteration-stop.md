# Iteration And Stop

## Loop

1. Read the sidecar and current strict context pack.
2. Verify exactly one current candidate and its predecessor handles.
3. Validate dispatch, scope, fixtures, negatives, commands, and stop rules.
4. Execute one Task Session.
5. Audit the terminal receipt and preservation evidence.
6. Run Invoke Refresh to reconcile controlled planning, Craft, and read models.
7. Instantiate and strictly pack the next smallest coherent SWU.
8. Continue under campaign pre-authorization only if every selection condition
   still passes.

## Stop

Stop at the first real blocker:

- failed proof or preservation check;
- zero or multiple candidates;
- ambiguous, expanded, protected, or forbidden write scope;
- missing/stale predecessor receipt;
- missing independent freeze, admission, or consumer-owner handle;
- audit veto or non-terminal receipt;
- missing strict pack or validator;
- release or production authority would have to be inferred.

The blocked report must preserve successful prior receipts and name the exact
owner and unblock action. Never widen scope to keep the campaign moving.
