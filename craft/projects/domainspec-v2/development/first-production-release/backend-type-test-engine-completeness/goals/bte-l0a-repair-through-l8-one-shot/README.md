# BTE L0A Repair Through L8 One-Shot

This folder is the local sidecar for the native Codex Goal selected and approved
on 2026-07-23.

The one-shot is one autonomous campaign, not one oversized Task Session. It
executes exactly one current SWU at a time, accepts only terminal evidence,
refreshes the frontier, and continues only when one next SWU has an exact scope.

## Start Here

1. `00-goal-command.md`
2. `CODEX-GOAL-PROFILE.md`
3. `handoff-pack.md`
4. `handoff-index.json`
5. `APPROVAL-RECORD.json`

The goal is private DomainSpec execution control. It does not change public
Arcanum, release state, admission state, or production authorization.
