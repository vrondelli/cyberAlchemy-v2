# W5 — L4 Catalogues And Selections

## Question

Are six exact nonempty denominators and both causal effect selections frozen by
owners independently from the implementation under test?

## Entry, Work, Exit

Entry requires exact W4 handles. Exit requires six catalogue/freeze handles,
the 13-row node-pattern selection, the 16-row relationship selection, matching
admissions or typed residue, and all red matrices. No TestCase may exist before
its matching freeze. Missing admission excludes only the affected catalogue
from core eligibility; missing freeze blocks its test materialization.
