# W1 — Compiled CLI

Layer/slice: L1 / SFC-S2. Units: SWU-SFC-007 through SWU-SFC-010.

## Outcome

Provide the two supported read-only commands, exact channel/exit behavior, one
npm lock authority, compiled JavaScript staging, and a two-clean-root equality
proof over normalized green and red results.

## Order and gates

`007 → 008 → 009 → 010` is sequential. SWU-009 also requires the reviewed
install-script allowlist `SFC-PR-002`. Network, runtime install, source-run
coupling, competing package-manager authority, partial stdout, or project writes
block the wave.

Exit requires four passing Task Session and closeout receipts plus the exact
artifact manifest. It makes SWU-SFC-011 and SWU-SFC-013 independently eligible;
it does not start either lane.
