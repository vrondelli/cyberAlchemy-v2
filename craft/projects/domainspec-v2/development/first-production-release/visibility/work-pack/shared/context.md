# Shared execution context

## Read boundary

All visibility SWUs may read:

- `../../PLANNING-CONTEXT.md`
- `../../IMPLEMENTATION-LAYERING.md`
- `../../WORK-PACK.md`
- `../../../ROADMAP.md`
- `../../../craft/expected-node-edge-manifest.yml`
- `../../../../../.craft/ledger.yml`

Task-relative paths are descriptive. Commands must run from the repository root using
the canonical paths recorded in the planning context.

## Authority rules

- Craft owns current continuation state.
- The manifest owns the graph projection.
- Generated files own nothing.
- The accepted decision owns product scope.
- Parent FPR stage/gate/next move must not change in this feature.

## Shared negative controls

- mutate an edge endpoint to an unknown node: generation must fail;
- introduce a node dependency cycle: generation must fail;
- remove a projected frontier from Craft gaps: generation must fail;
- remove a declared research or decision source: generation must fail;
- set `production_authorized: true`: generation must fail;
- modify a generated byte: `--check` must fail;
- disable JavaScript: the page must retain a visible claim warning and provenance.

## Receipt schema

Every `RESULT.md` contains: status, inputs, mutations, validation commands and results,
negative controls, artifacts, residue, and next-owner handoff.
