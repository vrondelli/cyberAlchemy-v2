The direction is agreed. The release is not.

We know the direction for DomainSpec v2. But the roadmap, specifications, past decisions, and current code do not yet agree in every place. FPR-01 finds each disagreement and records the owners' decision about what the team will follow. Once those contradictions are resolved, we can define exactly what the first release includes, build it, and prove only the claims its tests support.

How to use Roadmap Lab

Use one pass to understand the current step and leave one specific improvement for an authorized owner to review.

  1. Understand: read the FPR-01 focus and choose Continue.
  2. Restate: explain what FPR-01 means, what it depends on, and how completion will be proved.
  3. Inspect: request and copy one source path behind the roadmap.
  4. Propose: choose one proposal type, state the change and reason, and add evidence paths when required.
  5. Copy: submit, inspect Last emitted event, and use Copy event JSON to take it to owner review.
