# Shared Context: UI Meta-Type Formalization

## Authority Precedence

1. Root DS-D1 and DS-D8 definition artifacts remain authority.
2. Accepted UI11 review findings govern the current deferred recommendation.
3. Existing meta-type formalization research governs the public structural
   method and private-engine boundary.
4. This package owns candidate hypotheses, experiment evidence, and planning
   only.

## Stable Constraints

- All 11 UI labels are currently formation-deferred.
- DS-D8 endpoint use creates evidence pressure but cannot promote DS-D1 nodes.
- Per-instance criteria use structural `.schema.yml` plus bounded table walks.
- A self-declared tag or raw edge-participation difference does not establish
  non-collapse.
- Every survivor needs human and machine twins, malformed and neighbor
  fixtures, correction contract, tests, real-corpus evidence, portability, and
  an owner gate.
- No canonical definition, schema, validator, registry, or relationship is
  mutated by this planning package.
