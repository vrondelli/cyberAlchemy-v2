# Implementation Layering

## L0 — Admission boundary

Question: can a development profile explicitly admit structured node logic and
can the compiler reject all unadmitted or malformed logic?

Evidence: positive compiler fixture, no-profile negative, wrong-kind negative,
wrong-version negative, malformed-envelope negative, deterministic build.

Promotion unlock: G-SFOL-06 may close only after one canonical proof context
projects the exact logic owned by a source node.

## L1 — Finite semantic evidence

Question: can the framework derive, run, evaluate, receipt, and replay effect
cases with the same expected-value separation and exact-set discipline as pure
cases?

Evidence: effect fixture digest validation, exact-one binding, raw trace,
independent relation evaluation, mutation detection, exact stage sets, replay.

Promotion unlock: adoption may require effect roles without inventing
consumer-local proof semantics.

## L2 — Canonical consumer build

Question: can Financial Settlement encode the experimental proposed pure/effect profile in
canonical nodes and regenerate the complete proof context twice identically?

Evidence: experimental source-proposal artifact, direct-user test-lane
authorization, node schemas, graph, source manifest, build receipt, build
verifier, projection receipt. Formal G-SFOL-01 source-owner approval remains a
separate parent-lifecycle gate.

Promotion unlock: experimental adoption becomes executable. Formal
SWU-SFOL-011 status remains gated until the declared Financial Settlement
source owner approves the exact semantic digests.

## L3 — Adoption proof

Question: does the unchanged framework detect an incorrect Financial Settlement
implementation for every admitted clause and replay the passing evidence?

Evidence: joined pure/effect exact-set report, negative/mutation tests, replay,
no-core-change audit for the adoption unit, existing BTE verification.

Non-promotion: success proves the experimental admitted profile only. It does
not prove all Financial Settlement behavior, accounting correctness, release
admission, or production authorization.
