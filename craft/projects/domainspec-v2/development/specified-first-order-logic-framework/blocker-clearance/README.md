# DS-SFOL Financial Settlement Blocker Clearance

This package turns the two recorded SWU-SFOL-011 entry gates and one newly
confirmed framework gap into five bounded implementation units.

The target is an experimental, non-release Financial Settlement proof:

1. canonical per-node machine sources admit `domainspec-node-logic/v1`;
2. the compiler validates that admission, preserves canonical structured-value
   equality in the graph, and separately binds source bytes through the source
   manifest and build receipt;
3. an experimental proposed finite clause/fixture universe is explicit;
4. pure and effect cases both produce exact-set proof and replay evidence; and
5. Financial Settlement is regenerated deterministically from the canonical
   sources.

Start at [WORK-PACK.md](WORK-PACK.md). The package does not grant release,
production, accounting-policy, or public-publication authority.
