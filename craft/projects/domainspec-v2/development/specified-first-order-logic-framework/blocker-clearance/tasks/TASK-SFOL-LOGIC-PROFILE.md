# TASK-SFOL-LOGIC-PROFILE

## Objective

Make node logic an explicit development-profile capability instead of an
accidentally preserved object inside `body`.

## Dependencies

SWU-SFOL-010 canonical projection is passing.

## SWU-SFOL-BC-001

- Primary behavior: validate profile admission for `body.logic` before graph
  construction and preserve the accepted canonical structured value
  losslessly while the manifest separately binds source-file bytes.
- Inputs: explicit development registry, logic-envelope schema, minted nodes.
- Outputs: compiler diagnostics and one canonical projection proof.
- Algorithm:
  1. Extend the internal profile shape with an optional logic contract that
     binds the envelope schema by path and SHA-256.
  2. If a node has `body.logic` and no contract exists, reject it.
  3. Require an admitted node kind and `domainspec-node-logic/v1`.
  4. Validate the envelope schema, leaving deep AST validation to the DS-SFOL
     decoder.
  5. Build twice and compare every generated byte surface.
  6. Project the module from graph/manifest/build handles.
- Edge cases: absent logic remains valid; wrong kind/version, malformed
  envelope, and unadmitted profile fail with stable codes.
- Failure modes: released registry changes, deep semantic validation duplicated
  in compiler, logic dropped or normalized, digest mismatch.
- Split analysis: schema-only and compiler-only changes cannot independently
  prove admission; the smallest executable boundary is contract plus positive
  and negative compiler evidence.
- Write scope:
  `impl/spec/sfol-profile/`, `impl/tools/minted-project/compiler.ts`,
  compiler tests, and the BC-001 session-evidence directory.
- Done criteria: all five positive/negative behaviors pass, schema-digest drift
  fails, build is deterministic, canonical logic value equality survives
  projection, source bytes remain digest-bound by the manifest, and released
  profile bytes are unchanged.
- Acceptance evidence: compiler test output, projection output, before/after
  released-registry digest, execution receipt.
- Validation surface:
  `npm --prefix projects/domainspec-v2/impl run tools:test`;
  `npm --prefix projects/domainspec-v2/impl run typecheck`;
  targeted SFOL projection test.
- Execution owner: local-fallback.
- Handoff: refresh closes G-SFOL-06 and returns SWU-SFOL-BC-002.
