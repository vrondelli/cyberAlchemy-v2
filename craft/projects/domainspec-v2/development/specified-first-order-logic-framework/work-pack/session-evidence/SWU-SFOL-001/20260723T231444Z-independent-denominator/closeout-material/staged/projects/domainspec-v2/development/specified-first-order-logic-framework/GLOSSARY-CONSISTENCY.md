## Collision Check

- “Specified first-order logic” is a module-local name, not a claim that
  arbitrary first-order logic is decidable or executable.
- “Complete” is always qualified by the admitted DS-SFOL profile.
- “Proof” means reproducible test-evidence linkage here; it does not mean a
  theorem-prover proof.
- “Binding” never owns expected values.
- “Receipt” is evidence and never promotion authority.
- “Node-owned” means semantic authorship is attached to the canonical node;
  generated graph and manifest rows remain read models, not authority.

No unresolved glossary collision blocks planning.
