# Distill Validation

## Proposer

The narrowest trust-bearing first unit is `SWU-SFOL-001`: define and validate
the independent exact clause denominator before validator, generator, or runner
work can create self-referential completeness metrics.

## Balancer Challenges

| Challenge | Resolution |
| --- | --- |
| “General framework” could become full theorem-prover scope. | DS-SFOL v1 is bounded, typed, finite, and executable; full FOL and solvers are non-goals. |
| One consumer could masquerade as generality. | Require an adopter-neutral core corpus and two independent feature adopters. |
| Generator-derived counts could create another false green. | Denominator is a separate module with forbidden dependency checks. |
| A language task could hide several irreversible changes. | AST/contracts, structured decoder, typechecker, and evaluator are separate SWUs. |
| Effects could be judged by a pure return-value runner. | Pure and effect observation work are split across layers and SWUs. |
| Source approval could block core construction prematurely. | Adoption approval is a later layer-entry gate; core corpus work proceeds first. |
| Markdown extraction could recreate a second feature graph. | The node adapter accepts only canonical graph/manifest/build proof contexts; Markdown and direct node traversal fail. |
| Current node v1 could be treated as “close enough.” | L3 adoption requires a successor node contract that losslessly preserves a typed logic payload. |

## Recomposition Proof

The work recomposes only if:

1. every mutation SWU leaves a validated receipt and deterministic successor;
2. the language, denominator, cases, bindings, observations, and evaluator
   preserve stable identities and digests;
3. the independent exact sets join with no residue;
4. the framework corpus passes before consumer adoption;
5. Financial Settlement and Agent Execution Orchestrator reuse unchanged core
   semantics; and
6. verification replays evidence without trusting authored summaries.

## Result

Pass. The plan uses medium-complexity split mode. The 12 mutation SWUs are
bounded, ordered, independently verifiable, and narrower than their parent
tasks. The closure-only verification task is explicitly exempt from carrying a
mutation SWU.
