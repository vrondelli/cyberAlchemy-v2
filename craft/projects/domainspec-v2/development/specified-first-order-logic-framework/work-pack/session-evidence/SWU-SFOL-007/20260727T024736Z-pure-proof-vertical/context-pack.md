# Context Pack — SWU-SFOL-007

Selected `SWU-SFOL-007` after the passing SWU-006 owner receipt. Scope is only
pure case derivation, raw target observation, independent evaluation,
exact-set proof joining, replay, an adopter-neutral vertical corpus, and this
evidence.

The case deriver may consume typed source logic, denominator membership, and
finite fixtures, but it cannot invoke targets. The pure runner may consume an
exact resolved binding and a target handle, but its invocation contract omits
all expected values and predicates. Independent evaluation consumes source
logic plus the immutable raw observation and cannot resolve or invoke a
target. The proof join requires exact case identities and compatible digests at
every stage and cannot fill or ignore residue.

Missing, extra, duplicate, skipped, todo, stale, thrown, indeterminate,
evaluation-failing, target-mutated, receipt-mutated, and non-allowlisted replay
states must fail. Effects, canonical-node projection, adopters, BTE semantic
claims, authority, release, and production remain excluded.
