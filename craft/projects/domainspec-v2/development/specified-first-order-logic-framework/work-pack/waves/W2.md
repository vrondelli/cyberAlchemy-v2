# W2 — Effects and Canonical Node Governance

## Decision

After this wave, we know whether effectful behavior can be observed within a
declared boundary and whether node-owned logic can enter through the canonical
graph/manifest/build pipeline without losing identity.

## Sequence

`SWU-SFOL-008 -> 009 -> 010`

## Exit Evidence

- finite effect schemas typecheck and evaluate order-sensitive relations;
- missing, extra, reordered, or unobservable admitted effects fail;
- setup, execution, trace capture, and teardown are contained;
- canonical node logic projects bijectively with exact proof-context handles;
- stale/incompatible handles, unsupported versions, duplicate IDs, direct
  node-file input, Markdown input, and invalid ownership fail;
- all L1 guarantees remain green.

Promotion to W3 requires three closeout receipts and adopter source approvals.
