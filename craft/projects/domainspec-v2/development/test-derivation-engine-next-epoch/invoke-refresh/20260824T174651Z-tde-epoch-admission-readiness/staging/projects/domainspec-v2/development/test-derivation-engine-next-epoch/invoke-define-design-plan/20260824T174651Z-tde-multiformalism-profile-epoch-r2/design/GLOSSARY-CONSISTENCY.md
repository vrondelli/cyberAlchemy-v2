# Glossary Consistency

The Define glossary and Design use the same ownership boundaries:

- FormalClaim means the canonical source proposition plus logic-semantics profile.
- executable profile and executable projection remain downstream validation-governance concepts.
- implementation profile means one language renderer/runtime/provider contract.
- semantic parity does not mean byte-identical source.
- theorem-provider lane refers only to EVF-routed formal proof execution.
- needs_formal remains visible with typed upstream reasons.

No Design term redefines FormalClaim as FOL-only, treats Lean as a code backend, admits candidate profiles, or conflates TDE evidence with runtime/theorem proof.
