# Design Transport

Plan receives:

- one exact source/assessment/projection intake sequence;
- one neutral TDE obligation/case IR;
- one non-ambient versioned profile registry;
- independent TypeScript, Python, and Rust renderer/runtime lanes;
- a separate Lean/EVF theorem-provider handoff;
- semantic parity and total non-pass requirements;
- preserved predecessor behavior and separate legacy debts;
- an explicit pre-admission execution block.
