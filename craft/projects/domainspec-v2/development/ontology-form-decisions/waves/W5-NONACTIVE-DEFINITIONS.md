# W5 — Non-active definitions

This is a definitions decision wave, not an implementation architecture wave.

- Page, Layout, Component, View Model, Hook, Form, Action, Guard, and Binding
  remain `wait-for-definition`.
- Adapter remains deferred until evidence separates it from Mapping.
- State Indicator remains deferred until domain state and request state split.
- Saga remains superseded by Workflow and its stable ID cannot be reused.

An active definitions-owner decision returns a card to `inventoried`; it does
not jump directly to an architecture form or implementation queue.
