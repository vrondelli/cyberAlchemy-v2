# TASK-BTE-L7B-BODY-WAR — Machine Consumer And Redaction Proof

## Primary Behavior

Replace Body War's prose/fixture-only handshake with a versioned machine
contract, schema, consumer-owned runner, exact declared writes/redaction proof,
fresh raw receipt, and separate BTE-owned replay against one L6 core handle.
The consumed core must bind the exact candidate denominator of 13 backend kinds
and 17 ordered relationship signatures, including the frozen `creates` oracle
handle; the consumer cannot redefine that denominator.

## Boundary And Outputs

Consumer writes stay under
`cyberAlchemy-v2/development/domainspec-v2/body-war-consumer/`. The package must
declare accepted core schema/version, exact projected IDs/relations/provenance,
public/redacted field allowlist, forbidden private fields, output paths, raw
observations, and receipt schema. BTE writes only its independent replay under
the BTE run root.

## Failures And Exit

Reject absent/stale/wrong core, schema/fixture-only substitution, BTE-authored
consumer receipt, undeclared write, private-field leak, missing required field,
projection mutation, nondeterministic rebuild, literal pass, or stale raw bytes.
Exit is one fresh Body War ReplayResult referencing the same exact L6 handle as
IOLM. It cannot change core truth or admission.

No Body War contract acceptance, run, receipt, or replay is synthesized by this
planning proposal.
