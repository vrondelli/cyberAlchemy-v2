## Complete Proof Unit

The L5 implementation order is fixed:

1. Resolve the exact immutable `ProofContext`.
2. Load a validation-owner-frozen `O_spec` entry.
3. Derive `O_gen` from graph/manifest handles only.
4. Compare exact coverage keys and compatible governing identities/digests.
5. Materialize one pre-run TestCase bundle only after exact equality.
6. Resolve exactly one explicit binding for every required role.
7. Run the bound compiler/runtime and persist raw observations.
8. Evaluate through one bounded evaluator that cannot import the compiler,
   kernel, adapter, graph builder, generator, or result builder.
9. Create a fresh child-lineage primary mutation and require its declared
   phase/code/delta kill; stale-digest rejection alone is not a kill.
10. Emit a ProofReceipt over allowlisted raw handles.
11. Independently replay bytes, schemas, digests, joins, sets, observations, and
    scope recomposition into a separate ReplayResult.
