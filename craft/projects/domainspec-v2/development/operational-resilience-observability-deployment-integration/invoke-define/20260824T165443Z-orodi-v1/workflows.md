# Workflows

## A. Bind and evaluate a finite witness

1. Select one admitted claim set.
2. Bind exact subject, environment, owners, artifacts, profiles, tools, policies, fixture, evaluator, receipt schema, expiry, and invalidation keys.
3. Reject missing, ambient-latest, unowned, or disabled bindings.
4. Activate the declared fault or workload.
5. Record product observations through privacy/cardinality controls.
6. Evaluate required controls independently.
7. Aggregate only the exact claim-specific set.
8. Emit immutable child and aggregate receipts.

## B. Plan/canary/deploy/rollback

1. Evaluate an immutable infrastructure plan; unknown or destructive facts cannot authorize apply.
2. Obtain separate protected deployment authorization.
3. Observe the canary controller and complete stable/candidate evidence.
4. Analyze the canary; missing evidence is inconclusive.
5. Independently observe actual deployment effects for C12.
6. When triggered, actuate rollback through its protected owner.
7. Verify every declared resource has zero candidate reference before the deadline.

This Invoke run executes none of these workflows.
