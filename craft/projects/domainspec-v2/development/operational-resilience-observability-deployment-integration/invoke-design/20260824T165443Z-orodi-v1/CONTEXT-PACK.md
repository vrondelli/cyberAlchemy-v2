# Design Context Pack

Design consumes the accepted findings plus the complete Define package. It must cover authority, failure, state/event, persistence, reliability, integration/versioning, migration, rollout, privacy/data, performance and validation concerns. UX is outside the current target because no human-facing product surface is being designed.

Every concern is source-bound in `DESIGN-SCOPE-MANIFEST.json`; every runtime witness remains planned and unexecuted.
