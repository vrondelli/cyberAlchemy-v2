# UI Evidence Repair Glossary

| Term | Definition |
| --- | --- |
| semantic content | Stable meaning-bearing fields covered by canonical serialization. |
| content digest | Versioned digest of semantic content; excludes chronology and lineage. |
| generation | Immutable production event linked to a predecessor and input handles. |
| parity | Equal normalized outcome and violation code across validation paths. |
| mutation ledger | Append-only results for finitely enumerated structural mutations. |
| mandatory base | The 165 deletion, empty, whitespace, and wrong-fixed cases; not completeness. |
| reroute receipt | Two-sided evaluation of one specimen under source and destination contracts. |
| corpus receipt | Immutable source facts and provenance, separate from reviewer projections. |
| owner packet | Question and evidence handoff that grants no relationship decision. |
| dossier | Conjunctive formation-evidence adjudication over independent evidence planes. |
| typed negative | Explicit rejected claim or closed negative outcome preserved as evidence. |
| `not-observed` | No observation in the declared finite review; not an absence claim. |
| `pending-owner` | External destination or relationship evaluation has not been decided. |
| `DEFER` | Required evidence is missing, disputed, or owner-pending. |
| `DOSSIER-ZEROED` | The finite current dossier has no surviving formation witness; not a type KILL. |
| orchestration index | Append-only references to separately owned evidence records and replay state. |

Canonical DomainSpec and Arcanum terms remain owned by their existing
definition surfaces. This glossary defines only package-local operational terms.
