# Design Transport

Producer: bounded Invoke Design Proposer

Consumer now: parent Invoke Design Balancer and independent final validation

Status: candidate artifacts authored; protected domain gate blocked

The transported unit consists of the closed context/scope/selection evidence,
six-view hardening architecture, exact candidate schemas and instances,
planned fixtures/validator contracts, frozen package manifest, pending Rondelli
and Victor requests, Distill Proposer trace, and helper receipt.

The parent must independently verify hashes, schema conformance, fixed-point
selection, path boundary, planned-witness status, and the Proposer/receipt
claim ceiling. Any parent edit to an acceptance-bound artifact invalidates the
frozen package and requires regenerated hashes, manifest, requests, and future
responses.

No automatic route to Plan is available. The next protected route is exact
Rondelli and Victor admission/verification choreography; V1 additionally needs
a separately authorized checker implementation and execution. This transport
does not send requests, authenticate principals, execute validators, mutate
canonical sources, migrate, promote, publish, or use Git.
