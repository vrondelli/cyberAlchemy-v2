# Template Selection

Selected primary template: `arcanum/spells/invoke/templates/work-pack.md`.

Companions:

- `implementation-layering.md` for the L0-L3 decomposition;
- `domainspec-spec/execution-pack.md` for execution handoff and gates.

The legacy `implementation-plan/implementation-plan.md` template is retired.
`IMPLEMENTATION-PLAN.md` in this candidate is therefore a derived navigation
view; `WORK-PACK.md`, its split task/wave files, the SWU manifest, validation
contracts, and `EXECUTION-ENTRY.json` are the executable planning authority.

Complexity: medium/high. The change crosses FormalClaim, formal-language
profiles, translation, category admission, Lean runtime identity, EVF evidence,
runtime conformance, migration, and C12 pre-merge closure. It is split into 14
single-behavior units so every unit can be independently admitted and closed.
