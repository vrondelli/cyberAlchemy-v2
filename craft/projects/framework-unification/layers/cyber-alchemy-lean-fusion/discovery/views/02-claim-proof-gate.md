# View 02 — Claim≤proof / novelty gate

> Parent: [`../MAP.md`](../MAP.md). Axis: refusing inflated claims as an automatic
> gate, not a label.

## EVIDENCE (owned, anchored)

- **The asymmetry is diagnosed and owned by TO-VLAD5.** `Arcanum/TO-VLAD/TO-VLAD5.md`
  finding #1 (survived both skeptics): *Arcanum gates promotion, never novelty* —
  every gate is existence-gated (contract validates, fixtures pass, no blocker);
  none asks the orthogonal question domainspec forces: *is this actually new?* The
  Arcanum-native fix is a **novelty default** (a sigil claiming "new" carries the
  burden of a registry-check), not three typed-open bins. Collapse-test recorded in
  the memo: *if no two sigils ever overlap in capability, the finding contributes
  nothing* — it grows exactly as fast as the registry.
- **Finding #2 (wounded to magnitude):** Arcanum already enforces claim ≤
  validation-report at the gate (that half is a *rename*, conceded); but
  `QUALITY-BAR.md:25,70` separates evidence/inference **by label only** — silent on
  whether a labeled "inference" overclaims its magnitude.
- **domainspec owns the discipline being ported.** `domainspec-theorem/CLAUDE.md`:
  the subset rule (claim ≤ proof), four stop-triggers, typed-open, collapse-test —
  cited as the benchmark in TO-VLAD5's first section.

## INFERENCE / SEAM (partly owned)

- **Owned half (do not re-claim):** claim ≤ validation-report at the promotion gate
  already exists in Arcanum — porting it is a rename.
- **Open half:** (a) the **magnitude** check on labeled inferences (QUALITY-BAR is
  silent); (b) the **novelty default** as an actual gate, not prose; (c) wiring the
  subset-rule check so a Pass/Flag/Block verdict is *computed from claim vs evidence*,
  not asserted by a reviewer.
- **Collapse-test (carried from TO-VLAD5):** the novelty gate contributes only as
  fast as the registry grows overlapping capabilities; on a ~12-sigil registry it is
  near-vacuous today.

## STATUS

**PARTLY OWNED.** The label-deep half is a rename (conceded). The magnitude +
novelty-default + auto-verdict half is open and is the honest build target (the
View 02 `subset-rule` gate sigil).

Owner for any change to the Arcanum gate: TO-VLAD5 / `QUALITY-BAR.md`
(Authority-Bound Composition). Build target: the smallest `subset-rule` gate sigil
(see `../../DESIGN.md §6`).
