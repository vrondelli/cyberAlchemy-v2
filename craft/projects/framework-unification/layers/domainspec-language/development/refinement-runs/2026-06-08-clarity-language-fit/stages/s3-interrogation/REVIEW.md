# Interrogation refine-review — Dialectic Convergence (s3)

Roles: language-fit-advocate vs language-fit-skeptic (briefs in this folder).
Pattern: dialectic + zig_zag. Convergence criteria: a recorded position + the
bridge condition named.

## The remarkable result: both sides converge on the same line

- **Advocate** (load-bearing): the functor needs a target category `S`; the
  language is that schema side; the contract layer's `obligation_id`s are exactly
  what lifts P3 from stub to real. **Honest concession:** that layer does not
  exist yet (B-1 open, obligations still prose); the language is load-bearing
  *by design and stated dependency*, not yet *by running wire*.
- **Skeptic** (incidental): the σ-model's vocabulary source is `domainspec-core`
  + paper tables, never the DESIGN-PACKAGE; the translator maps to `Meta`/
  `EdgeType`, and the language's doc kinds/envelope/lifecycle appear in **no**
  Lean module. **Honest concession:** the bridge is already *designed* —
  TRANSLATOR-DESIGN defers P3/P4 "gated on B-1"; once P3/P4 source a
  contract-shaped obligation table, the language **stops being incidental** and
  becomes the obligation authority for half the grading surface.

## Convergence
Both agree on the **exact same boundary**:
- **Today (shipped Layer-1: P1/P2/P5):** the language is **incidental**. The
  σ-model is self-contained; nothing in the Lean path imports the language.
- **At the P3/P4 wiring step:** the language becomes **load-bearing** for the
  *completeness/obligation* half of the verdict — iff obligations are authored as
  addressable `obligation_id` predicates indexed per Meta/EdgeType, and the
  graded σ/obligation table is **derived from** contract/schema artifacts rather
  than hand-maintained.

## Recorded position → verdict = PARTIAL-BRIDGE (see s5)
Neither pure load-bearing nor pure incidental. The disagreement dissolved into a
**time/scope split**: incidental for the structural half (P1/P2/P5), load-bearing
for the obligation half (P3/P4) **once the bridge is built**. The bridge is B-1 +
"derive the table from the language, don't hand-maintain it."

## Residue
- The bridge is currently **designed, not wired** — so any present-tense "the
  language helps the validator" claim is premature; it is "the language is
  *required to* help, on the P3/P4 build path."
