# Decision — Explainer Format (gate g-format-decision)

- Decision id: DEC-FMT-01
- Status: decided

## Choice: **Executive-narrative with an embedded assurance ladder + appended FAQ**
A hybrid of the three menu options:
- Lead with the **executive narrative** (pitch → problem → language → validator →
  two-locks-one-key) so a non-technical reader is hooked in the first minute.
- Embed the **assurance ladder** (proven / machine-checked / human-judged) as the
  trust spine — this is what a due-diligence advisor turns to.
- Append the **skeptical-buyer FAQ** and a **"built today vs roadmap"** box.

## Why
The buyer is non-technical but brings a technical advisor. Narrative wins the
buyer; the ladder + FAQ + current-state box win the advisor. Leading ladder-first
(option 2) would lose the non-technical reader; FAQ-first (option 3) presumes
hostility. The hybrid serves both audiences in one 5-minute read.
