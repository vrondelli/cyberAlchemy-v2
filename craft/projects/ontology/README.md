# Ontology Project Witness

Status: private witness/incubator
Owner: domainspec-core parent workspace and future owner routes
Boundary: not current CyberAlchemy v2 ontology authority

This folder preserves project-local design evidence for ontology
materialization. It records how source selectors, inventory evidence,
ontology candidates, PromotionRecords, and governed projections can fit
together without treating a file path, generated inventory page, or folder name
as ontology authority.

The current CyberAlchemy v2 base ontology package lives in
[`../../cyberAlchemy-v2/ontology/`](../../cyberAlchemy-v2/ontology/). Use this
project folder as witness/incubator material for future crosswalks, examples,
or owner-gated promotions. Do not treat it as a competing base ontology package.

## Allowed Reading

- Evidence of a prior materialization design.
- Private-parent witness material for crosswalks into the CAV2 ontology package.
- A source of examples for selector -> evidence -> candidate -> PromotionRecord
  -> projection workflows.
- A place to preserve blocked or candidate design residue until an owner route
  accepts, harvests, or retires it.

## Forbidden Reading

- Not current CyberAlchemy v2 ontology authority.
- Not a definitions, specs, schema, or promotion owner.
- Not evidence that branch-as-view, run-view, or residue-view names are
  canonical.
- Not a reason to write private parent evidence into public `arcanum/`.
- Not a folder to collapse into `cyberAlchemy-v2/ontology/` without an explicit
  owner decision.
