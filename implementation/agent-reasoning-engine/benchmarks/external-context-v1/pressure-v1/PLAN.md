## Frozen condition and budget

After the first successful source read, or after turn4 if none occurred, append one explicitly labelled synthetic padding message: 6,000 repetitions of `pressure ballast `. This is artificial pressure, not model-authored history or genuine repository evidence. No gold, hidden tests, reference patch or human-selected solution path is added.

At the next generation call the real tokenizer must trigger recycling. Refuse model dispatch if its prompt still contains the ballast. If message size exceeds existing transport limits or the tokenizer does not force a transition, record failure and stop; never silently alter the threshold or padding. If the model finishes before injection, record unexercised. No padding is sent to model generation; it is measured by the tokenizer and retained in the local archive. Later explicit archive retrieval can encounter labelled ballast.

One episode only: at most12 model and24 tokenizer calls, no retries, 60s model-request timeout, 720s episode deadline, USD0.05 reserved ceiling; sandbox and evaluator unchanged. Previous final timeout remains a separate unresolved issue; do not enlarge it inside this experiment.

## Acceptance

Live: attributable transition, stable handle per generation, no repeated delivered page, useful post-transition source retrieval, separate patch outcome. A missing or rejected patch is not a semantic test failure. Evaluate only accepted patches with the existing isolated evaluator and report its custom-harness limitations.

One previously seen development task with artificial pressure is a mechanism check, not natural-pressure prevalence, an official benchmark score, or GLM qualification. Source index and cursor remain a compound treatment. No fresh matched baseline is claimed.
