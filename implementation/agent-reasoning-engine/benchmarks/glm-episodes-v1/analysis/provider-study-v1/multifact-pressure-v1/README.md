# H22 multiple-fact construction

This package implements the fixture and recorder stages of [the pressure plan](../research/pressure-frontier-v1/PLAN.md). H15 and H21 candidates remain unchanged. Six fresh fixtures cross 8K/10K/12K with co-located final evidence versus two earlier independent evidence sources. Each arm makes the same six reads plus submission. routeCode combines independently highest-revision route/region values and preserves stableLabel. Hidden task/oracle data never enter the agent fixture.

Local construction uses a scripted responder and constant token measurements. Exact per-fact source bodies are verified independently of echoed answers, and captured model/tokenizer bytes match receipts. No pressure behavior or live GLM quality follows from these checks. Existing H21 pressure evidence is not repurposed as actual capacity calibration.

Product frontier: complete local recorder/oracle tests, then separately bind actual-tokenizer-only calibration (maximum proposed 96 tokenizer attempts, zero model calls, no retries). Owner: ARE implementer/evaluator. Dependencies: H22 candidate hypothesis and experiment, original H15 and H21 sources, existing source adapter, runtime and pinned sandbox. Product integration, serving activation and publication remain separate user-owned decisions.
