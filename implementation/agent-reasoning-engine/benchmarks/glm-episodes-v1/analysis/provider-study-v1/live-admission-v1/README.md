# H21 live admission-before-masking pilot

Hypothesis: complete inspected history, when admitted by the actual tokenizer, avoids ordinary evidence masking without extra model calls. This is a separate live test of the existing H21 candidate, following the completed H20 review. Exact ontology dependencies are H21 in ../admission-before-masking-v1/hypothesis.json, its local verification and the completed H20 review; experiment, observation and learning-decision constructors project candidate research evidence only.

## Frozen comparison

24 rows, 12 matched pairs: three windows (8K/10K/12K), two repetitions, visible/delayed conditions, baseline/admission arms. Fresh deterministic facts and opaque note paths use an H21-specific seed. Repetition two keeps the same value across revisions. Only allowlisted source and notes reach the model; task metadata and oracle stay outside its fixture. The baseline and candidate share instruction, tools, paging, patch contract and dispatch caps. The candidate differs only in initial history projection, retaining the existing admission/fallback machinery. Serving behavior is unchanged.

Support requires 6/6 visible controls in both arms, at least 5/6 delayed candidate successes, at least three delayed net wins, exact decisive original file bodies at the final selected request in at least five delayed candidate rows, and candidate total model attempts no greater than baseline. Echoed answers do not count as preserved original source. Incomplete or unknown evidence, unexpected exposure or actual recycling yields an inconclusive mechanism screen; all failed acceptance floors remain reported. Correctness is measured in the existing pinned container separately from schema and required-read completion. Do not execute generated source on the host.

Physical caps remain 320 model/640 tokenizer attempts across the whole schedule, one worker, zero automatic retries and no failed-row replacements. Each dispatch uses actual tokenizer admission with the existing headroom. Record tokenizer counts and headroom separately from model-call cost. Stop on transport, uncertain reservation, source drift or sandbox cleanup failure; retain failures for review before any unstarted remainder. H20 and the original cohort must be complete before this cohort starts.
