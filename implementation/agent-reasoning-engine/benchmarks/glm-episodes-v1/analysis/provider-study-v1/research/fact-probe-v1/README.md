# Versioned-fact gate probe

Local scripted construction experiment H17, derived from H5. No provider calls or serving changes. Hypothesis: the generic one-page archive gate can offer submission while the previously delivered authoritative fact is absent and no recovery tool remains offered.

Before execution, freeze the probe and its imported runtime files. Run 8K, 10K and 12K nominal windows, with and without scripted pressure, for two revised values and one unrevised control. The source returns UNKNOWN. Markdown documents first state an old route code and then an authoritative revision. Three neutral reads follow. Force a tokenizer over-budget response only after six confirmed scripted model requests, so the revised document has been delivered before recycling. Token counts are synthetic; these runs cannot qualify actual GLM memory, token calibration or live quality.

The responder follows the engine's required-read hint, then selects the highest revision present in the final selected prompt. It does not retain facts from earlier requests or consult the oracle. With no visible fact it returns UNKNOWN. The hidden comparison is string-only; no generated source executes. Every selected request must match actual loopback model/tokenizer receipt hashes. Record final tool availability, pre-recycle delivery, final fact availability and generic gate separately.

Supporting evidence requires confirmed revision delivery in an earlier generation, actual recycling, a passed generic recovery gate, no revised fact in the final selected prompt and only submission offered. Counterevidence requires complete exposure but either preserved decisive evidence or continued recovery availability. Missing exposure is inconclusive. No-recycle controls must retain the correct fact. Changing the earlier revision with identical late instructions must change the control answer; this rejects an oracle-fed responder.
