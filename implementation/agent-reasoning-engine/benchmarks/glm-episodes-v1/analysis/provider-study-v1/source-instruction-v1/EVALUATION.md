This clarification is written before the first H15 provider call. The frozen [experiment](prepared/experiment.json) and eight-row schedule remain unchanged. H14's [complete cause audit](../contract-window-v1/cause-summary.json) motivates measuring unchanged source before schema admission: one no-op was also schema-invalid.

For every completed row, verify the complete raw response hash, parse it with the canonical bounded parser, and preserve all canonical schema diagnostics. A raw unchanged-source observation requires exactly one replacement of the allowlisted source, the expected base and file hashes, and string source bytes. Compare those bytes with the original fixture regardless of schema validity. Unreadable or out-of-scope proposals are unknown, never evidence of a successful repair or reduced no-op rate.

Use the pinned container oracle on every attributable raw source, including schema-rejected and unchanged proposals. Retain the original qualified endpoint separately. Never fill schema fields, replace failed trials, expose hidden oracle feedback to the model, or pool H14 observations into this pilot.

The mechanism screen supports H15 only when all eight rows complete with attributable source and semantic outcomes, treatment has fewer unchanged-source proposals than baseline, treatment has at least as many raw semantic passes, and no dispatch or delivery safety violation occurs. A zero baseline no-op count makes the mechanism comparison inconclusive. Transport, missing attribution, or incomplete rows also remain inconclusive. Otherwise failure of the predeclared reduction or semantic condition is counterevidence. Report paired outcomes and window strata without a statistical or generalization claim.

Before live dispatch, pin this evaluator document by SHA-256 in the execution evidence together with the prepared manifest digest. The separate live-effect assessment must state the fixed cap: 96 model and 192 tokenizer attempts, concurrency one, no retries. Confirm H14's process terminated and its lock is absent. Preparation does not itself dispatch calls.
