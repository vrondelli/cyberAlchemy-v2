# ARE documentation

The complete product manual starts at [`docs/README.md`](docs/README.md).
It covers the supported Candidate 018 product, local use, architecture, agent
integration, operations, evaluation, release evidence, and contribution.
The [documentation coverage map](docs/DOCUMENTATION-COVERAGE.md) connects every
reader question to its owning guide. Release-readiness pages already exist with
explicit lifecycle states: they expose blocked deployment, migration, security,
service, and compliance work without presenting those boundaries as active.

The documentation candidate has its own
[release manifest](docs/release-manifest.json) and
[verification receipt](docs/release-receipt.json). The manual remains outside
the immutable Candidate 018 product closure.

The implementation [README](README.md) remains the compact command reference.
Machine-readable product scope remains in [`product.json`](product.json).
