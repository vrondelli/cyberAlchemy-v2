# Single-Chat Product Prototype

Status: non-authoritative D65 scaffold  
Primary user: a developer collaborating with CyberAlchemy  
Authority effect: none

The user sees one transcript and one composer. They describe work naturally,
correct earlier statements, request research, ask for a plan, or request a
bounded implementation without changing product workspaces. ARE changes its
internal route and context while the visible conversation continues.

Progress, questions, blockers, diagnostics, proposal reviews, and exact human
decision gates appear inline. A blocked, rejected, completed, or verified turn
returns to the same composer when ARE declares continuation available.

Success means the user can continue the work without understanding ARE package
boundaries, while consequential effects remain explicit and fail closed.
