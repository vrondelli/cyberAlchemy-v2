## Failure and analysis rule to freeze

Use **zero automatic model retries and zero task replacement**. The live factory pins `maximum_model_retries:0`; the provider-health and comparison accounting require one successfully terminal attempt with known usage. Although the underlying GLM transport has a bounded retry mode, the current G01 health, episode, and campaign boundaries reject retried attempts. Enabling it as a configuration-only change would be unsound. A timeout, budget exhaustion, provider refusal, missing receipt, or failed native score remains a failed or unscored attempt in the frozen 24-pair audit. Do not top up a control or score an unsealed prediction. Report unknown spend explicitly.

The primary product-headline gate remains strict: **24/24 native-scored pairs**, no unresolved score/label integrity issue, and the predeclared paired repository-stratified 95% intervals for both Span-F1 and File-F1 differences wholly above zero and known model-token and summed arm-time ratios wholly below one. Use the pinned 20,000-resample method on complete paired rows; report absolute arm means, paired differences, intervals, validity, all failures, and per-task results. If any pair is unscored, the directional headline gate fails regardless of favorable valid-pair estimates. Do not pool r2/r3/r4.

As a separate all-attempt reliability readout, report final-selection/native-score completion for each arm over all 24 tasks, paired completion categories (both, ARE-only, control-only, neither), every failed-attempt code and known/unknown usage, and campaign wall time. This readout does **not** silently impute missing F1, relax the 24/24 quality gate, or become a substitute superiority headline. Reviewer interpretation of any incomplete campaign must be explicitly qualified.
