## Research follow-up, not an active intervention

[AutoFL](https://coinse.github.io/publications/pdfs/Kang2024ay.pdf) uses bounded
tool-driven access to covered classes/methods and method implementations before
localization. That uses execution coverage we do not currently provide for all62
cases; it is not equivalent to our stack-only lexical graph.
[LocAgent](https://aclanthology.org/2025.acl-long.426.pdf) separates entity search,
typed graph traversal and entity retrieval, with folded/preview/full source views.
Its evaluated code backbone is Python, not this Java campaign. A Java adaptation
with complete method excerpts is a research inference, not a reproduced result.

Source-only shape audit of1509 combined candidate excerpts:343 start at line1,
740 contain a package/import statement, and373 match a conservative method-body
heuristic. These counts are neither gold-method coverage nor reader correctness;
they motivate examining source-delivery quality after sealing all paired answers.
Any method-aware or adaptive reader requires a new prospective freeze and equal
budget controls. Do not change this running experiment using interim responses.
