# G02 r11 import-bound call navigation — exposed source pilot r1

## Prospective mechanism and scope

The prior [active-anchor screen](G02-R11-ACTIVE-VERIFICATION-SOURCE-SCREEN-R1-2026-10-05.md)
has insufficient candidate concentration. This successor resolves actual call
sites, rather than lexical same-name definitions or module import neighbors.
[LocAgent](https://aclanthology.org/2025.acl-long.426/) motivates typed invocation
relationships; this conservative Python transfer is not a paper replication.

Freeze before generation/scoring: all12 already-exposed G02 r11 tasks, their
pinned buggy-base trees, sealed selected ARE spans and delivered-path ledger.
Read only tracked regular Python files <=262144 bytes. Parse ASTs; report
syntax/size exclusions. Non-Python tasks remain explicit abstentions in the full
denominator. No reference patch, gold, DSH output or native score in generation.

Only direct module-body imports establish bindings. Resolve absolute imports or
valid relative imports under repository root, lib/ or src/. Require a unique
module path and direct function/class definition (or a directly declared class
method); no guessing by terminal name, dynamic imports, re-export inference,
instance type inference or execution. Multiple bindings, assignments or function/
class declarations shadowing an import reject it. Conservatively reject aliases
that occur in parameters, assignment targets, nested/local imports or enclosing
class/local declarations. Calls must fall in an already-selected span. Preserve
source/call/target SHA256, call line, bound qualified name and definition line.

Candidates must be outside both selected and delivered paths. Rank by exact
case-sensitive issue mention of the resolved target name, distinct source origins,
distinct call sites, smaller target definition line span, then lexical path.
At most3 file proposals per task. Keep target bodies/witnesses as source evidence,
not a model-produced confidence or an evaluator-derived oracle.

exact policy. A pass requires separately frozen integration/quality/cost testing.
Preserve all earlier failed gates and unopened confirmation partitions.
