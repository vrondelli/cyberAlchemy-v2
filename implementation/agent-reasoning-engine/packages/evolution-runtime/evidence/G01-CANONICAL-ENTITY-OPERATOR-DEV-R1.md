# G01 canonical entity/operator navigation — exposed pilot r1

## Hypothesis and freeze

Source-declared symbols and exact qualified entities can seed bounded source
navigation more usefully than generic query expansion. This follows the
[canonical-source diagnostic](G01-CANONICAL-SOURCE-DEV-R1.md); all62 r3/r4 cases
are exposed development. Policy selection used their diagnostics; generator
label blindness does not make this confirmation. No gold file/path injection.

Freeze before full-cohort generation: keep the canonical caller candidate union;
add at most4 missing production files from witnessed lexical navigation. Match
each variant with the same number of expanded-query BM25 additions. Preserve all
cases and base candidates. Mathematical maximum36 candidates, not a silent
truncation to the old observed width. No providers, fresh labels or publication.

Source corpus, query views and first20kUnicode projection remain identical to the
canonical source seals. Resolve only uniquely matched source-declared package +
filename types. Qualified names in the recorded failure seed their enclosing
outer type, including nested `$` names; at most8 unique entities in query order.
Parse operator tokens only inside the explicit `Evaluating <...> expected:`
failure expression, excluding quoted literals. Accept only source `String
getSymbol()` implementations whose body is a direct, short literal return;
comment/string impostors and unresolved getters do not qualify. At most8 symbol
seeds in path order. No hard-coded expected class names or invented operator-to-
class dictionary.

Combined seed order: operator aliases, qualified entities, every retained-frame
matched source path, then caller production top5. Deduplicate paths. Use the
existing masked-source package/import/type graph with degree-normalized .75
outgoing/.25 incoming mass, two hops, second-hop half weight, seed1/(ordinal+1).
Direct seeds additionally contribute1/(direct-signal ordinal+1) to their own
files. Rank by score, expanded-query production order, then lexical path.
Retain witnesses for each added file. This is lexical file-level type navigation,
not compiler-validated call/dataflow binding or GraphCoder/DraCo replication.

Primary is combined. Two diagnostic seed ablations omit operator or qualified
direct signals while retaining common frame/fallback seeds. They cannot replace
the primary after scoring without a new prospective development freeze.

Require complete canonical mappings, no base reach losses, primary net gain>=2
over equal-width control and a positive primary gain in each cohort. Also test
whether candidate reach can clear the unchanged24 absolute hits, six-hit relative
advantage and MRR+.10 ceilings. A source pass is not reader accuracy or superiority.
If primary fails, no GLM replay or fresh confirmation for this exact policy.

comparators and budget/tokenizer admission before any calls.
