## Proposed claim

On a prespecified, previously unexposed **40-question LongMemEval-S cohort spanning five available question types**, with **GLM-5.3-flash at an 8K request window**, ARE's ranked memory projection answered **22/40 (55.0%)** correctly versus **5/40 (12.5%)** for a sequential retained-note control. The paired accuracy difference was **+42.5 percentage points** (stratified paired-bootstrap 95% interval **+27.5 to +57.5 points**).

All 40 questions had paired answers and all 80 blinded native-rubric judgments were valid. There were **zero provider refusals**, **zero invalid judgments**, and **zero task replacements**. The frozen accuracy-only gate and independent receipt/metric audit both passed.

## Essential limits beside the claim

This is the selected five-type cohort, **not all six LongMemEval-S types**: the preference-question supply was exhausted before r6. The result concerns this GLM model, window, two specified memory strategies, dataset revision, and September 2026 campaign. It does not establish full-benchmark, general-workflow, all-model, cost, speed, or broad ARE-product superiority. Token and summed arm-time ratios are deliberately omitted from this accuracy-only card; summed arm time is not wall-clock speedup.
