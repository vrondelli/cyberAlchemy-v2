# G02 broad clause hints — exposed development screen passed

This one-task screen expanded deterministic pinned-base hints from at most
eight to at most twenty clause-diverse code and non-code leads, delivered them
in the actual compact system message, and limited generation to twenty model
calls. The first captured request contained all twenty hints. The task was
already exposed by earlier G02 development screens; this is not prospective
confirmation.

ARE completed a valid native selection in 15 model calls, 118,270 known model
tokens, zero unknown-usage requests, and 172.34 seconds. Native Span/File-F1
was `0.4643944005`/`0.4137931034`. The pinned same-task DSH development row
scored `0.3960750270`/`0.4000000000` in 482,228 tokens and 223.41 seconds.
Thus both quality metrics rose and both measured costs fell on this exposed
screen. The [native screen](native-screen/screen.json) passed its fixed gates.

but excludes source checkouts and credentials. VPS run root:
