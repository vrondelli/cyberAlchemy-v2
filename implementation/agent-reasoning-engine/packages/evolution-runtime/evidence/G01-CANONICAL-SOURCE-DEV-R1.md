# G01 canonical-source exposed development

## Purpose and boundary

Resolve the [fixture-fidelity defect](G01-DEFECTS4J-TRACE-SOURCE-AUDIT-R1.md)
before further G01 tuning or confirmation. This is all62 already-exposed r3/r4
cases, not a new confirmation partition. Historical receipts and failed gates
remain unchanged. Canonical corpus repair is not itself an ARE algorithm gain.

The pinned Defects4J framework constructs each buggy fixture in trusted WSL
preparation. That stage internally consumes fixed source, inverse patches,
test/dependency fixes and gold-derived build properties. Only tagged buggy Java
blobs and projection receipts reach ranking consumers. No consumer traverses Git
history, fixed tags, patches, properties or raw preparation logs. No provider
calls, fresh cases, publication or deployment are included in this stage.

availability for other project builds remains distinct from source construction.
No new tooling/provider dependency is a reason to change the benchmark gate.

## Research-backed next hypothesis

[GraphCoder](https://arxiv.org/abs/2406.07003) uses structural code-context graphs
and coarse-to-fine retrieval for repository-level completion.
[DraCo](https://arxiv.org/abs/2405.19782) retrieves code entities through extended
dataflow relations. Their completion results do not establish Java failure-
localization performance for ARE; no replication or equivalent implementation is
claimed here.

Our transfer hypothesis, inferred from that structural-retrieval direction and
the exposed diagnostics: seed bounded source navigation with exact qualified
entities in the failure text and source-declared symbolic aliases, then follow
source-backed type/inheritance relationships. Buggy JxPath source explicitly
declares `getSymbol()` literals such as `=`, `>` and `<`; this permits a source-
witnessed bridge from an evaluated expression to code entities without hard-coding
gold class names. Generic basename/import graph expansion already failed in the
old bare-Git pilot; this would be a distinct seeded policy on the canonical corpus,
not retrospective admission of that failed experiment. Freeze it before full-
cohort source generation, preserve base reach, include an equal-width expanded-
query control, and keep generator label-free. Full cohort evaluation, ablations
and fresh transfer—not the papers alone—must determine whether it helps.
