## Next mechanism boundary

The observations identify two distinct failures: (1) source navigation/region extraction loses answer-bearing neighboring states or whole control subtrees; (2) the reader can still omit an item even when the exact ordered menu is supplied. The next candidate should be a **general question-to-evidence interface**: query decomposition into target UI surfaces, action transitions, and reusable procedure/premise notes; source-linked bounded regions instead of isolated keyword lines; deterministic list/filter operations when the question requests exact set membership; and explicit uncertainty when a target surface is unobserved. The pinned [official AgentRunbook-R implementation](https://github.com/xiaowu0162/LongMemEval-V2/blob/main/memory_modules/agentrunbook_r.py) uses separate raw-state, event, and note queries and pre/post evidence, which is a research lead, not evidence that ARE would improve by importing it. Screen a new mechanism on the exposed 28+26 before consuming independent reserve IDs. Preserve the 140-question confirmation set and the failed r18 threshold.
