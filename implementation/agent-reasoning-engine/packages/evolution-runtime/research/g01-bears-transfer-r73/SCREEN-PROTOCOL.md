superiority claim. The Bears official repository at commit
`f69ba79793e8dc05888e588660d8e3bb74538d79` supplies 251 original
metadata records and 118 currently active bug IDs. Preserve those two
denominators. Do not count all 251 as currently runnable.

Reconstruct the 246 previously occupied BugSwarm repositories from the exact
manifest sources used by r71; additionally exclude the 12 distinct BugsInPy
r1/r2b projects and seven exposed ARB v2 trace2code projects, including
case-insensitive owner/name aliases. Iterate Bears `docs/data/bears-bugs.json`

repository. Project only repository identity, bug ID, branch, original buggy
commit SHA, and failure details. Do not export `diff`, `patchDiff`, fixes,
passing code, or gold paths to source-side files or the VPS.

under a separately fixed source-cap policy, before any model request.

order, never a quality outcome. Java is a new transfer population and will
need a fresh protocol for input queries, baseline, treatment, label rule,
cost, statistical gate, and claim ceiling. It cannot silently inherit the
Python r72 success gate or be called an unchanged r61 replication.
