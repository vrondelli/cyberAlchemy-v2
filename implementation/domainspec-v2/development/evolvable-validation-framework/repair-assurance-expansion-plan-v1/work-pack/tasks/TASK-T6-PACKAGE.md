# T6 — Assemble the measured service candidate

Layer/slice: L4/S5. DAG: N, O. Complexity: medium.

## Objective and SWUs

- SWU-T6-01: create private templates for property/scope intake, implementation
  binding, counterexample or typed non-result, defect explanation, optional
  repair, bounded retest, evidence manifest, reviewer report, residual risk,
  data handling and pilot acceptance.
- SWU-T6-02: compile measured engineering/reviewer/setup/compute/retest effort
  from L2/L3; model delivery ranges and obtain product-owner pilot/revise/defer
  decision.

Every service claim must trace to evidence from both target types or be labeled
proposal/open question. Pricing inputs use measured work; no price, SLA,
certificate, customer promise or success guarantee is invented.

Failure modes: presenting mutation calibration as natural defect discovery,
calling technical replay independent accreditation, hiding no-result outcomes,
mixing repair authorship with oracle approval, unsupported general correctness,
or missing customer data/access boundary. Claim audit rejects the package.

Write scope: new private service-candidate and decision artifacts only. No
customer contact, sharing, publication, deployment or certification application.

Done evidence: complete template set, traceability matrix, measured unit-
economics assumptions, qualification boundaries and attributable product-owner
decision about whether to seek a separately authorized bounded pilot.
