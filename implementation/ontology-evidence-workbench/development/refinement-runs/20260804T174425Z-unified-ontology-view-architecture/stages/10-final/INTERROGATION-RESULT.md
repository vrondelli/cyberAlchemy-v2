# Final Architecture Interrogation

Status: pass with named non-blocking residue.  
Mode: refine-review synthesis.  
Roles: semantic fidelity, user comprehension/navigation, implementation executability, evidence/authority.

## Questions and findings

### Does the architecture reuse the best existing ontology-view work?

Yes. It combines the typed view roles and sequences from Augmentor, model/layout separation from Unified Canvas, lossless/static/browser contracts from the Body War atlas, exact evidence/index/focus semantics from OEW, digest-bound nonvisual projections from Anime, and explicit claim ceilings from CyberAlchemy. It deliberately rejects the monolithic explorers, separate focus/evidence renderers, per-edge flat portals, whole-graph force default, color-only meaning, and compiled-bundle patching found in earlier families.

### Can arrows, colors, icons, portals, and Path coexist without semantic loss?

Yes at contract level. Every arrow is one real path keyed by exact source relation ID; predicate color is one-to-one by exact predicate and redundantly labeled/patterned; icons supplement node text; Grouped Portals retain every cut-relation constituent; Path hops select the same relation record used by graph, inspector, and index. The toy game proves the contract catches thirteen deliberate degradations. No implementation proof exists yet.

### Does bounded navigation hide the full ontology?

No. Home/focus scenes have numeric caps, while Full Index and the linear projection remain complete and distinguish the 577-row denominator from filtered counts. Back restores the complete Navigation Frame. A failed renderer degrades to those complete projections rather than showing a semantic black box.

### Are clusters accidental layout groups or ontology claims?

No. A versioned View Pack is the sole membership owner. The planned Body War pack is explicitly candidate-local, source-referenced, total, and `authority_effect: none`; geometry and community detection cannot define it. Canonical promotion remains a separate owner decision.

### Is the renderer replaceable and testable?

Yes. `KnowledgeScene`, `SceneGeometry`, adapter capabilities, semantic intents, and encodings are separate versioned seams. React Flow 12.10.1 plus ELK 0.9.3 is the first pinned candidate using controlled arrays, not `addEdge()`. Cytoscape is retained as a separately admitted alternative, never an automatic fallback. Geometry and browser gates assert exact paths, markers, endpoints, identity, focus, occlusion, responsive modes, and numeric performance.

### Is the Work Pack executable without another design decision?

Yes. It contains 22 one-behavior SWUs in four gated waves, starts with pure source normalization, supplies algorithms and write scopes, requires Task Session evidence/closeout per mutation, and selects deterministic successors. The source-owned build cutover occurs only after semantic and UI contracts pass. Full Body War acceptance occurs before static/cross-project reuse.
