# TASK-UOVA-08 — Reusable Projections

Goal: prove the architecture is not a Body War-only renderer without widening ontology authority.

Write scope: OEW static/print adapter sources and tests plus OEW-owned read-only fixtures derived from one selected second project. Do not mutate Body War ontology, Augmentor, Anime, or any other project source.

## SWU-UOVA-022 — Static and print projection

Primary behavior: generate deterministic SVG/print output from the same `KnowledgeScene` and `SceneGeometry`.

Algorithm: consume scene and canonical geometry directly; emit stable DOM/SVG IDs by exact source identity; render paths, markers, exact labels, patterns, icons plus text, Grouped Portal sentences, legend, and evidence/source references; provide a linear reading order; never rebuild semantic relations in the adapter.

Acceptance: spatial/static/index identity parity, deterministic output digest, visible direction at grayscale/print, no-JS inspection, and no alternate semantic denominator. Dependency: 021. Select 023.

## SWU-UOVA-023 — Second-project adapter proof

Primary behavior: compile one smaller external ontology/view corpus through the same SourceGraph, View Pack, Scene, geometry, index, and static contracts.

Algorithm: select the smallest digest-bound Augmentor or Anime source fixture already present; implement only its source adapter and candidate-local View Pack in OEW test fixtures; compile and compare denominators/identities across spatial, linear, and static projections; record unsupported source features explicitly rather than generalizing them away.

Acceptance: no project-source writes, exact source/digest binding, total scene/index mapping, same schemas and adapter interface with zero Body War conditionals in core modules, and 58/58 full UI API inventory conformance including the SWU-022 `StaticProjection` contract and all six Mapping specializations. Dependency: 022. Success closes G4; failure leaves a named portability residue rather than invalidating Body War G3 evidence.

Each unit runs OEW regression, deterministic replay, and scoped whitespace. Closeout synchronizes its row, this task, W4, and Work Pack. Expected result: adapter parity receipt, input/output digest inventory, unsupported-feature list, and capability ceiling.
