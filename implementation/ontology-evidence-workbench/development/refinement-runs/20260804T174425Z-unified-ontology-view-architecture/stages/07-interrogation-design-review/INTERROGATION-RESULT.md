6. Add versioned geometry, adapter-capability, semantic-intent, and encoding-registry schemas.
7. Make React Flow/ELK admission executable: pinned dependencies/environment, controlled parallel edges, numeric budgets, commands, failures, and activation rule. Cytoscape stays non-operational until independently admitted.
8. Replace `bounded`, `within tolerance`, `correct`, `valid`, and `obviously unusable` with numeric/machine-addressable oracles.
9. Separate complete index from filtered result and test realistic worst-case bounded/focus/Path scenes.
10. Specify source-build input/output, lock, parity, cutover/rollback, and proof of zero minified surgery.

## Kill conditions

- Any exact source relation is lost, duplicated, tuple-deduplicated, or untraceable across scene, portal, Path, inspector, and index.
- Parallel relations become coincident/indistinguishable or lose predicate/evidence access.
- Cluster/portal destination is inferred from layout or ambiguous membership.
- Back crosses a stale graph/View Pack revision or cannot restore all state/focus.
- Path makes semantic inference beyond bounded declared edge traversal.
- Primary adapter lacks semantic, accessibility-state, geometry, or numeric performance evidence.
- Build still patches compiled/minified JavaScript.
- Negative fixtures cannot emit their named failure codes.

Owner-authored cluster membership, executed full-bundle budgets, human predicate discrimination/comprehension, formal accessibility audit, and admitted renderer versions remain downstream evidence.
