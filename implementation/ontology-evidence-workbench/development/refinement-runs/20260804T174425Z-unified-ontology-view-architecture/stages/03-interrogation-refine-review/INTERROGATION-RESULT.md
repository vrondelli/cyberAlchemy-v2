# Refine Review — Definition Attack

Mode: `refine-review`  
Decision: proceed with repairs embedded in Design; no operator question is blocker-level.

## Tension ledger

| Thesis | Attack | Resolution / owner |
|---|---|---|
| One Knowledge Scene solves the split UI. | A universal scene can become a god object and couple semantics to layout. | Scene is immutable semantic/presentation input; geometry and transient renderer state remain adapter outputs. Design owner must publish separate schemas. |
| Exact predicate color makes relations understandable. | Thirty-nine colors are not learnable and color cannot carry identity. | Exact text is primary; color is stable recognition aid, pattern and marker are redundant; legend is contextual and filterable. |
| Cluster portals reduce the black box. | Aggregation can hide distinct predicates, directions, and evidence. | Portal summary is an index over lossless constituent relation IDs; expanding it is mandatory. |
| Bounded scenes protect comprehension. | Curated scenes can hide gaps and imply completeness. | Show scene denominator, portal count, and a persistent Full Index escape with complete counts. |
| A graph tool can replace custom rendering. | Library data models can become semantic authority and constrain accessibility. | Tool sits behind RendererAdapter/LayoutAdapter; query, state, evidence, and index remain framework-neutral. |
| Full Body War is acceptance proof. | Counts alone previously passed a broken UI. | Acceptance requires geometry, marker endpoints, cues, portal constituents, restoration, viewport collision checks, and negative fixtures—not only counts. |

## Required repairs carried forward

1. Split `KnowledgeScene` from `SceneGeometry` and `NavigationFrame`.
2. Make `SourceRelationBinding` total and preserve source plus traversal direction.
3. Define a source-owned cluster registry; forbid layout-derived clusters from being labeled ontology groups.
4. Keep Full Index and evidence inspector independent of spatial-renderer operability.
5. Require relation and node visual encodings to be redundant in text/structure.
6. Test exact restoration of every Navigation Frame field and initiating focus.
7. Use a multi-predicate, boundary-crossing first-scene fixture; the current one-edge fixture is insufficient.
