## Toy-game

The executable toy reads the actual Body War presentation graph and evidence sidecar. Positive control confirmed 276 nodes, 301 graph relations, 301 sidecar relations, 39 unique exact predicate colors, and 577 complete-index rows. Thirteen independent mutations each emitted its required failure code, including relation-card substitution, missing arrow, missing icon, flattened portal, predicate loss/color collision, partial/stale restoration, tuple deduplication, index loss, inspector occlusion, unresolved portal cluster, and unbounded Path.

The first run correctly failed because the color-collision mutation selected two relations with the same predicate. The fixture was repaired to collide `tested_by` with `realized_by`, then the full matrix passed. This is useful negative-control evidence, not product evidence.
