# Implementation Layering — Unified OEW

## Global boundary

| Layer | Question | Included SWUs | Promotion evidence |
|---|---|---|---|
| L0 semantic trust | Can exact source identity compile into bounded, reversible, renderer-neutral scenes? | 001–006 | pure fixture tests, totality, portal partition, bounded Path, frame replay |
| L1 visible prototype | Can a digest-bound UI API first prove complete non-spatial access, then admit one renderer with real typed geometry and lossless navigation? | 007–014 | typed UI-profile admission, encoding, canonical ELK geometry, Full Index/linear fallback before React Flow, paths, portals, Path/inspector |
| L2 usable full fixture | Does the source-owned Body War build pass responsive, accessibility-state, negative, scale, and migration gates? | 015–021 | viewport/keyboard/forced-color evidence, 276/301 adapter/build/browser receipts |
| L3 reusable projections | Can the same scene produce static output and load a second non-Body-War View Pack? | 022–023 | static parity receipt and one bounded cross-project adapter fixture |

Promotion is evidence-driven. L1 cannot start before L0 source/scene receipts pass, and visible UI cannot proceed beyond its first admission unit until G1U passes. L2 cannot cut over Body War before the L1 adapter capability receipt passes. L3 is optional for the first Body War test but remains required for the architecture's reusable/static claim.

## Decision ownership

- Project ontology owners own source graphs and View Packs.
- OEW owns scene/query/navigation/adapter contracts.
- DomainSpec's candidate profile supplies development-only classification evidence; OEW owns the compiled UI API and must not import DomainSpec at runtime.
- ELK owns geometry calculation only.
- Renderer adapter owns spatial primitives and intents only.
- Body War generator owns its source adapter and candidate-local build.
- Task Session owns one SWU execution and its terminal evidence; it does not reinterpret architecture.

## Deferrals

Cytoscape/Sigma adapters, deployment, ontology promotion, human-comprehension claims, formal WCAG conformance, and production rollout are outside L0–L3.
