# Joined Evidence Findings

## Convergence

The evidence supports one framework-neutral, lossless Scene Model above project-owned graph/view sources and below three presentation modes: interactive spatial graph, linear/accessibility projection, and static/print projection. It does not support one rendering engine for every task.

## Reusable versus discardable

| Source family | Reuse | Do not carry forward |
|---|---|---|
| CyberAlchemy view contracts | authority/claim ceilings | Markdown as interactive architecture |
| Unified Canvas | deterministic model/layout/route seam and SVG mechanics | fixed five-band layout and toy-only assumptions |
| Body War Atlas | exact source coverage, arrow sentences, static/browser gates | project-specific generator and flat relation portals |
| Augmentor | typed view roles and source-bound sequences | fixed horizontal-lane canvas |
| Anime.js vault | digest-bound nonvisual task views | assumption that every view needs a graph canvas |
| Existing OEW | inspector, index, deep links, filters, receipts | split renderers, relation cards as edges, flat portals, minified patching |
| Force explorer | large-graph overview/search precedent | full-graph default, CDN monolith, color-heavy canvas |

## Architecture consequences

1. Scene compilation owns source/view normalization, bounded queries, portal grouping, Path, evidence binding, and Navigation Frames.
2. Layout owns dimensions, hierarchy, ports, coordinates, bend points, and label routes only.
3. Renderer owns spatial primitives and emits semantic intents; it cannot infer relations or grouping.
4. Exact source relation IDs survive parallel edges; tuple identity is forbidden.
5. The first adapter is React Flow + ELK behind conformance gates; Cytoscape + ELK is the named fallback.
6. Full Index remains complete even when the spatial scene is bounded or renderer capability fails.
7. Static/print and linear/accessibility projections consume the same scene and evidence bindings.
8. Acceptance must test behavior and geometry, not DOM counts alone.
