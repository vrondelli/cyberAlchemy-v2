# Evidence-lane Returns

## View-surface cartographer

Eleven architectural families were reconstructed from direct source and receipts. Conditional convergence is supported: project-owned source graphs remain authoritative, while one lossless scene projection feeds separate interactive, linear/accessibility, and static/print adapters. A single renderer for every task is not supported.

Strongest reusable precedents:

- CyberAlchemy views: allowed/forbidden claims and owner boundaries.
- Unified Canvas: model/layout/render separation, deterministic ports/routes, typed edges, keyboard navigation.
- Body War Atlas: exhaustive source fidelity, actual SVG arrows, print/no-JS/narrow/browser checks.
- Body War relation views: literal relation sentences and learner/reviewer separation.
- Augmentor views: typed view roles, sequences, allowed readings, forbidden authority moves.
- Anime.js vault: digest-bound orthogonal task projections.
- Current OEW: full bundle, evidence inspector, index, and focus derivation—but its split renderers are rejected.

Rejected patterns: project-specific atlas as universal owner; tours/layers/lenses as ontology branches; one button per cut edge; separate active-scene renderers; minified-bundle surgery; full-force default; layout/color as semantics; count-only acceptance.

## Graph-tool evaluator

Primary-documentation comparison found React Flow + ELK the provisional first renderer because it best fits the existing React stack, semantic DOM cards, SVG edge assertions, keyboard hooks, and testability. Cytoscape + ELK remains non-dominated if full-fixture performance or compound/multigraph behavior fails. Sigma/Graphology is an optional dense-overview adapter, not the primary semantic UI. ELK owns geometry only.

Critical negative: React Flow `addEdge()` tuple-deduplicates matching endpoints/handles even when edge IDs differ; source ingestion must use controlled arrays keyed by exact relation ID.
