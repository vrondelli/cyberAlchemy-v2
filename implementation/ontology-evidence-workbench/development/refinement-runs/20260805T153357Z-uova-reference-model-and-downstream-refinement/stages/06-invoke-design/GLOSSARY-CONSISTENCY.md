# Glossary Consistency

Status: PASS with candidate additions.

- `SourceRelationBinding`, `SourceGraph`, `KnowledgeScene`, `ViewPack`, `NavigationFrame`, and `SceneGeometry` retain their prior meanings.
- `RelationRef`, `RelationFacet`, `RelationFacetIndex`, `RelationIndexReceipt`, and `RelationSnapshot` are candidate-local design terms linked to the Define glossary.
- `RelationFacet` is explicitly a role over an existing binding, not an ontology facet and not a new authority node.
- `source_direction` and `traversal_direction` remain non-collapsed.
- `predicate encoding` remains presentation metadata and never redefines `exact_predicate`.

No canonical definition is promoted or changed.
