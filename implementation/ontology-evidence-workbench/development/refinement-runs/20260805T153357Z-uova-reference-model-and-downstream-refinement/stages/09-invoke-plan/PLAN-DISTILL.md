# Plan Distill

The previous downstream sequence hid one cross-cutting relation law. This repair
reduces it to nine independently verifiable units:

- establish identity and migration first;
- implement Portal and Path independently over the same resolver;
- join selection and projections only after both interaction records are stable;
- defer project data and browser acceptance until the generic chain is complete.

This is the smallest plan that preserves distinct acceptance owners for schema,
migration, Portal, Path, state, presentation, static output, project integration,
and final reuse. Combining adjacent units would blur a failure owner; splitting
further would create tasks that cannot prove an observable invariant.
