## Fixed envelope

Each cell: context limit 8,000; recycle threshold 7,000; safety margin 1,000;
cumulative model input plus output cap 96,000; maximum 96 model calls; output
cap 2,048. Index: at most eight entries and 1,024 measured presentation tokens;
its separately capped tokenizer allowance is 512. Reasoning low and existing
token margin/model timeout remain as recorded in the matrix.

Before an exploration dispatch would consume the 14,000-token finalization
reserve, or when only two calls remain, switch to tools-disabled finalization.
The phase switch makes no model request. Every finalization/correction request
must independently fit context and cumulative-token admission. Unused reservation
is not charged as model usage. The one correction opportunity remains bounded;
there are no free final responses, provider retries or replacement episodes.

## Complete evidence contract

Final context names relevant delivered evidence that can be represented in the
pinned base revision. Current-source reads remain available for source work.
Schema, delivered-ID and source-version failures are diagnosed before terminal
acceptance. During exploration, existing tools may retrieve or recover relevant
base evidence before resubmission. Do not substitute IDs automatically, drop
selected changed lines to improve precision, or expose gold-relevant handles.

Newly executed tool exchanges remain in the next measured request until a
successful model response confirms first delivery. If that complete request
cannot fit after recycling, record context_budget_stopped. An explicit empty
selection is no_context_selected with no native score, never archive-union credit.
Neither case is scored as a successful repair or a zero-valued native result.

Native final metrics use the independently executed pinned scorer. Source trace
projection can omit nonfinal changed lines, and archive-recovery redisplay is not
credited as a new native step. Therefore complete trajectory/AUC and semantic
retention claims remain out of scope. Patch presence is not correctness.

## Stopping, analysis and successor

The scheduler verifies result identity/hash/status, export errors and scoring
artifacts before starting another cell. Any shared exporter, scoring or unknown
runtime failure pauses unstarted cells. Retain ordinary call/token/context budget
stops, invalid final responses and explicit empty selections as distinct outcomes.
Record unstarted-paused cells separately from attempted failures.

Analyze every scheduled identity, paired native file/span metrics, derived final
span F1, missingness, and cumulative model tokens. Unknown usage is unknown and
prevents further requests. Record phase switches separately from corrections.
Do not use complete-case averages to claim full-cohort improvement when pairs are
missing. A valid instrument alone cannot support H1; actual post-displacement use
needs separate evidence beyond native retrieval scores.

Closeout binds observations and a reviewed learning decision to the exact H1
experiment. A failed/inconclusive round returns to a new evidence-led hypothesis
and separately frozen protocol. Only the unchanged full [acceptance contract](acceptance.json)
and reserved confirmation can clear ContextBench; no automatic SWE-bench stage.
The initial GLM small-window goal and broader model/domain transfer remain explicit
remaining obligations after this diagnostic round.
