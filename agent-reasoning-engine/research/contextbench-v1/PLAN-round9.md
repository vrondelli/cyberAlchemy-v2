## Fixed development decision rule

Use the same eight exposed tasks at 8K, recycle at 7K, and 96K cumulative model
tokens per cell. Both arms share source, tools, output deferral, structured
terminal submission, one incomplete-output correction, provider, scorer, and
all limits. Only treatment state presentation differs. Failed and corrective
requests both count. Pair order alternates.

H18 requires at least +0.05 paired macro span F1; file F1 and valid completion
must not degrade; every treatment state is at most 1,024 tokens; at most four
state measurements occur per render; each cell uses at most one output-cap
correction; control has zero state presentations; speculative measurements,
false facts, false source credit, effects, and unknown model usage are zero; all
model input/output tokens remain below 96K per cell. Any policy mismatch or
second incomplete output stops the round.

Development cannot clear ContextBench. Clearance still requires all 1,136
tasks, 8K/10K/12K, 48K/96K/192K tiers, two confirmation repetitions, the fixed
bootstrap lower bound and non-degradation checks, with missing/errors retained.
