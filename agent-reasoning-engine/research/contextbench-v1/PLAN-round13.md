## Fixed decision rule

Use the same exposed eight tasks at 8K, recycle at 7K, and cap each cell at
96,000 cumulative model input plus output tokens. Control receives no task state.
Treatment receives one fitted evidence-only state on the first dispatched request
of each recycle generation. The host retains all outcome facts for verification
and recovery. Both arms otherwise share source, tools, prompt, output correction,
provider, scorer, call limit, and 300,000 ms deadline.

H23 requires all eight pairs and state-minus-control paired macro span F1 of at
least +0.05. Scheduled zero-filled file F1 and aggregate valid completion may not
degrade. Each treatment generation gets exactly one presentation of at most
1,024 tokens and four fitting measurements. Aggregate treatment model tokens
must be below Round 12's 352,655. False state facts, false source credit,
unmatched presentations, generation mismatches, outcome leakage, terminal
repository effects, unknown model usage, and control presentations must be zero.

No task, source, prompt, cap, threshold, state mechanism, or stop rule changes
after freeze. Missing and failed outcomes remain in the denominator. A favorable
development result may prepare untouched confirmation; it does not clear
ContextBench by itself.
