## Research method

Every round follows this exact chain:

objective → gap → question → competing hypotheses → selection → experiment/tasks/criteria → results → observations → reviewed decision → successor

Round ten verified one-to-one state cadence and produced a favorable incomplete
native signal before a provider deadline. Round eleven then exposed a deeper
cross-layer defect on its first cell. A fully accounted HTTP 200 response used
all 2,048 output tokens and reported `finish_reason: length`. The episode retained
its usage and invoked the frozen one-correction policy, but the transport had
persisted the durable ledger as failed and rejected that corrective request.
The cell used 10,211 known model tokens; fifteen cells remained unstarted.

Gap: typed incomplete-output recovery and durable transport accounting disagree
about whether a fully observed length-limited response is recoverable. Until
they agree, the one-shot state hypothesis cannot receive complete exposure.

Question: does treating only fully accounted length-limited responses as
ledger-idle permit the bounded correction and allow the complete GLM-5.3-flash
8K one-shot experiment to evaluate its fixed criteria?

- H22-R12 (selected): an exact accounted-incomplete-output ledger transition
  permits the one correction and enables the complete one-shot experiment.
- H20-R12: delta-only boundary state is needed to reduce token input further.
- H0-R12: process state cannot reliably improve native evidence selection because
  semantic interpretation is the limiting factor.

The exact records and selection are in `hypotheses-round12.json`. Round-ten's
incomplete signal, Round 11's one attempt and fifteen unstarted cells, its failed
ledger, and all earlier counterevidence remain retained by their closeouts.

## Fixed decision rule

Use the same eight exposed tasks at 8K, recycle at 7K, and cap each cell at
96,000 cumulative model input plus output tokens. Control receives no task state.
Treatment receives one fitted receipt-bound state on the first dispatched request
of each new recycle generation. Both arms use the same source, tools, prompt,
output deferral, terminal submission, one incomplete-output correction, provider,
scorer, call limit, and 300,000 ms model deadline. A fully accounted length
response and its correction both count all model input and output tokens. Network,
authentication, malformed response, missing usage, and uncertain-dispatch errors
remain terminal instrument failures. Deadline duration is not an optimization
metric and never excuses unknown token usage.

H22 requires all eight scheduled pairs and state-minus-control paired macro span
F1 of at least +0.05. Scheduled zero-filled file F1 and aggregate valid completion
may not degrade. Every treatment recycle generation must have exactly one matching
presentation, every generation at most one, each state at most 1,024 tokens and
four fitting measurements, and aggregate treatment model tokens below round
nine's fixed 396,085-token state total. False state facts, false source credit,
unmatched presentations, generation mismatches, terminal repository effects,
unknown model usage, and control presentations must be zero.

No task, source, prompt, cap, threshold, state mechanism, or stopping rule may
change after freeze. Round-ten and Round 11 attempts are historical evidence,
not substitute runs. Missing and failed outcomes remain in the denominator. A favorable result
may prepare untouched confirmation under the existing acceptance contract; it
does not clear ContextBench.
