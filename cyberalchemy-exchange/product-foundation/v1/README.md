# Exchange product foundation

Candidate consolidation, 2026-09-13. Owner: Exchange product owner.

Start with the [product thesis](PRODUCT-THESIS.md) and [selected offering catalog](OFFERINGS.md), then the
[ontology structure](ONTOLOGIES.md), [capability inventory](CAPABILITIES.md),
and [source map](SOURCE-MAP.md). The host is included in Exchange's product scope.
The packet links dispersed work without moving or rewriting its implementation.

[model.json](model.json) records the candidate scope, concepts, capabilities and
questions. The business, system and bridge JSON files are review models, not
admitted runtime ontologies. Existing Alch/DomainSpec generated artifacts retain
their original source and claim boundaries.

The [Exchange MVP design](mvp/v1/README.md) now connects the thesis to ten
customer-facing capabilities, one application, three complete journeys and a
[successor integration roadmap](mvp/v1/ROADMAP.md). It supersedes the earlier
roadmap sequencing and retains exact implementation evidence as bounded input.

The [quality evidence design](QUALITY-EVIDENCE.md) records public scores, community validation, sustained usage and application outcome feedback.
