# Hosted Devnet Exchange Ontology

This private durable package uses the `business-system-bridge` archetype.
Business meaning and system realization stay separate; bridge relations require
evidence on both sides. `validate.py` checks exact source currency, stable IDs,
endpoint closure, bridge evidence and the non-effect authority ceiling.

```bash
python3 ontology/validate.py
```

A PASS validates this candidate package only. It does not admit it.
