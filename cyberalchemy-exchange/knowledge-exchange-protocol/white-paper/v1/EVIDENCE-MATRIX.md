## Evidence join

The evidence is complementary rather than cumulative authority:

```text
definitions explain meaning
  + Product Capabilities bound intended outcomes
  + ontology/DomainSpec express system obligations
  + EVF formal providers check seven bounded propositions through fifteen projections
  + local providers observe selected implementation behaviors
  + relation evidence maps 204 compiled relations to providers
  + independent review challenges one immutable implementation candidate
  + PostgreSQL observes one persistence realization
  + Devnet reads observe one prior finalized public state
  != exact formal-to-implementation refinement
  != automatic D65 or aggregate conformance
  != production proof
```
