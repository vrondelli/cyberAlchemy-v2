# CyberAlchemy Exchange Presentation

This folder contains a 20-slide, image-led live presentation for the Knowledge
Expansion Protocol. It is a local presentation candidate, not a publication or
product-approval artifact.

## Present

Serve this directory over loopback and open `index.html` in Chromium. The deck
is also usable directly from the filesystem.

- `Right Arrow`, `Space`, or `Page Down`: next slide
- `Left Arrow` or `Page Up`: previous slide
- `Home` / `End`: first / last slide
- `N`: toggle speaker notes
- `F`: toggle fullscreen
- Click the right or left half of a slide to move forward or back

The URL hash identifies the current slide, for example `index.html#9`.

## Print or export

Use Chromium's print dialog and select landscape orientation. Print CSS creates
one 16:9 page per slide. Speaker notes and controls are excluded.
