# Robot Talks Template

Status: example candidate  
Authority effect: none

This is a reusable strategy example rather than a product mode. Its Strategy
Template creates four concern lanes with a constructive and adversarial agent in
each lane, followed by generic synthesis, audit, and closeout work. The Run
Template supplies a button-ready default topic while still producing a Dispatch
Proposal for review and admission.

Regenerate or check the committed artifacts with:

```sh
python3 orchestrator/examples/robot-talks/build.py
python3 orchestrator/examples/robot-talks/build.py --check
```

The example generates hypotheses and evidence. It does not decide scientific
truth, policy, permission, publication, or external-effect authority.
