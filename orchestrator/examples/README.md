# Orchestrator Examples

Status: candidate package boundary  
Authority effect: none

This context contains reusable strategies, templates, fixtures, and demonstrations. Robot Talks and Robot World remain examples or consumers rather than fixed product modes.

## Current boundary

`robot-talks/` supplies an eight-agent paired-tension template. `robot-world/`
supplies a run-and-verify template and domain adapter. `trusted-dataset/` records
the direct pure-RWO consumer binding. Domain-specific evidence remains with each
domain.
