# Invoke Define Template Selection

Status: candidate evidence  
Authority effect: none

## Selected family

`module-formulae`, vocabulary-map subset.

## Eligibility

The Orchestrator is a high-complexity module with product, authority, ontology,
contracts, capabilities, RWO, runtime, workers, UI, deployment, examples, tests,
and migration contexts. It needs a concept index, relationship map, evidence
links, boundary language, and deterministic synchronization checks.

## Alternatives

- `generic` is ineligible because the module-specific vocabulary template fits.
- `architecture` is a later design-stage family; the current objective is Define.
- `implementation-plan` is a later planning-stage family.
- `research`, `spell`, `sigil`, `session-handoff`, and `ux-plan` do not match the
  current target artifact.

## Selection posture

There was no eligible-template tie. The installed Invoke package references a
missing generated `define.md` companion; the root Invoke contract, Module
Formulae vocabulary template, and repository-native Define contract were used.
This is an Invoke packaging gap, not an Orchestrator definition blocker.
