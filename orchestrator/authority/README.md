# Shared Orchestrator Authority

Status: candidate package boundary  
Authority effect: none

This context owns normative Orchestrator definitions, scoped constitutions, and recorded owner decisions used across product, ontology, contracts, RWO, runtime, frontend, deployment, examples, and tests. Candidate material becomes authoritative only through its configured owner route.

## Current boundary

`definitions/` currently contains the candidate ORCH vocabulary. `constitutions/` and `decisions/` will be introduced only when M2 identifies an exact shared rule or decision that requires them.
