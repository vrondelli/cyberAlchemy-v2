# Light Sculptures

Eleven 256×256 transparent WebP illustrations for the A.R.E documentation prototype.
`manifest.json` records runtime hashes and export settings. Semantic IDs and labels are
owned by `src/sculptureAssets.ts`; labels remain text rather than being baked into images.

Source prompts and generation paths: `SCULPTURE-PROMPTS.json` in the prototype root.
The five reused assets originate in `keld-project/prototype/assets/are-icons/README.md`
from the repository root. Six additional assets were generated for this implementation.
