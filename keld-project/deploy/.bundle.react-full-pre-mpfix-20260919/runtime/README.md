# Private KELD sandbox runtime candidate

Install from integrations with npm ci --omit=dev --ignore-scripts --install-links.
Then run npm run check-config -- /private/config.json before npm start.
Node 26.8.1 and Python 3.14 were used for local verification.
No credentials, database, TLS key or ARE release is included.
This is not a production or redistribution approval.
