# Engine release preparation — not an engine package

The offer is now an alpha release with first-100 one-year upgrades and direct
maker support. No source repository or product archive was provided for this
website revision.
This is a preparation checklist, not an assertion that these files already exist.

## Proposed archive contents

- The actual engine release, in the source/binary format you decide to ship.
- README with tested installation steps, requirements and one verified example.
- The unmodified Apache License 2.0 text in a LICENSE file for the covered work.
- NOTICE and third-party license/attribution information as applicable.
- Release notes and a clear version identifier.

Publish a checksum generated from the real archive; do not invent a size or hash.
Do not include API keys, credentials, personal data or unrelated internal files.

## Licensing checks

Confirm ownership or permission to license the work. Identify components covered
by Apache 2.0 and any components with different licenses. Preserve their required
notices rather than automatically relicensing them. Record the real copyright
owner in applicable notices; do not replace it with the Apache Software Foundation.

Apache 2.0 redistribution conditions include supplying the license, marking
modified files, retaining applicable notices in distributed source derivatives,
and preserving relevant NOTICE attribution when the original includes it.
A NOTICE file is not a mechanism for adding new software-use restrictions.
The license does not grant general trademark rights.

This is a working checklist; evaluate the actual release, dependency obligations,
and any applicable legal requirements before distribution.

## Alpha release and upgrade delivery

Publish the real alpha version identifier, known limitations, breaking-change
notes and safe installation/testing instructions with the package. Do not label
it a stable or production-ready release. Record the official release history
and prepare upgrade access for eligible customers throughout their first year.
Confirm the support destination and recovery process before opening sales.
