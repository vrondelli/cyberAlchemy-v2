# A.R.E Light Sculptures

Selected direction: 01 / Light Sculptures. Owner selection: “1 is good”.

style reference. Five transparent WebP assets are consumed by the inline SVG in

Generation prompt template:

> Create ONE standalone production icon asset, not a concept sheet. Use the supplied sheet only as STYLE REFERENCE: specifically row 01 LIGHT SCULPTURES, never row 02 or 03. Subject: [subject below] Premium fluid blue holographic energy sculpture with translucent ribbons, pale icy-blue edges, restrained glow. Graceful, clean, readable silhouette at 40px. Consistent three-quarter perspective and soft blue lighting as the reference first row. Center the one object in a square canvas, occupy 80 percent of width and height with comfortable margin. GENUINELY TRANSPARENT BACKGROUND with alpha; no navy backdrop, no checkerboard baked into image, no ground, no cast shadow panel. No text, labels, logos, border, badge, tile, particles or extra objects. Preserve the reference's refined light sculpture aesthetic, not metal, not cartoon, not plastic. Output just the single [name] icon.

Subjects:

- `goal.webp`: A luminous central blue pearl held within three thin, intertwined translucent blue energy ribbons, like a focused aperture. Match the top row first icon.
- `action.webp`: Two open circular energy components facing each other, connected by a concentrated luminous bridge. Match the top row second icon.
- `evidence.webp`: Three floating translucent gently curved blue sheets stacked diagonally, with a small captured waveform of light between them. Match the top row third icon.
- `comparison.webp`: One continuous blue ribbon splitting into two flowing branches, each ending in a tiny luminous pearl. Match the top row fourth icon.
- `refinement.webp`: Four curved blue energy fragments assembling around one luminous central pearl into a coherent spherical form. Match the top row fifth icon.

Exports: 256px square, WebP quality 90, alpha quality 100. Generated alpha retained;
no background removal or creative redrawing. Motion remains browser-controlled.
Original PNGs remain in the generation archive; runtime assets are stored here.
